근거:
- 2026-10-23 글·문항 검수 4건(Haiku)
- 브랜드 조사(Opus)
- 운영 페이지 직접 확인

목표: "신뢰가 안 간다", "읽으면 부자연스럽다"는 문제를 검증 가능한 방법으로 줄인다.
- 확인할 수 없는 주장을 없앤다.
- 사실 오류를 고친다.
- 모의고사에서 문제를 안 읽고도 맞히는 단서를 없앤다.
- 문체를 하나로 통일한다.
- 제작 방식을 공개한다.

## 공통 안전 규칙
day.md를 편집하는 모든 단계에 적용한다.
- **본문 범위**
  - `## 📝 연습 문제` 앞의 본문만 수정한다.
  - 본문에 `**문제 N.`을 쓰지 않는다.
  - `# Day N -` 제목은 바꾸지 않는다.
- **편집 후 검사**
  - `node scripts/restore-quiz.mjs <경로>`로 퀴즈 원본을 복원한다(퀴즈 자체를 고치는 단계는 예외).
  - `npx vitest run src/lib/quizContract.test.ts`를 통과해야 한다.
- **커밋과 내용 원칙**
  - 주차 단위로 커밋한다.
  - 사실을 지어내지 않는다. 출처가 없는 수치·사례는 지우거나 완화한다.
- **브랜치**
  - 작업은 worktree에서만 한다. 공유 체크아웃에서 브랜치를 바꾸지 않는다.
  - 브랜치는 단계마다 하나씩 만든다.

## Step 3. 모의고사 실전화 (content/exams/*.json)
### 3a. 정답 보기 길이 편향 제거
- **내용**: 정답 보기가 가장 긴 비율이 sap·scs 100%, dva 99%, dop 94%, mls 92%, dea·mla 88%다. 오답 보기를 정답만큼 구체적으로 늘리거나, 정답을 간결하게 줄인다. 정답·해설의 사실은 바꾸지 않는다.
- **수용 기준**
  - 자격증별 "정답이 가장 긴 보기" 비율이 40% 이하다.
  - 이 비율을 계산하는 회귀 테스트를 추가한다.
  - 정답 키는 바뀌지 않는다.

### 3b. 정답 글자 분포와 문항 수
- **내용**
  - mls-c01은 정답이 B 44개, C 2개, D 1개다. 보기 순서를 섞어 A~D 분포를 고르게 한다.
  - 문항 수를 실제 시험과 맞춘다. saa·dva·soa는 68 → 65, sap·dop는 72 → 75. 도메인 비중은 `exam-info`를 따른다.
  - 기존 응시 기록(DB)이 문항 번호·정답 글자를 참조하는지 먼저 확인하고, 호환을 유지한다.
- **수용 기준**
  - 자격증별 정답 글자 하나가 35%를 넘지 않는다.
  - 문항 수와 도메인 비중이 `exam-info`와 일치한다(±1문항).
  - 기존 응시 결과 페이지가 깨지지 않는다.
- **범위 밖**: 일차 연습 문제(day.md)의 정답 글자 재배치. 별도로 판단한다.

## Step 4. 문체 가이드와 일괄 정리
### 4a. 문체 가이드·용어집 작성
- **내용**: `docs/content-style-guide.md`를 만든다.
  - 본문은 평서체 "~다"로 통일한다.
  - 응원·권유 문구("Fighting!!", "~하자", "합격을 빈다")를 금지한다.
  - 이모지 콜아웃은 시험 판단에 필요한 것만, 글당 최대 2개.
  - 요약 섹션은 "정리" 하나만 둔다.
  - "핵심은 ~다" 반복과 출처 없는 빈도·수치 표현("시험 단골", "절반은")을 금지한다.
  - 한영 용어집을 만든다(Lambda, 페일오버, 스택 등 한 가지 표기).
  - 기존 `docs/content-format.md`와 충돌하지 않게 한다.
  - 위반을 세는 검사 스크립트를 만든다(`scripts/audit-style.mjs`). 출력은 파일별 위반 건수.
- **수용 기준**
  - 가이드와 용어집이 작성되어 있다.
  - 스크립트가 전 콘텐츠의 위반 건수를 기준선으로 출력한다.

### 4b. 트랙별 일괄 정리
- **내용**: 4a 가이드대로 자격증 하나씩 본문을 정리한다. 순서는 saa-c03 → clf-c02 → aif-c01 → 나머지 AWS → linux-master-1·2. 영어판(content/en)은 제외한다.
- **수용 기준**
  - 대상 트랙의 audit-style 위반이 기준선 대비 80% 이상 줄어든다.
  - quizContract 테스트가 통과한다.
  - 주차 단위로 커밋한다.
- **범위 밖**: 내용 보강·새 섹션 추가, 퀴즈 수정.
