# 남은 작업 계획 (2026-11-14 기준)

영어판 전체 번역(#65~#73)이 끝난 뒤의 남은 일을 순서대로 적는다. 앞 단계가 뒤 단계의 전제다.

## 순서를 이렇게 잡은 이유

- 영어판 전 주차가 이미 공개(색인 대상)이므로, 새 작업을 쌓기 전에 운영 상태부터 확인한다.
- 한국어 원문을 고치면 영어 번역도 같이 고쳐야 하므로, 한국어 정리는 영어 점검 뒤에 한다.
- 색인 감소 원인은 사용자의 서치 콘솔 캡처가 필요해서 에이전트 단계가 아니다. 사용자가 병행한다.

## Step 1 — 영어판 운영 점검(#72·#73)

#72(영어판 전 주차 공개)와 #73(SQLD·리눅스마스터 영어판)을 검토하고 운영에서 확인한다.
사이트맵의 영어 URL 수·hreflang 짝·canonical·noindex 잔존 여부, 영어 페이지 표본의 한글 잔존,
퀴즈 기준선 테스트, 언어 전환 버튼(`src/lib/enEdition.ts`)의 이동 대상 존재 여부를 본다.
수정이 필요하면 고친다. 인수 기준: 전체 테스트와 타입 검사 통과, 영어 URL이 사이트맵에 있으면 200.

## Step 2 — 정리 문서의 남은 일 바로잡기

`docs/growth/exam-realism-and-en-i18n-2026-11.md` 3절이 #72·#73 이전 내용이라 틀리다.
(영어 week2+ noindex, SQLD·리눅스마스터 영어판 없음). Step 1 결과를 반영해 고치고 `docs/growth-100.md` 기록도 맞춘다.
인수 기준: 문서에 사실과 다른 "남은 일"이 없다.

## Step 3 — 영어 연습 문제 번호·자리표시 정리

DVA week11, DOP week7/12, SAP week15/16은 영어 문제 번호가 한국어와 다르고(한국어 문제를 덧붙인 상태),
SAP week15/day1은 연습 줄이 자리표시뿐이다. 한국어 원문 기준으로 영어 문제를 맞춘다.
인수 기준: 해당 파일의 `**Question N.**` 개수와 정답이 한국어와 일치, 한글 0자,
`quizContract.test.ts`가 통과(기준선은 `UPDATE_QUIZ_BASELINE` 없이 맞춘다).

## Step 4 — 한국어 원문 오류 정리(영어 동기화 포함)

PR #66~#70 설명에 모아 둔 한국어 원문 오류(수치 시점, 부등호 방향, 보기 누락 등)를 공식 문서로 다시 확인하고 고친다.
고친 곳은 영어 노트도 같은 내용으로 맞춘다. 근거가 불확실하면 고치지 않고 목록에 남긴다.
인수 기준: 고친 항목마다 공식 문서 근거를 PR 설명에 적는다, 한국어·영어 문제 수와 정답이 계속 일치한다.

## 사용자 쪽 일정(에이전트 단계 아님)

- 색인 감소 원인: 서치 콘솔 캡처(색인 그래프, "안 된 이유" 표, 떨어진 URL 하나의 URL 검사)를 주면 원인을 가린다.
- cert 사이트맵 재제출, 11-20 전후 서치 콘솔 재확인, 11-24 전후 애드센스 검토 요청.
- 11-20 결과를 보고 종합·복습 노트(792개 중 182개) 처리와 영어판 색인 유지 여부를 정한다.
