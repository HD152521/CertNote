## 상황 분석

### 현재 상태
- **콘텐츠**: AWS 11종 + 리눅스마스터 1급, 16주 × 5일 = 415개 강의
- **구조**: Week 1 무료 / Week 2~16 Pro 구독
- **SEO**: 노출 100 / 클릭 3 (CTR 3%) → 수정됨 (Week 2+ noindex)
- **사용자**: 소수(대기자 + 초기 테스트 사용자)
- **마케팅**: Google SEO + 단톡방만 진행

### 경쟁 환경 (조사 진행 중)
- Udemy, A Cloud Guru, Coursera, Pluralsight, Linux Academy
- 각각 수천 개 코스, 100만+ 사용자
- 가격 경쟁 격화 (월 $15~50)

### CertNote의 차별화 요소
1. **한국어**: 유일한 한국어 AWS 자격증 종합 학습 플랫폼
2. **체계성**: 16주 주차별 커리큘럼 (Udemy의 산만한 코스 vs 명확한 끝)
3. **SRS 복습**: Leitner 시스템으로 과학적 암기
4. **깊이**: 각 자격증당 100+ 강의 (깊이 있는 커버리지)
5. **모의고사**: 실제 시험 유형 반복 연습
6. **지속 업데이트**: 시험 변경사항 즉시 반영
