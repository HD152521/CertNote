## A. 이미 반영한 수정 (commit + 검증 완료)

### A0. Week2+ 프리미엄 noindex (이전 커밋 96624d7)
- `[week]/[day]/page.tsx`: `w > FREE_WEEK`면 `robots: noindex,nofollow` 조기 반환.
- 효과: `kms generatedatakey` 같은 관련 없는 검색어에 프리미엄 페이지가 뜨던 문제 차단.

### A1. 허브 Course JSON-LD — 거짓 "무료" 선언 제거 ✅
- **문제:** `[slug]/page.tsx`에 `isAccessibleForFree: true` 하드코딩. 실제로는 Week2+ 페이월.
  구글에 "전부 무료"라 선언하고 페이월을 내리는 건 **구조화 데이터 스팸 → 수동 조치 사유.**
- **수정:** `isAccessibleForFree: false` + `hasPart`로 "Week 1만 무료"를 정직하게 선언.
  유료 강좌임을 밝히면서도 무료 파트를 명시 → 페널티 없이 색인 유지.
- 검증: `curl /aws-certs/saa-c03` → `isAccessibleForFree:false` + `hasPart{isAccessibleForFree:true}` 확인.

### A2. day 페이지 title에서 "Week N" 제거 ✅
- **문제:** `KMS 키 관리 전략 — SAP-C02 Week 3`. "Week 3"은 검색량 0인데 title 자리를 차지.
- **수정:** `${content.title} — ${code}` — 주제어를 앞세우고 Week 제거.
- 참고: 현재 Week2+는 noindex라 실질 적용은 색인 대상인 Week1 + (향후 전략 전환 시 전체).

### A3. sitemap `lastModified` 추가 + Week2+ 제외 ✅
- **문제 1:** `lastModified` 부재. 구글은 changeFrequency/priority를 사실상 무시하고 **lastModified만** 본다.
- **문제 2:** Week2+가 noindex인데 sitemap에 포함 → Search Console "제출된 URL이 noindex" 경고 + 크롤 예산 낭비.
- **수정:** 전 URL에 `lastModified`(day는 파일 mtime≈배포일), Week2+ day는 sitemap에서 제외.
- 검증: `curl /sitemap.xml` → `<lastmod>` 존재, `week2/` 카운트 0.

### A4. 허브 ExamInfoCard 언어 게이팅 해제 ✅
- **문제:** `[slug]/page.tsx` line 108 `lang === 'ko'` 조건이 영어 허브에서 시험정보 카드를 숨김.
  카드는 **이미 완전 이중언어**(문항수·시간·응시료 전부 en 라벨 보유)인데 불필요하게 막혀 있었다.
- **수정:** 게이팅 제거 → `/en` 허브에도 시험정보 노출(해외 유입에 유용).

## B. 남은 작업 (신규 페이지 — 설계·카피 필요)

### B1. 수요 키워드 대응 페이지 [HIGH]
현재 대응 페이지 없이 상위 노출된 검색어 → **의도 저격 페이지를 만들면 상위권 가능.**

| 검색어 | 현재 | 만들 페이지 | 노림수 |
|--------|------|-----------|--------|
| `aws saa-c03 후기` | 대응 페이지 0, 7위 노출 | `/guides/saa-c03-review` (합격 후기·공부법·기간) | 후기 의도 → CTA로 커리큘럼 연결 |
| `aws 요금` | 7위 노출 | `/guides/aws-pricing-basics` (요금 개념 + 자격증 연결) | 정보성 유입 → 브랜드 인지 |
| `aws 자격증 순서` | (B2 허브가 대응) | `/aws-certs` 카테고리 허브 | 로드맵 의도 |

- 형식: 정보성 아티클(구조화 데이터 `Article`) + 내부링크로 커리큘럼/무료 Week1 유도.
- 주의: 얇은 페이지 양산 금지. 각 페이지 실질 정보(표·체크리스트) 포함.

### B2. `/aws-certs` 카테고리 허브 신설 [HIGH]
- **문제:** `[category]/`에 `page.tsx`가 없어 `/aws-certs`가 **404**. (`/en`은 있는데 비대칭.)
- **기회:** "aws 자격증 순서" 키워드의 최적 착지 페이지. 전 자격증을 레벨별(foundational→associate→professional→specialty)로 나열 + 추천 순서 + 각 시험정보 요약.
- 구조화 데이터: `ItemList`(자격증 목록) 또는 `CollectionPage`.
- 예상: 반나절. `listCerts` + 레벨 그룹핑 재사용(랜딩/대시보드 패턴).

### B3. `/en` 영어판 확장 (동남아 돌파구) [MEDIUM]
- **현황:** 노출의 **65%가 해외**(베트남 14·필리핀 4…)인데 `/en`은 Week1만 번역.
- **논리:** 동남아는 한국보다 AWS 자격증 검색 경쟁이 덜해 **초기 상위권 진입이 쉽다.**
- 단계: (1) A4로 시험정보 노출 완료 → (2) 인기 자격증(SAA/CLF) Week1 영어 품질 점검 → (3) 영어 허브 메타/내부링크 보강 → (4) 반응 보고 Week2+ 영어화 판단.
- 결정 필요: 영어 콘텐츠 제작 비용 대비 동남아 전환(결제) 가치. 우선 무료 유입으로 검증.

## D. 전략 결정 필요 — Week2+: noindex vs 페이월 마크업 색인

지금은 **A0(noindex)**로 프리미엄을 검색에서 뺐다. 하지만 A1의 통찰("페이월을 제대로 마크업하면 유료 본문도 페널티 없이 색인 가능")은 **반대 전략**도 가능함을 뜻한다.

| 전략 | 장점 | 단점 |
|------|------|------|
| **① noindex (현재)** | 관련 없는 노출 즉시 제거, 단순 | 415페이지의 SEO 잠재력 포기 |
| **② 페이월 마크업 + 색인** | 프리미엄 페이지가 검색 랜딩으로 전환 유입 | 미리보기/title 품질 필수, 잘못하면 얇은 페이지 위험 |

- **권고:** 지금은 **① 유지**(CTR 회복이 급함). B1·B2로 무료 페이지 SEO를 먼저 세운 뒤,
  트래픽이 안정되면 **②로 전환 실험**(일부 인기 자격증 Week2~3만 먼저). 되돌리기 쉬움.
- 전환 시 필요: day 페이지 `Article` + `isAccessibleForFree:false` + `hasPart`(cssSelector로 무료 미리보기 영역 지정), sitemap 재포함, title/description 품질.
