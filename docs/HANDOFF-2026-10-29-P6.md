### #37 설계 메모
- 도메인 키: 자격증을 고르면 도메인 이름, 전체 범위면 `slug::도메인` (`src/lib/exam/domainKey.ts`). 같은 도메인 이름이 여러 자격증에 있어서다.
- 연습 모드의 "정답 확인"은 기록하지 않는다. 마지막 제출(`gradeExam`)에서 한 번만 기록해 오답이 복습 큐에 두 번 들어가지 않게 한다.
- 코드 리뷰 에이전트 MEDIUM 2건 수정: 전체 범위 재시도 뒤 숨은 도메인 필터가 남던 문제, 결과 화면에서 오류가 안 보이던 문제.

### #38 설계 메모
- 사용자 의견(2026-10-29): "이어보기는 있는데 페이지 들어가지면 스크롤이 항상 맨 위라 어디까지 봤는지 알 수 없음". #34 는 일부러 자동 스크롤을 안 하고 버튼만 띄웠는데, 그 버튼이 눈에 안 띄었다. 자동 이동 + 되돌리기("처음부터")로 바꿨다.
- 자동 이동 안 함: 진행 10% 미만·95% 초과, 목차 등 `#소제목` 링크로 진입, 이미 200px 넘게 내려가 있음.
- 홈·허브 카드는 `sessionStorage` 표시(`markResumeIntent`)로 구분해 `#소제목`에서 구간 안 자리까지 맞춘다.
- 광고 칸이 늦게 자리 잡는 경우를 위해 0.7초 뒤 한 번 더 맞추되, 그 전에 스크롤·터치·키 입력이 있으면 취소한다.
- 실측(로컬 dev, Playwright, SAA W1D2): 390px·1440px 모두 다시 열기·허브 카드 진입이 저장 위치와 같은 scrollY.
- 한계: 위치는 브라우저(localStorage)에만 있다. 폰 ↔ PC 이어 보기는 안 된다. 하려면 로그인 사용자용 서버 저장(운영 DB 테이블 추가, 마이그레이션은 사용자가 실행)이 필요하다.

## 3. 확인 방법과 남은 것

- 로컬에는 `.env`(DB)가 없어 로그인 화면을 못 띄운다. #37 화면은 가짜 API 를 붙인 임시 미리보기 페이지로 390·1440px 을 확인하고 지웠다. 운영 로그인 확인은 사용자가 한다.
- `src/lib/auditStyle.test.ts` 는 main 에서도 실패한다(SyntaxError, 이번 작업과 무관). 따로 고쳐야 한다.
- `npm run build` 뒤에는 `git checkout -- src/data` 로 생성된 데이터 변경을 되돌린다.
