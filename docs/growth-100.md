## 애드센스 (11-10)

**결과**: 11-08 신청 → `juganlab.com` "주의 필요 · 가치가 별로 없는 콘텐츠". ads.txt 는 "승인됨"(루트·cert 모두 `pub-8773257530258678`, 정상).

**원인 판단**: 애드센스에 등록된 사이트는 루트 `juganlab.com` 이다. 루트는 한 페이지(본문 약 1,500자: 서비스 카드 1개, 한 줄 일지 7개, 원칙 3개)뿐이고 콘텐츠 링크는 cert 하나, `robots.txt`·`sitemap.xml`·`/about` 은 404 였다. 검토자가 cert 까지 봤는지는 알 수 없다 — cert 의 같은 틀 노트 750여 개도 "대량 생성"으로 보였을 수 있어 루트만 고친다고 통과를 장담하지 못한다.
- 방문자 수는 공식 요건이 아니다. 다만 색인·외부 링크가 적으면 가치 근거를 찾기 어렵다 → 색인 문제와 원인이 같다(신뢰도).
- 루트를 cert 로 리다이렉트하는 안은 기각: 애드센스가 리다이렉트 대상을 심사하는지 확인 못 했고 "사이트 접근 불가"가 될 위험.
- cert 만 따로 신청하는 안도 불가: 2023년부터 애드센스 사이트 목록은 루트 도메인만 받는다(공식). 자세한 건 `docs/growth/adsense-gsc-guide.md`.

**대응 순서**
1. 루트를 글이 있는 사이트로 — juganlab-hub PR #1 (11-11 머지·배포). 머지 전 결정 4가지와 답:
   - 구독제 글: 접은 이유 → "아직 아무도 모르는데 구독부터 요구하면 첫 방문부터 막힌다". 글에 반영.
   - 글 두 편에 GSC 숫자(색인 107 등) 공개 → 유지.
   - AI 작성 표시 → 따로 쓰지 않음(목록·소개의 "저장소 기록 기반"만).
   - 일지 "핵심 정리 카드" 날짜 → 10-14 에서 09-01 항목으로 옮김(`48b3816`).
2. 외부 링크 — PR #54 초안을 사용자가 게시. GitHub 저장소 설명·웹사이트 칸·README 정리를 Show GN 보다 먼저.

4. 루트 배포 뒤 GSC 에 `juganlab.com` **도메인 속성**(Namecheap TXT, 메일 영향 없음) 등록·사이트맵 제출 → 글 페이지 크롤 확인(1~2주) → 애드센스 재검토 요청. 고친 것 없이 재신청하지 않는다.

**DNS(11-10 판단)**: 지금은 옮기지 않는다. Namecheap 기본 DNS 자체는 문제가 아니고 2% 오류로 색인 832개 미색인을 설명할 수 없다. 또 `juganlab.com` 메일이 Namecheap 메일 전달(eforward MX + SPF)이라 DNS 를 옮기면 메일 전달을 새로 만들어야 한다. 11-20 크롤링 통계에서 DNS 오류가 늘거나 호스트 상태 경고가 뜨면 그때 Cloudflare(DNS 전용 + Email Routing)로.

**빙 웹마스터**: 등록 권장(GSC 가져오기). 빙 색인은 DuckDuckGo·ChatGPT 검색·Copilot 에도 쓰인다.
