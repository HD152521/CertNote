# 가입자 100명 (2026-11-09 ~ 12-09)

사용자가 맡긴 목표: 가입자 24명 → 100명, 구글 색인 정상화. 가입자 수는 운영 DB 기준이라 사용자가 주마다 알려 준다.

## 시작 상태 (11-09)

- 기술 SEO는 이미 갖춰져 있다. 사이트맵 908 URL, 페이지마다 canonical, Course·Article JSON-LD, robots 는 로그인 전용 경로만 막는다. GSC·네이버 소유 확인 파일도 있다.
- 미국 웹 검색으로 `cert.juganlab.com` 을 찾으면 아무것도 안 나온다. 색인 상태는 GSC 를 봐야 안다.
- 전환 구멍: 노트·실습은 로그인 없이 다 보이는데, 가입해야 쓰는 모의고사(`/exam`)로 가는 링크가 자격증 허브에 없었다. SQLD 모의고사 100문항은 있는데 닿을 길이 없었다.
- 일정: SQLD 63회 시험 11-14(토). 다음 접수는 2027-02 예상(공지 확인 필요). 이번 주가 SQLD 수요의 정점이다.
