# Day 5 - D-Day 마무리: 시험 구성, 시간 배분, 시나리오 분해 전략

## 📌 핵심 정리

- DEA-C01 은 65문항(채점 50 + 비채점 15), 130분, 100~1,000점 척도에서 720점이 합격선이다. 도메인 비중은 34/26/22/18% 다.
- 문항당 약 2분이다. 1차 통과 90분, 표시한 문항 검토 30분, 최종 확인 10분으로 나누고 한 문항에 3분 넘게 머물지 않는다.
- 무응답은 오답으로 채점되고 찍어서 틀려도 감점은 없다. 빈 답을 남기지 않는다.
- 시나리오는 질문 → 제약 키워드 → 오답 소거 → 제약 최적화 순으로 분해한다. 복수 응답은 요구한 개수를 정확히 고른다.
- D-Day 는 새 학습 대신 번역표(Day 4)·오답 노트 복습과 컨디션 관리에 쓴다. 불합격하면 14일 뒤 재응시할 수 있다.

## 시험 구성 한눈에

마지막 날이다. 새로운 지식을 욱여넣기보다, 시험장에서 실력을 그대로 발휘하도록 **시험 구성·시간 운용·문제 분해**를 정리한다. DEA-C01 은 지식의 깊이보다 "요구사항을 올바른 서비스로 번역하는 속도와 침착함"이 합격을 가른다.

| 항목 | 내용 |
|------|------|
| 문항 수 | 65문항 (채점 50 + 비채점 15) |
| 시간 | 130분 |
| 합격 점수 | 720점 / 1000점 (100~1000 척도) |
| 문항 유형 | 객관식(보기 4개 중 정답 1개), 복수 응답(보기 5개 이상 중 정답 2개 이상) |
| 도메인 1 (수집·변환) | 34% |
| 도메인 2 (스토어 관리) | 26% |
| 도메인 3 (운영·지원) | 22% |
| 도메인 4 (보안·거버넌스) | 18% |
| 응시료 | 150 USD |
| 응시 언어 | 영어, 한국어, 일본어, 중국어 간체 |
| 응시 방식 | Pearson VUE 시험 센터 또는 온라인 감독 시험 |
| 자격 유효 기간 | 3년 |

> 💡 **관련 이론**: 비채점 15문항은 어느 것인지 표시되지 않는다. 따라서 "어려운 문항은 점수에 안 들어갈지 모른다"고 가정하지 말고 모든 문항을 동일하게 대하되, 막히면 표시 후 넘어간다.

## 점수는 어떻게 매겨지나

시험 가이드가 밝힌 채점 규칙은 다섯 가지다. 규칙을 알면 시험 중에 무엇을 걱정하지 않아도 되는지가 정해진다.

| 규칙 | 내용 | 시험장에서의 의미 |
|------|------|------|
| 척도 점수 | 결과는 100~1,000 의 척도 점수로 보고된다. 시험 폼마다 난이도가 조금씩 달라 그 차이를 보정하려는 것이다 | 720점이 "정답률 72%"를 뜻하지는 않는다. 정답 개수로 합격을 역산하려 하지 않는다 |
| 보상 채점 | 도메인(섹션)별 합격선이 없고 전체 점수만 본다 | 약한 도메인을 강한 도메인으로 메울 수 있다 |
| 비채점 문항 | 15문항은 향후 출제를 위한 통계 수집용이며 표시되지 않는다 | 낯설고 지나치게 어려운 문항에 흔들리지 않는다 |
| 무응답 | 답하지 않은 문항은 오답으로 채점된다 | 빈 답을 남기지 않는다 |
| 추측 | 틀려도 감점이 없다 | 모르면 소거 후 찍는다 |

- 성적표에는 도메인별 성취 수준이 표로 나올 수 있다. 도메인마다 문항 수가 달라 문항이 적은 도메인의 평가는 흔들리기 쉬우므로, 시험 가이드도 섹션별 피드백은 신중하게 해석하라고 적는다.
- 도메인 비중을 채점 문항 50개에 곱하면 대략 17·13·11·9문항이다. 도메인 1·2 가 30문항 안팎이므로 마지막 복습 시간도 이 비율로 나눈다.

## 시간 배분 전략

- **총 130분 / 65문항 = 문항당 약 2분.** 단순 매핑 문제는 30~60초에 끝내 어려운 문항에 시간을 비축한다.
- **1차 통과(약 90분)**: 빠르게 풀고, 막히는 문항은 "검토 표시(flag)" 후 즉시 다음으로. 한 문항에 3분 이상 붙잡히지 않기.
- **2차 검토(약 30분)**: 표시한 문항을 다시 풀고 확신이 선 것부터 확정.
- **3차 여유(약 10분)**: 복수응답 문항의 "정확히 N개 선택" 조건 재확인, 빈 답 없는지 점검.

> 💡 **관련 이론**: 빈 답은 점수를 받을 수 없으므로 모르는 문항도 반드시 한 개는 찍는다. 시간이 부족할 위험이 있으면, 막판에 미응답 문항부터 일괄로 가장 그럴듯한 보기를 채우는 것이 기대 점수를 높인다.

- 표시는 **잠정 답을 고른 뒤에** 붙인다. 답 없이 표시만 해 두면 시간이 모자랄 때 그 문항이 그대로 무응답이 된다.
- 2차 검토에서 답을 바꾸는 기준을 미리 정해 둔다. 지문에서 놓친 조건을 새로 찾았을 때만 바꾸고, 막연한 불안으로는 바꾸지 않는다.

## 시나리오 문제 분해 4단계

긴 문제 앞에서 당황하지 않는 방법이다.

1. **질문 문장 먼저 읽기**: "가장 비용 효율적인", "최소 운영 부담으로", "실시간으로"가 진짜 채점 기준이다.
2. **제약 키워드 밑줄**: 서버리스/실시간/배치/비용/보안·암호화/최소 코드.
3. **오답 2개 소거**: 서비스 목적이 명백히 어긋나는 보기 제거(예: 분석 SQL에 DynamoDB).
4. **제약 최적화 선택**: 남은 둘 중 제약을 가장 잘 만족하는 쪽. "가능"이 아니라 "가장 적합".

```text
예) "초당 수만 건 스트리밍을 최소 운영으로 S3 Parquet 적재"
  질문 기준 → 최소 운영(서버리스)
  키워드   → 스트리밍 / 무관리 적재 / S3
  소거     → 상시 EMR, EC2 cron (운영 부담)
  선택     → Data Firehose (버퍼링·변환·자동 배달)
```

## 복수응답 문항 주의

- "다음 중 **두 가지**를 고르시오" 같은 조건을 정확히 지킨다. 시험 가이드는 부분 점수를 언급하지 않으므로, 요구한 개수를 모두 맞혀야 점수가 된다고 보고 준비한다.
- 보기 각각을 독립적으로 참/거짓 판단한 뒤 조합한다.
- 요구가 둘이면 정답도 요구마다 하나씩 대응하는 경우가 많다. "컬럼 접근 통제 + 복호화 감사"라면 Lake Formation 과 SSE-KMS 처럼 서로 다른 요구를 채우는 두 보기를 고르고, 같은 요구를 중복해서 채우는 두 보기는 의심한다.

## 시험 가이드 1.1 판에서 달라진 것

시험 가이드는 2025년 12월 12일에 1.1 판으로 개정됐다. 개정 내용은 공개 후 약 한 달 뒤부터 시험에 반영된다고 안내되어 있다. 오래된 기출 요약만 본 수험생이 낯설게 느낄 항목이다.

| 구분 | 내용 |
|------|------|
| 새로 추가된 기술 항목 | 데이터 처리에 LLM 통합, 오픈 테이블 포맷(Apache Iceberg) 관리, 벡터 인덱스 유형(HNSW·IVF), 벡터화 개념(Amazon Bedrock 지식 기반), 비즈니스 데이터 카탈로그(Amazon SageMaker Catalog), SageMaker Unified Studio 의 도메인·프로젝트, 거버넌스 프레임워크와 데이터 공유 패턴 |
| 범위에 추가된 서비스 | Amazon Aurora, Amazon Q, Amazon Bedrock, Amazon Kendra, AWS Data Exchange, Amazon S3 Tables |
| 범위에서 빠진 서비스 | AWS Cloud9, AWS CodeCommit, AWS Schema Conversion Tool(목록에서는 빠졌지만 스키마 변환 기술 항목의 예시로는 여전히 언급된다) |
| 삭제된 기술 항목 | 없음(기존 지식 항목이 기술 항목으로 합쳐졌다) |

- 벡터 관련 새 항목은 "설명한다(Describe)"로 적혀 있다. 벡터 인덱스를 튜닝하는 법이 아니라 HNSW 와 IVF 가 무엇이 다른지, Iceberg 가 왜 필요한지를 한 문장으로 말할 수 있으면 된다(Day 1 의 표 참고).
- 시험 가이드가 **범위 밖**이라고 밝힌 직무도 있다. ML 모델의 학습·추론 수행, 특정 프로그래밍 언어의 문법 지식, 데이터에서 비즈니스 결론을 끌어내는 일이다. 코드가 나오더라도 문법이 아니라 그 코드가 하는 일을 묻는다.

## 도메인별 마지막 점검표

아래 문장을 소리 내어 완성할 수 있으면 그 줄은 통과다. 막히는 줄만 해당 주차로 되돌아간다.

```text
[도메인 1 — 수집·변환]
□ Streams 와 Firehose 를 가르는 한 단어는? (→ 직접 소비·재처리)
□ 핫 샤드의 원인과 유일한 근본 해결은? (→ 키 쏠림, 파티션 키 재설계)
□ 북마크가 동작하기 위한 세 조건은? (→ Enable, transformation_ctx, job.commit())
□ 북마크와 CDC 의 차이는? (→ 새 행만 / UPDATE·DELETE 까지)
□ Lambda 로 못 하는 변환의 기준은? (→ 15분 초과)
□ Glue 대신 EMR 을 고르는 단서 세 가지는? (→ 대규모, 세밀 튜닝·스팟, 기존 Spark/Hive)
□ Step Functions 와 MWAA 를 가르는 단서는? (→ 기존 Airflow 자산)

[도메인 2 — 스토어 관리]
□ Athena 가 느리거나 비쌀 때 고치는 네 가지는? (→ 포맷, 압축, 파티션, 파일 크기)
□ DISTKEY 와 SORTKEY 가 각각 줄이는 것은? (→ 셔플 / 스캔)
□ Spectrum 과 페더레이션 쿼리의 대상은? (→ S3 / 운영 DB)
□ 파티션 프로젝션의 제약은? (→ Athena 전용)
□ S3 클래스별 최소 보관 기간은? (→ IA 30일, Glacier 90일, Deep Archive 180일)
□ Iceberg 가 해결하는 것은? (→ 레이크에서의 ACID·행 단위 갱신·시간 여행)

[도메인 3 — 운영·지원]
□ 알림 / 원인 추적 / 호출자 추적에 쓰는 도구는? (→ Alarm / Logs Insights / CloudTrail)
□ 적재 전에 불량 데이터를 막는 장치는? (→ ETL 잡 안의 Glue Data Quality)
□ 재시도를 여러 계층에 걸면 생기는 일은? (→ 곱해진다. 한 계층에만 둔다)
□ 재실행해도 중복이 안 생기게 하는 원칙은? (→ 멱등성: 덮어쓰기·MERGE)
□ 프로비저닝과 서버리스 중 종일 일정한 부하에 유리한 쪽은? (→ 프로비저닝)

[도메인 4 — 보안·거버넌스]
□ IAM / Lake Formation / KMS 가 각각 지키는 것은? (→ API·리소스 / 테이블·컬럼·행 / 키)
□ SSE-KMS 를 고르는 단서는? (→ 키 통제·교체·감사)
□ 계정 간 공유에서 AWS 관리형 키가 안 되는 이유는? (→ 키 정책을 바꿀 수 없다)
□ S3 객체 수준 접근 기록을 남기려면? (→ CloudTrail 데이터 이벤트)
□ Macie 와 GuardDuty 의 차이는? (→ 민감 데이터 발견 / 위협 탐지)
□ 자격 증명 자동 교체는? (→ Secrets Manager)
```

## 응시 절차와 정책

시험 내용만큼 절차를 몰라 손해 보는 경우가 있다. AWS 자격증 정책 페이지 기준이다.

| 항목 | 내용 |
|------|------|
| 일정 변경·취소 | 예약 시각 24시간 전까지 가능하고, 한 예약은 두 번까지만 변경할 수 있다. 24시간 이내에 취소하면 응시료를 돌려받지 못한다 |
| ESL +30 | 영어가 모국어가 아닌 응시자가 **영어로** 응시할 때 30분을 더 받는 편의 제도. 시험 등록 **전에** 한 번 신청해 두면 이후 등록에 적용된다. 한국어로 응시하면 해당하지 않는다 |
| 신분증 | 정부 발급 신분증이 필요하다. 온라인과 시험 센터의 요건이 다르므로 예약 안내에서 확인한다 |
| 결과 통지 | 시험 종료 후 영업일 기준 5일 이내에 AWS 자격증 계정에 게시된다 |
| 불합격 시 | 14일(달력 기준)을 기다린 뒤 재응시할 수 있다. 횟수 제한은 없지만 매번 응시료 전액을 낸다 |

- 한국어 응시와 영어 응시(+30분) 중 무엇이 유리한지는 사람마다 다르다. 한국어 번역 지문이 어색하게 느껴지면 서비스 이름과 기능 용어는 영어 원문을 떠올려 대조한다.
- 온라인 감독 시험은 시작 전에 응시 환경을 확인하는 절차가 있다. 접속 안내에 적힌 시각보다 여유 있게 들어가고, 책상 위를 미리 비워 둔다.

## D-Day 컨디션 체크리스트

- 시험 전날: 새 개념 학습 금지, 번역표(Day 4)와 오답 노트만 가볍게 복습.
- 신분증·예약 시간·시험 센터(또는 온라인 프록터 환경) 확인.
- 온라인 응시면 책상 정리·웹캠·네트워크 사전 점검.
- 충분한 수면. 시험 중에는 첫 막힘에 흔들리지 말고 페이스 유지.

합격선(720)은 만점이 아닌 "충분히 안다"를 증명하는 선이다. 1~2문항을 완벽히 풀려고 페이스를 잃기보다, 확실한 문항을 빠짐없이 확보하는 것이 전체 점수에 더 유리하다.

## 시험 중 흔들릴 때의 규칙

미리 정해 둔 규칙이 있으면 시험 중에 판단에 쓰는 힘을 아낄 수 있다.

| 상황 | 규칙 |
|------|------|
| 처음 보는 서비스 이름이 보기에 있다 | 아는 보기 셋을 먼저 판정한다. 셋이 모두 조건을 어길 때만 모르는 보기를 고른다 |
| 처음 보는 주제의 문항이 연달아 나온다 | 비채점 문항일 수 있다. 잠정 답을 고르고 넘어간다 |
| 두 보기가 모두 맞아 보인다 | 질문 문장의 한정어를 다시 읽는다. 대개 운영 부담이나 비용에서 갈린다 |
| 한 문항에 3분이 지났다 | 지금 가장 그럴듯한 보기를 고르고 표시한 뒤 넘어간다 |
| 중간 점검에서 5문항 넘게 뒤처졌다 | 다음 20문항은 긴 지문을 질문 문장부터 읽고 2분에서 끊는다 |
| 종료 5분 전 미응답이 남았다 | 지문을 읽지 말고 남은 문항부터 모두 답을 채운다 |
| 2차 검토에서 답을 바꾸고 싶다 | 놓친 조건을 찾았을 때만 바꾼다 |

10주 동안 쌓은 것은 서비스 목록이 아니라 "요구사항을 읽고 조건에 맞는 설계를 고르는 순서"다. 그 순서대로 65문항을 풀면 된다.

## 📖 용어

- **척도 점수(scaled score)** : 시험 폼마다 다른 난이도를 보정해 같은 기준으로 환산한 점수. 정답률과 일치하지 않는다.
- **보상 채점** : 영역별 합격선 없이 전체 점수로만 합격을 정하는 방식.
- **비채점 문항** : 점수에 반영되지 않는 통계 수집용 문항. 수험자는 어느 문항인지 알 수 없다.
- **복수 응답** : 보기 다섯 개 이상에서 정답을 둘 이상 고르는 문항 유형.
- **검토 표시(flag)** : 나중에 다시 보려고 문항에 붙이는 표시.
- **온라인 감독 시험** : 감독관이 웹캠과 화면 공유로 지켜보는 가운데 자기 장소에서 치르는 시험.
- **ESL +30** : 비영어권 응시자가 영어로 시험을 볼 때 신청할 수 있는 30분 연장 편의 제도.
- **시험 가이드** : AWS 가 공개하는 공식 출제 범위 문서. 도메인 비중과 기술 항목, 범위 안팎의 서비스가 적혀 있다.

**문제 1.** DEA-C01 시험의 구성으로 옳은 것은?

A) 100문항, 180분, 합격 600점  
B) 40문항, 90분, 합격 800점  
C) 65문항(채점 50 + 비채점 15), 130분, 합격 720점  
D) 75문항, 120분, 합격 700점  

**정답: C**  
해설: DEA-C01은 총 65문항(채점 50, 비채점 15)을 130분 동안 풀며 1000점 척도에서 720점이 합격선이다. 나머지는 실제 구성과 다르다.

**문제 2.** 시험 중 한 문항에서 4분째 고민하고 있다. 가장 바람직한 행동은?

A) 답을 찾을 때까지 계속 머문다  
B) 그 문항을 비워 둔다  
C) 남은 문항을 모두 같은 보기로 찍는다  
D) 잠정 답을 고르고 검토 표시 후 다음 문항으로 넘어간다  

**정답: D**  
해설: 문항당 평균 2분 페이스를 지키려면 막히는 문항은 잠정 답을 표시하고 넘어간 뒤 2차 검토에서 다시 본다. 무한정 머물면 쉬운 문항을 놓치고, 비워 두면 회수 기회를 잃는다.

**문제 3.** "다음 중 두 가지를 고르시오"라는 복수응답 문항에서 한 가지만 확신할 때 가장 적절한 대응은?

A) 한 가지만 선택해 제출한다  
B) 나머지 보기들을 독립적으로 참/거짓 판단해 가장 타당한 두 번째를 함께 고른다  
C) 무조건 세 개를 고른다  
D) 그 문항을 비운다  

**정답: B**

**문제 4.** 긴 시나리오 문제를 가장 효율적으로 분해하는 순서로 옳은 것은?

A) 질문(마지막 문장) 먼저 → 제약 키워드 추출 → 명백한 오답 소거 → 제약 최적화 선택  
B) 본문을 처음부터 끝까지 정독한 뒤 보기를 본다  
C) 보기를 먼저 외운다  
D) 가장 긴 보기를 정답으로 고른다  

**정답: A**  
해설: 질문을 먼저 읽어 채점 기준(비용·운영·실시간 등)을 파악하고, 제약 키워드로 오답을 소거한 뒤 제약을 가장 잘 만족하는 보기를 고르는 것이 시간 효율과 정확도를 높인다. 보기 길이는 정답과 무관하다.

**문제 5.** 시험 종료 5분 전 미응답 문항이 3개 남았다. 가장 합리적인 행동은?

A) 시간이 없으니 그대로 제출한다  
B) 한 문항만 신중히 풀고 나머지는 비운다  
C) 남은 문항에 가장 그럴듯한 보기를 골라 모두 답을 채운다  
D) 이미 푼 답을 모두 지운다  

**정답: C**  
해설: 빈 답은 확정 오답이므로 시간이 부족해도 미응답 문항은 가장 그럴듯한 보기로 모두 채워 기대 점수를 높인다. 비워 두거나 기존 답을 지우는 것은 점수를 잃는 행동이다.
