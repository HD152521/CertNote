# Day 5 - 최종 오답·암기카드 총정리와 시험 당일 전략 (70일 마무리)

## 📌 핵심 정리

- 마지막 날은 새 내용을 더하지 않는다. **시험 직전에 다시 볼 암기카드**와 **당일 시간·멘탈 전략**만 남긴다.
- 합격을 가르는 것은 모르는 문제가 아니라 **아는 문제를 실수로 틀리지 않는 것**이다.
- 시험이 시작되면 **포트표·시그널·런레벨을 여백에 먼저 적고** 문제를 푼다. 긴장으로 기억이 흐려지기 전에 꺼내 놓는 것이다.
- 시간은 **2-pass**로 쓴다 — 아는 것부터 빠르게 한 바퀴, 그다음 별표 문제 집중. 한 문제에 1분 이상 매달리지 않는다.
- 함정 3종: **부정 발문**("옳지 않은 것은")에 밑줄, **극단 표현**("항상·반드시·절대")은 오답 의심, **2차 단답은 철자·옵션이 정확**해야 한다.
- 답안 밀림은 합격을 통째로 날린다. 5문제마다 번호와 마킹을 대조하고 제출 전 전체를 재확인한다.

## 암기카드 1: 절대 틀리면 안 되는 포트표

- 시험 시작 직후 시험지 여백에 적어두면 좋은 핵심 포트다.

| 포트 | 서비스 | 포트 | 서비스 |
|------|--------|------|--------|
| 20/21 | FTP | 110 | POP3 |
| 22 | SSH | 123 | NTP |
| 23 | Telnet | 143 | IMAP |
| 25 | SMTP | 443 | HTTPS |
| 53 | DNS | 514 | Syslog |
| 80 | HTTP | 111 | rpcbind(NFS) |

> 💡 **여백 활용**: 시험 시작하면 떨려서 기억이 안 날 수 있다. **포트표·시그널·런레벨을 먼저 여백에 적고** 문제를 풀면 실수가 줄어든다.

## 암기카드 2: 시그널과 런레벨

| 시그널 | 이름 | 의미 |
|--------|------|------|
| 1 | SIGHUP | 설정 재로드 |
| 2 | SIGINT | Ctrl+C |
| 9 | SIGKILL | 강제 종료(무시 불가) |
| 15 | SIGTERM | 정상 종료(기본) |

| 런레벨 | 타깃 | 의미 |
|--------|------|------|
| 0 | poweroff | 종료 |
| 1 | rescue | 단일 사용자 |
| 3 | multi-user | 텍스트 다중 |
| 5 | graphical | GUI 다중 |
| 6 | reboot | 재부팅 |

## 암기카드 3: 권한·특수권한 빠른 표

| 권한 | 숫자 | 권한 | 숫자 |
|------|------|------|------|
| r(읽기) | 4 | SetUID | 4000 |
| w(쓰기) | 2 | SetGID | 2000 |
| x(실행) | 1 | Sticky | 1000 |

- umask는 파일 666·디렉터리 777에서 뺀다. `umask 022` → 파일 644, 디렉터리 755.

> ⚠️ **자주 틀리는 짝**: SetUID(4000)=소유자 권한, SetGID(2000)=그룹 권한·디렉터리 상속, Sticky(1000)=`/tmp` 삭제 제한. 숫자와 의미를 헷갈리지 말 것.

## 암기카드 4: 설정 파일 경로 모음

| 파일 | 용도 |
|------|------|
| `/etc/passwd` | 계정 정보 |
| `/etc/shadow` | 암호화된 비밀번호 |
| `/etc/group` | 그룹 정보 |
| `/etc/fstab` | 마운트 정보 |
| `/etc/resolv.conf` | DNS 서버 |
| `/etc/hosts` | 로컬 호스트 매핑 |
| `/etc/ssh/sshd_config` | SSH 서버 |
| `/etc/crontab` | 시스템 cron |
| `/var/log/messages` | 일반 시스템 로그 |
| `/var/log/secure` | 인증·보안 로그 |

> 🔍 **passwd 7필드**: 사용자명:비밀번호(x):UID:GID:설명:홈:셸. 비밀번호 자리의 `x`는 실제 암호가 `/etc/shadow`에 있다는 표시다.

## 암기카드 5: 헷갈리는 명령 쌍 정리

| 구분 | A | B |
|------|---|---|
| 사용량 | `df`(파일시스템) | `du`(디렉터리) |
| 패키지 | `rpm`(의존성 수동) | `yum`(자동 해결) |
| 서비스 | `start`(지금) | `enable`(부팅 시) |
| 메일 | `POP3`(내려받음) | `IMAP`(동기화) |
| FTP | 액티브(서버→클라) | 패시브(클라→서버) |
| 권한 표시 | `s`(x 있음) | `S`(x 없음) |

> 📚 **시험 빈출 포인트**: 이 6쌍은 "둘 중 무엇인가"를 묻는 형태로 매년 나온다. 차이의 핵심 키워드 한 단어씩만 확실히 잡으면 된다.

## 시험 당일 전략 1: 시간 배분

- 1차 필기는 과목별 문항 수가 정해져 있다.
- **모르는 문제에 매달리지 말 것** — 한 문제에 1분 이상 쓰지 말고 별표 후 넘어간다.
- 전체를 한 바퀴 돈 뒤 별표 문제로 돌아온다.

> 💡 **2-pass 전략**: 1차 통과(아는 것 빠르게) → 2차 통과(별표 집중). 시간 압박에서 아는 문제를 못 풀고 끝나는 최악의 상황을 막는다.

## 시험 당일 전략 2: 함정 회피와 멘탈

- **부정 발문 주의**: "옳지 않은 것은?", "아닌 것은?"에 밑줄. 긍정으로 착각해 정답을 뒤집는 실수가 가장 흔하다.
- **극단 표현 의심**: "항상", "반드시", "절대"가 들어간 보기는 오답일 확률이 높다.
- **2차 실기 철자**: 단답형은 철자·옵션이 정확해야 한다. `useradd`를 `usradd`로 쓰면 0점. 평소 손으로 써보며 연습.

> ⚠️ **마킹 점검**: 답안 밀림은 합격을 통째로 날린다. 5문제마다 번호와 마킹을 대조하고, 제출 전 전체를 다시 확인한다.

Week 1의 리눅스 역사부터 오늘의 시험 전략까지 70일을 완주했다. 이제 필요한 건 새 지식이 아니라 **차분함과 점검**이다. 암기카드를 시험 전날 한 번, 입실 전 한 번 훑고 침착하게 2-pass로 풀자. 합격을 기원한다.

## 📖 용어

- **암기카드** : 시험 직전과 시작 직후에 꺼내 볼 최소 단위 요약. 포트·시그널·런레벨·권한 숫자가 핵심이다.
- **rpcbind(111)** : RPC 서비스의 포트를 알려 주는 포트 매퍼. NFS가 동작하려면 반드시 살아 있어야 한다.
- **SIGKILL(9)** : 프로세스가 무시할 수 없는 강제 종료 시그널. `kill`의 기본값은 SIGTERM(15)이다.
- **런레벨 ↔ 타깃** : 옛 SysV의 시스템 상태 번호와 systemd 단위의 대응. 3=multi-user, 5=graphical.
- **SetUID / SetGID / Sticky** : 소유자 권한으로 실행(4000) / 그룹 권한·상속(2000) / 자기 파일만 삭제(1000).
- **소문자 s vs 대문자 S** : 실행 권한(x)이 함께 있는 정상 상태 / x 없이 특수 비트만 켜진 충돌 상태.
- **df vs du** : 파일시스템 단위 사용량 / 디렉터리·파일 단위 사용량. 역할을 바꿔 외우는 실수가 잦다.
- **의존성 자동 해결** : `yum`·`apt`가 저장소에서 필요한 패키지를 함께 받아 주는 성질. `rpm`·`dpkg`에는 없다.
- **2-pass 전략** : 아는 문제부터 빠르게 한 바퀴 돈 뒤 표시해 둔 문제만 다시 푸는 시간 배분법.
- **부정 발문** : "옳지 않은 것은?"처럼 틀린 보기를 고르게 하는 질문. 밑줄을 그어 착각을 막는다.
- **답안 밀림** : 문항 번호와 마킹 위치가 어긋나는 사고. 주기적 대조와 제출 전 재확인으로 예방한다.

**문제 1.** `/etc/passwd` 파일의 필드 구성으로 옳은 것은?

A) 사용자명:UID:GID:비밀번호:홈:셸:설명
B) 사용자명:비밀번호:UID:GID:설명:홈:셸
C) 사용자명:비밀번호:GID:UID:홈:셸:설명
D) UID:사용자명:비밀번호:GID:설명:셸:홈

**정답: B**
해설: passwd 7필드는 사용자명:비밀번호(x):UID:GID:설명(GECOS):홈디렉터리:로그인셸 순이다. 비밀번호 자리의 x는 실제 해시가 shadow에 있음을 뜻한다.

**문제 2.** 디스크 전체 파일시스템의 사용량을 확인하는 명령과 특정 디렉터리의 사용량을 확인하는 명령을 올바르게 짝지은 것은?

A) `du` - `df`
B) `df` - `du`
C) `df` - `fsck`
D) `du` - `mount`

**정답: B**
해설: `df`는 파일시스템 단위 전체 사용량, `du`는 디렉터리/파일 단위 사용량을 보여준다. 둘의 역할을 바꿔 외우는 실수가 잦다.

**문제 3.** 시험에서 "옳지 않은 것은?"이라는 부정 발문을 만났을 때 가장 적절한 대응은?

A) 옳은 보기 하나를 빠르게 골라 답한다
B) 발문에 밑줄을 긋고 틀린 보기를 찾는다
C) 가장 긴 보기를 정답으로 한다
D) 첫 번째 보기를 우선 검토한다

**정답: B**
해설: 부정 발문은 긍정으로 착각하기 쉬워 발문에 밑줄을 긋고 '틀린' 보기를 찾아야 한다. 가장 흔한 실수가 옳은 것을 골라 오답 처리되는 경우다.

**문제 4.** 실행 권한(x)이 없는 파일에 SetUID가 설정되었을 때 권한 표시에 나타나는 문자는?

A) 소문자 `s`
B) 대문자 `S`
C) 소문자 `t`
D) 대문자 `T`

**정답: B**
해설: 실행 권한이 있으면 소문자 `s`, 없으면 대문자 `S`로 표시된다(권한 충돌 표시). Sticky의 경우도 x가 있으면 `t`, 없으면 `T`다.

**문제 5.** 패키지 설치 시 의존성을 자동으로 해결하지 못해 누락 시 에러만 출력하는 도구는?

A) `yum`
B) `dnf`
C) `rpm`
D) `apt`

**정답: C**
해설: `rpm`(및 dpkg)은 저수준 도구로 의존성을 자동 해결하지 못한다. `yum`/`dnf`/`apt`는 저장소에서 의존 패키지를 받아 자동 해결한다.

**문제 6.** 시험 시작 직후 권장되는 행동으로 가장 적절한 것은?

A) 가장 어려워 보이는 문제부터 푼다
B) 포트·시그널·런레벨 등 암기 내용을 여백에 먼저 적는다

D) 마지막 문제부터 역순으로 푼다

**문제 7.** 서비스를 '지금 시작'하는 명령과 '부팅 시 자동 시작'하는 명령을 올바르게 구분한 것은?

A) `start` - 부팅 시 자동 / `enable` - 지금 시작
B) `start` - 지금 시작 / `enable` - 부팅 시 자동
C) 둘 다 지금 시작한다
D) 둘 다 부팅 시에만 시작한다

**정답: B**
해설: `systemctl start`는 즉시 시작, `systemctl enable`은 부팅 시 자동 시작을 설정한다. 둘은 독립적이라 둘 다 필요하면 `enable --now`를 쓴다.

**문제 8.** 2차 실기 단답형 시험에서 가장 주의해야 할 점으로 적절한 것은?

A) 명령의 의미만 맞으면 철자는 틀려도 된다
B) 명령어·옵션의 철자를 정확히 기술해야 한다
