# Day 5 - Week 2 종합 복습: 명령행에서 살아남기 위한 모든 것

이번 주는 리눅스를 명령행으로 다루기 위한 가장 기초적이면서도 가장 중요한 도구들을 배웠습니다. 파일을 옮기고 찾는 법(Day 1), 텍스트를 자르고 거르고 변형하는 법(Day 2), `vi`로 파일을 편집하는 법(Day 3), 파일을 묶고 압축하며 도움말을 활용하는 법(Day 4)까지, 이 네 가지는 따로 떨어진 지식이 아니라 실제 작업에서 끊임없이 맞물려 돌아갑니다. 예를 들어 로그 파일을 `find`로 찾고, `grep`으로 에러를 거르고, `awk`로 통계를 내고, `tar`로 백업하고, `vi`로 설정을 수정하는 일이 하루에도 수십 번 일어납니다. 오늘은 한 주의 내용을 주제별로 압축 정리하고, 실전 감각을 위한 연습 문제로 마무리합니다.

> 💡 **개념: 명령행 사고방식**
> 명령행의 핵심은 "작은 도구를 파이프로 연결한다"는 것입니다. 하나의 거대한 프로그램이 모든 것을 처리하는 대신, `find`, `grep`, `sort`, `awk` 같은 단순한 도구들을 `|`로 이어 복잡한 작업을 조립합니다. 이번 주에 배운 명령들은 모두 이 조립의 부품입니다.

## Day 1 핵심 정리: 파일과 디렉터리

경로에는 루트(`/`)부터 시작하는 **절대 경로**와 현재 위치 기준의 **상대 경로**가 있습니다. 상대 경로의 핵심 기호는 `.`(현재), `..`(상위), `~`(홈)입니다.

주요 명령을 한눈에 정리하면 다음과 같습니다.

| 명령 | 역할 | 자주 쓰는 옵션 |
|------|------|----------------|
| `pwd` | 현재 위치 출력 | `-P`(실제 경로) |
| `cd` | 디렉터리 이동 | `cd -`(직전 위치) |
| `ls` | 목록 보기 | `-l`, `-a`, `-h`, `-ltr` |
| `mkdir` | 디렉터리 생성 | `-p`(중간 경로 생성) |
| `rmdir` | 빈 디렉터리 삭제 | `-p` |
| `touch` | 빈 파일/시간 갱신 | `-t`(시각 지정) |
| `cp` | 복사 | `-r`, `-p`, `-i` |
| `mv` | 이동/이름변경 | `-i`, `-f` |
| `rm` | 삭제 | `-r`, `-f` |
| `find` | 실시간 파일 검색 | `-name`, `-type`, `-exec` |
| `locate` | DB 기반 검색 | `-i`, updatedb |
| `which` | 명령 경로 찾기 | `-a` |

> ⚠️ **함정 모음: Day 1**
> 디렉터리 복사는 `cp -r`이 필수(없으면 오류), `rmdir`은 빈 디렉터리만 삭제, `gzip`이 아니라 `rm`에는 휴지통이 없음, `locate`는 DB 기반이라 최신 파일을 못 찾을 수 있음. `find`의 `-exec`에서 `{}`는 파일명 치환, `\;`는 명령의 끝.

## Day 2 핵심 정리: 텍스트 처리

텍스트 처리의 출발점은 표준 스트림과 파이프(`|`)입니다. 한 명령의 출력을 다음 명령의 입력으로 연결합니다.

| 명령 | 역할 | 핵심 사용법 |
|------|------|-------------|
| `cat` | 전체 출력/이어붙이기 | `-n`(행 번호) |
| `head`/`tail` | 처음/끝 일부 | `-n`, `tail -f` |
| `grep` | 패턴 검색 | `-i`, `-v`, `-r`, `-n`, `-c` |
| `sed` | 스트림 편집 | `s/old/new/g`, `-i` |
| `awk` | 필드 처리 | `{print $1}`, `-F`, `NR`, `NF` |
| `sort` | 정렬 | `-n`, `-r`, `-k`, `-u` |
| `uniq` | 중복 제거 | `-c`, `-d` (sort와 짝) |
| `cut` | 열 추출 | `-d`, `-f`, `-c` |
| `tr` | 문자 변환 | `-d`, `-s` |
| `wc` | 개수 세기 | `-l`, `-w`, `-c` |

정규표현식의 핵심 메타문자는 `.`(아무 한 글자), `*`(앞 문자 0회 이상), `^`(행 시작), `$`(행 끝), `[]`(문자 집합)입니다. 확장 정규식(ERE, `grep -E`)에서는 `+`, `?`, `|`, `()`가 백슬래시 없이 동작합니다.

> 🔍 **더 깊이: 자주 쓰는 파이프라인 패턴**
> "에러 개수 세기"는 `grep error log | wc -l`, "고유 IP 빈도"는 `awk '{print $1}' log | sort | uniq -c | sort -nr`, "특정 사용자 정보"는 `grep user /etc/passwd | cut -d: -f1,6`. 이런 조합이 손에 익으면 로그 분석이 즐거워집니다.

## Day 3 핵심 정리: vi/vim

`vi`의 세 가지 모드를 기억하세요. **명령 모드**(시작 기본, 이동/편집), **입력 모드**(`i`/`a`/`o`로 진입, 텍스트 입력), **마지막 행 모드**(`:`로 진입, 저장/종료/치환).

| 작업 | 명령 |
|------|------|
| 입력 시작 | `i`(앞), `a`(뒤), `o`(아래 행), `O`(위 행) |
| 이동 | `h j k l`, `w`/`b`, `0`/`$`, `gg`/`G` |
| 삭제 | `x`(글자), `dd`(행), `dw`(단어) |
| 복사/붙여넣기 | `yy`(복사), `p`/`P`(붙여넣기) |
| 취소/반복 | `u`(취소), `Ctrl+r`(재실행), `.`(반복) |
| 검색 | `/패턴`, `?패턴`, `n`/`N` |
| 저장/종료 | `:w`, `:q`, `:q!`, `:wq`, `:x`, `ZZ` |
| 치환 | `:%s/old/new/g` |

> ⚠️ **함정 모음: Day 3**
> `a`는 커서 뒤 입력(`i`는 앞), `o`는 아래 행/`O`는 위 행, `:wq`는 항상 저장/`:x`와 `ZZ`는 변경 시에만 저장, `:%s`의 `%`는 파일 전체. `nano`의 저장은 `Ctrl+O`, 종료는 `Ctrl+X`.

## Day 4 핵심 정리: 압축과 도움말

**아카이브(묶기)**와 **압축(크기 줄이기)**은 다른 작업입니다. `tar`는 묶고, `gzip`/`bzip2`/`xz`는 압축합니다.

| 작업 | 명령 |
|------|------|
| 묶고 gzip 압축 | `tar czvf x.tar.gz dir/` |
| gzip 아카이브 풀기 | `tar xzvf x.tar.gz` |
| 내용 목록 보기 | `tar tzvf x.tar.gz` |
| 특정 위치에 풀기 | `tar xvf x.tar -C /tmp` |
| 단일 파일 압축 | `gzip file`(원본 삭제), `-k`로 보존 |
| zip 압축 | `zip -r x.zip dir/` |

`tar` 옵션: `c`(생성), `x`(풀기), `t`(목록), `v`(자세히), `f`(파일명), `z`(gzip), `j`(bzip2), `J`(xz). 압축률은 xz > bzip2 > gzip 순입니다.

도움말은 `man`(섹션별 매뉴얼), `info`(상세 문서), `whatis`(한 줄 요약, `man -f`), `apropos`(키워드 검색, `man -k`)로 활용합니다. 매뉴얼 섹션 1은 명령, 5는 파일 형식, 8은 시스템 관리입니다.

> 📚 **유래/사례: 한 주를 관통하는 유닉스 철학**
> 이번 주 도구들은 모두 켄 톰슨과 데니스 리치가 1970년대에 세운 유닉스 철학을 따릅니다. "하나의 일을 잘하라", "프로그램이 함께 동작하게 하라", "텍스트 스트림을 다뤄라". `grep`도 `sort`도 `tar`도 각자 한 가지만 잘하고, 파이프로 협력합니다. 이 설계가 50년이 지나도 유효한 이유입니다.

## 직접 쳐보기: 종합 실습

배운 모든 것을 한 흐름으로 엮은 종합 실습입니다.

```bash
# 1. 작업 공간과 로그 데이터 생성
mkdir -p ~/review/logs
cd ~/review
cat > logs/access.log << 'EOF'
192.168.0.1 GET /index 200
192.168.0.2 POST /login 401
192.168.0.1 GET /about 200
192.168.0.3 GET /index 500
192.168.0.2 GET /index 200
EOF

# 2. find로 로그 찾기
find . -name "*.log" -type f

# 3. grep + wc로 에러(401, 500) 세기
grep -E "401|500" logs/access.log | wc -l

# 4. awk + sort + uniq로 IP 접속 빈도 순위
awk '{print $1}' logs/access.log | sort | uniq -c | sort -nr

# 5. sed로 상태코드 200을 OK로 표시
sed 's/ 200$/ OK/' logs/access.log

# 6. tar로 백업하고 확인
tar czvf backup.tar.gz logs/
tar tzvf backup.tar.gz

# 7. 도움말로 확인
whatis awk

# 8. 정리
cd ~
rm -rf ~/review
```

이 실습을 막힘없이 해낼 수 있다면 Week 2의 목표는 충분히 달성한 것입니다. 각 단계에서 옵션을 바꿔 실험해 보면 이해가 더 깊어집니다.

**문제 1.** 현재 디렉터리 이하에서 `.conf`로 끝나는 일반 파일만 찾는 명령은?

A) `find . -type d -name "*.conf"`
B) `find . -type f -name "*.conf"`
C) `locate -type f "*.conf"`
D) `grep -r "*.conf" .`

**정답: B**
해설: `-type f`로 일반 파일을 한정하고 `-name "*.conf"`로 패턴을 지정합니다. A는 디렉터리만 찾고, C는 `locate`에 없는 `-type` 옵션을 썼으며, D는 파일 내용 검색이라 목적이 다릅니다.

**문제 2.** `sed -i 's/dev/prod/g' config.txt`의 동작으로 옳은 것은?

A) 화면에만 결과를 출력하고 원본은 그대로 둔다
B) 각 행의 첫 dev만 prod로 바꾼다
C) 파일 전체의 모든 dev를 prod로 바꾸고 원본 파일을 직접 수정한다
D) dev를 포함한 행을 삭제한다

**정답: C**
해설: `-i`는 원본 파일을 직접 수정(in-place)하고, `g`는 각 행의 모든 일치를 치환합니다. A는 `-i`가 없을 때, B는 `g`가 없을 때이며, D는 `d` 명령에 대한 설명입니다.

**문제 3.** `awk -F: '{print $1}' /etc/passwd`의 결과는?

A) 각 행 전체를 출력한다
B) 콜론으로 구분된 첫 번째 필드(사용자명)를 출력한다
C) 콜론으로 구분된 마지막 필드를 출력한다
D) 행 번호를 출력한다

**정답: B**
해설: `-F:`로 구분자를 콜론으로 지정하고 `$1`로 첫 필드를 출력하므로 사용자명이 나옵니다. 행 전체는 `$0`, 마지막 필드는 `$NF`, 행 번호는 `NR`입니다.

**문제 4.** `vi`에서 현재 커서가 있는 행 아래에 새 행을 만들며 입력 모드로 진입하는 키는?

A) `o`
B) `O`
C) `a`
D) `i`

**정답: A**
해설: 소문자 `o`(open)는 현재 행 아래에 새 행을 열고 입력 모드로 들어갑니다. 대문자 `O`는 위 행을, `a`는 커서 뒤에서, `i`는 커서 앞에서 입력을 시작합니다.

**문제 5.** `vi`에서 변경된 경우에만 저장하고 종료하여, 변경이 없으면 타임스탬프를 보존하는 명령은?

A) `:wq`
B) `:q!`
C) `:x`
D) `:w`

**정답: C**
해설: `:x`(및 `ZZ`)는 변경된 경우에만 저장하므로 변경이 없으면 파일을 건드리지 않아 타임스탬프가 보존됩니다. `:wq`는 변경 여부와 무관하게 항상 저장(타임스탬프 갱신), `:q!`는 저장 없이 강제 종료, `:w`는 저장만 합니다.

**문제 6.** 디렉터리 `data`를 bzip2 압축 형식의 아카이브로 묶는 명령은?

A) `tar czvf data.tar.bz2 data/`
B) `tar cjvf data.tar.bz2 data/`
C) `tar cJvf data.tar.bz2 data/`
D) `tar xjvf data.tar.bz2 data/`

**정답: B**
해설: bzip2 압축은 `j` 옵션입니다(`c`=생성, `v`=자세히, `f`=파일명). `z`(A)는 gzip, `J`(C)는 xz, `x`(D)는 풀기 동작입니다.

**문제 7.** `gzip -k report.txt`를 실행했을 때의 결과로 옳은 것은?

A) report.txt가 삭제되고 report.txt.gz만 남는다
B) report.txt와 report.txt.gz가 모두 존재한다
C) report.txt.bz2가 생성된다
D) 압축되지 않고 오류가 발생한다

**정답: B**
해설: `-k`(keep)는 원본을 유지하므로 원본과 압축 파일이 모두 남습니다. `-k` 없이 실행하면 A처럼 원본이 삭제됩니다. C는 bzip2의 확장자, D는 잘못된 설명입니다.

**문제 8.** "network"라는 키워드를 매뉴얼 설명에서 검색해 관련 명령을 찾는 것과 동일한 명령 쌍은?

A) `whatis network` = `man -f network`
B) `apropos network` = `man -k network`
C) `info network` = `man network`
D) `which network` = `whereis network`

**정답: B**
해설: `apropos`는 키워드로 매뉴얼을 검색하며 `man -k`와 동일합니다. `whatis`는 정확한 이름 매칭(`man -f`와 동일)이므로 A는 검색이 아닌 요약입니다. C와 D는 검색과 무관합니다.

**문제 8.** 로그 파일에서 IP별 접속 횟수를 많은 순으로 정렬해 보려고 한다. 가장 적절한 파이프라인은?

A) `awk '{print $1}' log | uniq -c`
B) `awk '{print $1}' log | sort | uniq -c | sort -nr`
C) `grep $1 log | sort -n`
D) `cut -f1 log | uniq`

**정답: B**
해설: 먼저 첫 필드(IP)를 추출하고, `sort`로 같은 IP를 모은 뒤 `uniq -c`로 개수를 세고, 다시 `sort -nr`로 빈도 내림차순 정렬합니다. A는 정렬 없이 `uniq`를 써서 흩어진 중복을 놓치고, C와 D는 목적에 맞지 않습니다.

**문제 9.** 다음 중 `cp` 명령으로 디렉터리 전체를 권한과 타임스탬프까지 보존하며 복사하는 옵션 조합으로 가장 적절한 것은?

A) `cp -i dir1 dir2`
B) `cp -r dir1 dir2`
C) `cp -rp dir1 dir2`
D) `cp -f dir1 dir2`

**정답: C**
해설: 디렉터리 복사에는 `-r`(재귀)이 필요하고, 권한·타임스탬프 보존에는 `-p`(preserve)가 필요하므로 `-rp`를 함께 써야 합니다. A는 보존이 안 되고 재귀도 없으며, B는 보존이 빠졌고, D는 강제 옵션일 뿐입니다.

**문제 10.** `grep -E "^[0-9]+$" data.txt`가 찾아내는 행은?

A) 숫자로 시작하는 모든 행
B) 숫자로 끝나는 모든 행
C) 숫자만으로 이루어진 행
D) 숫자를 포함한 모든 행

**정답: C**
해설: `^`는 행 시작, `$`는 행 끝, `[0-9]+`는 숫자 1개 이상을 의미합니다. 시작부터 끝까지 숫자뿐인 행, 즉 숫자만으로 이루어진 행을 찾습니다. A는 `^[0-9]`만, B는 `[0-9]$`만, D는 `[0-9]`만 있을 때입니다.

**문제 11.** `tar`로 만든 `backup.tar.gz`의 내용을 풀지 않고 목록만 확인하는 명령은?

A) `tar xzvf backup.tar.gz`
B) `tar czvf backup.tar.gz`
C) `tar tzvf backup.tar.gz`
D) `tar rzvf backup.tar.gz`

**정답: C**
해설: `t`(list) 옵션은 아카이브를 풀지 않고 내용 목록만 보여줍니다. `x`는 풀기, `c`는 생성, `r`은 아카이브에 파일 추가입니다.
