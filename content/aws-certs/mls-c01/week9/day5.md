# Day 5 - Week 9 종합 복습: 평가와 디버깅

## 📌 핵심 정리

- Week 9는 도메인 3(Modeling)의 마지막 단계 — **"이 모델이 정말 좋은가, 어디서 어떻게 틀리는가"**에 숫자와 도구로 답하는 법이다.
- 관통하는 원칙은 하나: **지표는 비즈니스 비용의 번역이다.** FP가 비싸면 정밀도, FN이 비싸면 재현율, 불균형이면 정확도를 버리고 F1/PR-AUC로 간다.
- **모델 비교와 임계값 결정은 분리된 단계**다. AUC로 잘 순위 매기는 모델을 먼저 고르고, 그 위에서 비용에 맞는 컷을 사후에 정한다.
- 회귀는 "큰 실수 치명적=RMSE, 이상치 잡음=MAE, 규모 다른 비교=MAPE", 잔차 플롯으로 편향·비선형·이분산을 읽는다.
- 도구 분담은 **"기울기/손실/과적합/텐서=Debugger, 공정성/집단/SHAP=Clarify"**, 튜닝 방향은 **분류 Maximize / 오차 Minimize**.

## 한 장 요약: 평가에서 디버깅까지

알고리즘을 고르고(Week 6) 학습·튜닝했다면(Week 7~8), 남은 것은 채점과 수리다. 나흘 치를 하나의 흐름으로 엮으면 다음과 같다.

```text
[학습된 모델]
   │
   ├─ 1) 문제 유형으로 지표군 결정
   │     분류 → 정확도/정밀도/재현율/F1, ROC-AUC, PR-AUC
   │     회귀 → RMSE/MAE/MAPE/R²
   │
   ├─ 2) 비즈니스 비용으로 지표·임계값 선택
   │     FN 치명 → 재현율 / 임계값 ↓
   │     FP 치명 → 정밀도 / 임계값 ↑
   │     불균형  → F1, PR-AUC (정확도 금지)
   │
   ├─ 3) 곡선으로 트레이드오프 분석
   │     ROC/AUC = 변별력, 모델 비교
   │     PR 곡선 = 극단 불균형에서 정직
   │
   └─ 4) 디버깅·편향·오류 분석
         Debugger = 학습 과정(기울기/손실/과적합)
         Clarify  = 편향(집단 공정성) + SHAP(설명)
         오류 분석 = 큰 오류 버킷부터 개선
```

## 분류 지표 총정리 (Day 1~2)

| 지표 | 공식 분모 | 언제 | 대표 시나리오 | 이 지표의 맹점 |
|---|---|---|---|---|
| **Accuracy** | 전체 | 균형 데이터만, 불균형 금지 | 클래스가 5:5에 가까운 문제 | 다수 클래스만 찍어도 높게 나온다 |
| **Precision** | TP+FP (예측 양성) | FP 비용 클 때 | 스팸 분류(정상 메일 차단이 치명) | 놓친 양성(FN)을 전혀 보지 않는다 |
| **Recall** | TP+FN (실제 양성) | FN 비용 클 때 | 질병·사기 탐지(놓치면 치명) | 전부 양성으로 찍으면 1.0이 된다 |
| **F1** | 조화평균 | FP·FN 균형, 불균형 데이터 | 비용 비대칭이 명시되지 않은 불균형 | 어느 쪽이 더 비싼지는 못 반영한다 |
| **ROC-AUC** | TPR vs FPR 면적 | 임계값 무관 모델 비교 | 후보 모델 여러 개 중 고르기 | 극단 불균형에서 낙관적으로 보인다 |
| **PR-AUC** | Precision vs Recall 면적 | 극단 불균형에서 정직 | 양성 0.5%인 사기 탐지 | 모델 간 절대 비교가 데이터 의존적 |

### 임계값과 곡선

| 항목 | ROC 곡선 | PR 곡선 |
|---|---|---|
| 축 | TPR vs FPR | Precision vs Recall |
| 분모에 TN 포함 | 포함(FPR에) | **미포함** |
| 강점 | 일반적인 모델 변별력 비교 | 극단 불균형에서 성능을 부풀리지 않음 |
| 불균형일 때 | 다수 음성 덕에 FPR이 작게 보여 낙관적 | 소수 양성만 보므로 정직 |

- **임계값 ↓** → 재현율 ↑, 정밀도 ↓ (놓치지 않는 대신 오경보 증가)
- **임계값 ↑** → 정밀도 ↑, 재현율 ↓ (확실할 때만 양성, 대신 놓침 증가)

### 혼동행렬 위에서 지표가 어디를 보는가

```
                 실제 양성        실제 음성
             ┌───────────────┬───────────────┐
  예측 양성  │      TP       │      FP       │  ← Precision = TP / (TP+FP)
             ├───────────────┼───────────────┤
  예측 음성  │      FN       │      TN       │
             └───────────────┴───────────────┘
                     ↑
             Recall = TP / (TP+FN)

  Accuracy = (TP+TN) / 전체   ← TN이 압도적이면 전부 여기서 부풀려진다
  ROC의 FPR = FP / (FP+TN)    ← 분모에 TN 포함 → 불균형에서 작아 보인다
  PR 곡선                     ← TN을 아예 쓰지 않는다 → 정직
```

### 비용 비대칭 → 지표·임계값

| 비즈니스 상황 | 더 비싼 실수 | 우선 지표 | 임계값 |
|---|---|---|---|
| 질병 진단 스크리닝 | FN (놓친 환자) | 재현율 | 낮춘다 |
| 사기 거래 탐지 | FN (통과된 사기) | 재현율 / PR-AUC | 낮춘다 |
| 스팸 분류 | FP (차단된 정상 메일) | 정밀도 | 높인다 |
| 자동 계정 정지 | FP (억울한 정지) | 정밀도 | 높인다 |
| 비용 비대칭이 명시되지 않음 | 판단 불가 | F1 | 기본값에서 시작 |

> ⚠️ **함정**: "불균형"이라는 단어가 지문에 보이면 **정확도 보기는 오답**이다. 사기 0.5% 문제에서 전부 정상으로 찍어도 정확도는 99.5%다.

## 회귀 지표 총정리 (Day 3)

| 지표 | 성격 | 단서 | 주의 |
|---|---|---|---|
| **MAE** | 이상치 강건, 단위 직관 | 이상치를 무시하고 싶을 때 | 큰 오차를 특별 취급하지 않는다 |
| **RMSE** | 큰 오차에 민감(제곱) | 큰 실수가 치명적, 빌트인 기본 | 이상치 몇 개에 크게 흔들린다 |
| **MAPE** | 스케일 무관 상대오차 | 규모가 다른 항목 비교 | **y=0 근처에서 발산** |
| **R²** | 평균 대비 설명력 | 설명력을 한 숫자로 보고 | **음수면 평균선보다 못함** |

### 잔차 플롯 읽기

| 잔차 모양 | 진단 | 다음 조치 |
|---|---|---|
| 무작위 산포 | 양호 | 그대로 진행 |
| U자 곡선 | 비선형 미포착 | 피처 변환·비선형 모델 재검토 |
| 깔때기 모양 | 이분산성 | 타깃 로그 변환, 가중 회귀 검토 |
| 한쪽으로 치우침 | 계통적 편향 | 누락 피처·절편 문제 점검 |

> 💡 **개념**: RMSE와 MAE의 **격차 자체가 정보**다. 두 값이 비슷하면 오차가 고르게 퍼져 있고, RMSE가 훨씬 크면 소수의 큰 오차(이상치성 잔차)가 존재한다는 신호다.

## 디버깅·편향 (Day 4)

| 키워드 | 서비스 | 무엇을 하나 |
|---|---|---|
| 기울기 소실/폭발, 과적합, 텐서 캡처, 잡 자동중단 | **Debugger** | 학습 중 텐서를 규칙으로 감시, 망가진 잡 중단 |
| 집단 공정성, Disparate Impact, 학습 전/후 편향 | **Clarify (편향)** | 데이터·예측의 집단 간 치우침 측정 |
| SHAP, 피처 기여도, 예측 설명 | **Clarify (설명)** | 전역 중요도 + 개별 예측의 이유 |
| 오류가 특정 구간에만 몰림 | **오류 분석**(사람) | 버킷 그룹핑 후 큰 버킷부터 개선 |

> 💡 **관련 이론**: 이번 주를 관통하는 단일 원칙은 **"지표는 비즈니스 비용의 번역이다"**이다. 같은 모델이라도 FP가 비싸면 정밀도를, FN이 비싸면 재현율을 보고, 불균형이면 정확도를 버리고 F1/PR-AUC로 간다. 회귀에서도 큰 실수가 치명적이면 RMSE, 이상치가 잡음이면 MAE다. 지표 선택 문제는 거의 항상 "이 비즈니스에서 어떤 실수가 더 비싼가"로 환원된다.

## 지표 선택 의사결정 트리

```
문제 유형은?
├─ 회귀
│   ├─ 큰 오차가 특히 치명적인가?
│   │     ├─ 예   → RMSE (튜닝 방향 Minimize)
│   │     └─ 아니오 ↓
│   ├─ 이상치를 잡음으로 보고 무시하고 싶은가? → MAE
│   ├─ 규모가 다른 항목을 함께 비교하나?     → MAPE (y=0 주의)
│   └─ 설명력을 한 숫자로 보고하나?          → R² (음수 = 평균만도 못함)
│
└─ 분류
    ├─ 클래스가 심하게 불균형한가?
    │     ├─ 예 → 정확도 금지. F1 / PR-AUC
    │     └─ 아니오 ↓
    ├─ FN이 더 비싼가? (질병·사기를 놓치면 치명)
    │     └─ 예 → 재현율 우선 + 임계값 ↓
    ├─ FP가 더 비싼가? (정상을 차단하면 치명)
    │     └─ 예 → 정밀도 우선 + 임계값 ↑
    ├─ 비용 비대칭이 불분명한가?              → F1
    └─ 여러 모델을 임계값과 무관하게 비교하나? → ROC-AUC
          └─ 그 다음 운영 컷은 곡선 위에서 기대비용 최소 지점으로
```

## 가장 헷갈리는 비교

| 비교 | 핵심 차이 |
|------|------|
| 정밀도 vs 재현율 | FP 줄이기 / FN 줄이기 |
| Accuracy vs F1 | 균형 데이터 / 불균형 데이터 |
| ROC vs PR 곡선 | 일반 / 극단 불균형(분모에 TN 없음) |
| AUC vs 임계값 선택 | 모델 비교 / 운영 컷 결정 |
| RMSE vs MAE | 큰 오차 강조 / 이상치 강건 |
| R² 양수 vs 음수 | 평균보다 나음 / 평균보다 못함 |
| Debugger vs Clarify | 학습 과정 건강 / 편향·설명 |
| Clarify 편향 vs SHAP | 집단 공정성 / 예측 설명 |
| 분류 튜닝 vs 회귀 튜닝 | Maximize(F1/AUC) / Minimize(RMSE) |

> 💡 **관련 이론**: 모델 평가와 임계값 결정은 분리된 단계다. AUC 같은 임계값-무관 지표로 "잘 순위 매기는 모델"을 먼저 고르고, 그 위에서 FP/FN 비용에 맞는 임계값을 사후에 정한다. 이 분리 덕분에 비용 구조가 바뀌어도 모델 재학습 없이 임계값만 조정하면 된다. 시험에서 "모델 비교=AUC, 운영 컷=곡선 위 한 점"으로 갈리는 이유가 여기 있다.

## 자주 틀리는 함정

| 틀리는 방식 | 왜 틀리나 | 올바른 판단 |
|---|---|---|
| 불균형 데이터를 정확도로 평가 | 다수 클래스만 맞혀도 높다 | F1 / PR-AUC / 정밀도·재현율 병행 |
| 극단 불균형에서 ROC-AUC만 신뢰 | FPR 분모의 TN이 커서 낙관적 | PR 곡선을 함께 본다 |
| 임계값을 먼저 고정하고 모델 선택 | 비용 구조를 무시한 순서 | AUC로 모델 → 임계값은 사후 결정 |
| 재현율만 끝까지 올리기 | 전부 양성으로 찍으면 1.0 | 정밀도와의 트레이드오프를 함께 |
| RMSE 하나만 보고 모델 확정 | 이상치 몇 개에 흔들린다 | MAE와 격차, 잔차 플롯을 함께 |
| R²가 낮으면 항상 데이터 탓 | 음수는 모델이 평균만도 못하다는 뜻 | 피처·모델 자체를 재검토 |
| 회귀 튜닝 목적 지표를 Maximize | 오차는 작을수록 좋다 | RMSE는 **Minimize** |
| 학습 실패를 Clarify로 진단 | Clarify는 편향·설명 담당 | 기울기·손실은 **Debugger** |
| 집단 공정성을 Debugger로 측정 | Debugger는 학습 과정 담당 | 공정성은 **Clarify 편향 지표** |

## 자가 점검 질문

답을 머릿속으로 떠올려 보자.

1. 사기 0.5%인데 정확도 99.5%를 신뢰 못 하는 이유는? → **다 정상으로 찍어도 99.5%, 불균형**
2. 질병을 놓치는 FN이 치명적일 때 우선 지표는? → **재현율(Recall)**
3. 극단 불균형에서 ROC보다 정직한 곡선은? → **PR 곡선(PR-AUC)**
4. RMSE가 MAE보다 훨씬 크면? → **큰 오차(이상치성 잔차) 존재**
5. R²가 음수면? → **평균선 예측보다도 못함**
6. 잔차 플롯이 U자 곡선이면? → **비선형성 미포착, 피처/모델 재검토**
7. 기울기 소실을 학습 중 자동 탐지하는 서비스는? → **SageMaker Debugger**
8. 집단 간 예측 공정성 측정은? → **SageMaker Clarify (편향 지표)**
9. 개별 예측의 피처 기여도 설명은? → **Clarify의 SHAP 값**
10. 회귀 튜닝 목적 지표의 방향은? → **Minimize (RMSE 등)**

## 지문 단서 → 정답 매핑

| 지문 단서 | 고를 답 | 이유 |
|---|---|---|
| "클래스가 95:5로 불균형하다" | F1 / PR-AUC (정확도 보기는 오답) | 다수 클래스만 맞혀도 정확도가 높다 |
| "질병/사기를 놓치면 안 된다" | 재현율 우선, 임계값 ↓ | FN 비용이 지배적 |
| "정상 사용자를 차단하면 안 된다" | 정밀도 우선, 임계값 ↑ | FP 비용이 지배적 |
| "어느 쪽 실수가 더 비싼지 언급 없음 + 불균형" | F1 | 정밀도·재현율의 조화평균 |
| "여러 후보 모델을 변별력으로 비교" | ROC-AUC | 임계값과 무관한 순위 품질 |
| "운영 임계값을 정해야 한다" | 곡선 위 기대비용 최소 지점 | 평가와 컷 결정은 분리된 단계 |
| "큰 예측 실수가 치명적이다" | RMSE | 제곱으로 큰 오차를 증폭 |
| "이상치가 많아 지표가 요동친다" | MAE | 절대오차라 이상치에 강건 |
| "규모가 다른 매장·품목을 함께 비교" | MAPE | 상대오차라 스케일 무관 (y=0 주의) |
| "모델이 평균 예측보다도 못하다" | R² 음수 | 기준선(평균)을 못 이긴 상태 |
| "잔차가 깔때기 모양이다" | 이분산성 | 분산이 예측값에 따라 변함 |
| "기울기 소실·과적합을 학습 중 잡고 싶다" | SageMaker Debugger | 학습 텐서를 규칙으로 감시 |
| "성별 집단 간 승인률 차이를 보고" | Clarify 편향 지표(DPPL·DI) | 예측의 집단 공정성 |
| "이 한 건의 결정 이유를 설명" | Clarify SHAP(국소) | 개별 예측의 피처 기여도 |
| "특정 구간에서만 성능이 급락" | 오류 분석 → 큰 버킷부터 개선 | 전면 재학습·무작위 튜닝은 비효율 |
| "Automatic Model Tuning의 목적 지표 방향" | RMSE=Minimize, F1/AUC=Maximize | 오차는 작게, 성능은 크게 |

## 📖 용어

- **TP / FP / FN / TN** : 맞게 잡은 양성 / 헛짚은 양성 / 놓친 양성 / 맞게 거른 음성. 모든 분류 지표의 재료다.
- **정밀도(Precision)** : 양성이라고 부른 것 중 실제 양성 비율. "헛짚지 않았는가".
- **재현율(Recall)** : 실제 양성 중 잡아낸 비율. "놓치지 않았는가".
- **F1 점수** : 정밀도와 재현율의 조화평균. 한쪽만 높아서는 점수가 오르지 않는다.
- **ROC-AUC** : 임계값을 전부 훑었을 때의 TPR-FPR 곡선 아래 면적. 모델의 순위 매기기 능력.
- **PR-AUC** : 정밀도-재현율 곡선 아래 면적. 음성이 압도적으로 많을 때 ROC보다 정직하다.
- **임계값(threshold)** : 확률 출력을 양성/음성으로 가르는 컷. 낮추면 재현율, 높이면 정밀도가 오른다.
- **MAPE** : 오차를 실제값으로 나눈 상대오차의 평균. 규모가 다른 항목을 비교할 때 쓰되 y=0을 조심한다.
- **R² (결정계수)** : "평균으로 찍기"보다 얼마나 나은지를 나타내는 값. 음수면 평균만도 못하다는 뜻이다.
- **잔차(residual)** : 실제값 − 예측값. 그 패턴이 모델의 구조적 결함을 드러낸다.

A) F1 점수를 본다  
B) PR 곡선의 AUC를 본다  
C) 단순 정확도(Accuracy)만으로 판단한다  
D) 재현율과 정밀도를 함께 본다  

**정답: C**  
해설: 불균형 데이터에서 정확도는 다수 클래스만 맞혀도 높게 나와 모델 성능을 과대평가하므로 단독 판단은 부적절하다. F1(A)·PR-AUC(B)·정밀도/재현율(D)은 불균형에 적합한 지표다.

**문제 2.** 여러 후보 분류 모델을 임계값과 무관하게 변별력으로 비교한 뒤, 운영 임계값은 FP/FN 비용에 맞춰 따로 정하려 한다. 올바른 접근은?

A) 모든 모델을 임계값 0.5의 정확도로만 비교한다  
B) AUC로 모델을 고르고, 임계값은 곡선 위에서 기대비용이 최소인 지점으로 사후 결정한다  
C) 임계값을 먼저 0.9로 고정하고 모델을 고른다  
D) RMSE로 분류 모델을 비교한다  

**정답: B**  
해설: AUC는 임계값-무관 변별력 비교에 적합하고, 운영 임계값은 비용 구조에 맞춰 곡선 위에서 사후에 정하는 2단계 분리가 정석이다. 0.5 정확도(A)·임계값 선고정(C)은 비용을 무시하고, RMSE(D)는 회귀 지표다.

**문제 3.** 회귀 모델 두 개를 비교하니 모델 A는 RMSE와 MAE가 비슷하고, 모델 B는 RMSE가 MAE보다 훨씬 크다. 이로부터 추론할 수 있는 것은?

A) 모델 B에는 소수의 큰 오차(이상치성 잔차)가 있을 가능성이 높다  
B) 모델 A는 분류 모델이다  
C) 모델 B의 R²는 반드시 음수다  
D) 두 모델은 완전히 동일하다  

**정답: A**  
해설: RMSE는 큰 오차를 제곱으로 증폭하므로 RMSE-MAE 격차가 크면 소수의 큰 오차가 존재할 가능성이 높다. 지표 유형이 모델 종류를 정하지 않고(B), R² 부호는 별개이며(C), 지표가 다르므로 동일(D)하지 않다.

**문제 5.** SageMaker Automatic Model Tuning에서 목적 지표 방향(objective_type) 설정으로 올바른 것은?

A) 회귀의 validation:rmse → Maximize
