# Day 4 - 모델 평가: 지표 선택, 과적합, 교차검증, 혼동행렬

학습이 끝났다고 모델이 좋은 건 아니다. "정확도 95%"라는 숫자 하나로 모델을 판단하면 위험하다 — 사기 거래가 1%인 데이터에서는 "전부 정상"이라 찍어도 99% 정확도가 나온다. 모델 평가의 본질은 "문제에 맞는 지표"로 "일반화 성능"을 재는 것이다.

MLA-C01 시험에서 평가는 "불균형 데이터에서 어떤 지표를 쓰나", "과적합을 어떻게 진단·완화하나", "혼동행렬에서 정밀도/재현율을 계산하라" 같은 형태로 자주 나온다. 오늘은 지표 선택, 과적합/과소적합, 교차검증, 혼동행렬 네 축을 본다.

## 혼동행렬과 분류 지표

분류 평가의 출발점은 혼동행렬(confusion matrix)이다. 이진 분류 기준으로 예측과 실제를 네 칸으로 나눈다.

```
                  실제 Positive    실제 Negative
예측 Positive       TP (참양성)      FP (거짓양성)
예측 Negative       FN (거짓음성)    TN (참음성)
```

여기서 핵심 지표가 나온다.

| 지표 | 공식 | 답하는 질문 |
|------|------|------------|
| 정확도 (Accuracy) | (TP+TN)/전체 | 전체 중 맞춘 비율 |
| 정밀도 (Precision) | TP/(TP+FP) | 양성이라 한 것 중 진짜 양성 비율 |
| 재현율 (Recall) | TP/(TP+FN) | 실제 양성 중 잡아낸 비율 |
| F1 | 2·P·R/(P+R) | 정밀도·재현율의 조화평균 |

핵심 직관: **정밀도는 "거짓 경보를 줄이고 싶을 때", 재현율은 "놓치면 안 될 때"** 본다. 스팸 필터는 정상 메일을 스팸으로 잘못 거르면(FP) 곤란하니 정밀도가 중요하고, 암 진단은 환자를 놓치면(FN) 치명적이니 재현율이 중요하다.

> 💡 **관련 이론**: 정밀도와 재현율은 본질적으로 트레이드오프 관계다. 분류 임계값을 낮추면 더 많이 양성으로 분류해 재현율은 오르지만 거짓양성도 늘어 정밀도가 떨어진다. 이 곡선 전체를 보는 게 PR 곡선이고, 임계값을 바꿔가며 TPR과 FPR을 그린 게 ROC 곡선이다. AUC(곡선 아래 면적)는 "임의의 양성 샘플이 임의의 음성 샘플보다 높은 점수를 받을 확률"로, 단일 임계값에 묶이지 않은 종합 판별력을 나타낸다.

## 불균형 데이터에서 지표 선택

정확도가 위험한 이유는 클래스 불균형이다. 사기 1%, 정상 99%인 데이터에서 "전부 정상"으로 찍으면 정확도 99%지만 사기는 하나도 못 잡는 쓸모없는 모델이다.

- **불균형 데이터**: 정확도 대신 **F1, AUC(ROC), AUC-PR**, 재현율/정밀도를 본다.
- **양성이 희귀하고 놓치면 안 됨(사기·질병)**: 재현율 또는 AUC-PR 강조.
- **거짓 경보 비용이 큼(스팸)**: 정밀도 강조.

```python
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score

print(confusion_matrix(y_true, y_pred))
print(classification_report(y_true, y_pred))   # precision/recall/f1
print("AUC:", roc_auc_score(y_true, y_prob))    # 확률 기반
```

> ⚠️ **함정**: 불균형 데이터에서 "정확도 99%"를 모델이 좋다는 근거로 제시하는 보기는 함정이다. 시험에서 "사기/이상/희귀 질병" 같은 키워드가 보이면 정확도가 아니라 F1·재현율·AUC를 골라야 한다. 또한 ROC-AUC는 극심한 불균형에서 낙관적으로 보일 수 있어, 양성이 매우 희귀하면 AUC-PR(정밀도-재현율 곡선)이 더 정직하다.

## 회귀 지표

회귀(연속값 예측)는 분류와 다른 지표를 쓴다.

| 지표 | 특징 |
|------|------|
| MAE (평균절대오차) | 오차 크기 평균. 이상치에 둔감, 해석 직관적 |
| MSE / RMSE | 제곱오차. 큰 오차에 민감(이상치에 큰 페널티) |
| R² (결정계수) | 모델이 설명하는 분산 비율(1에 가까울수록 좋음) |
| MAPE | 백분율 오차. 스케일 무관 비교 |

직관: **큰 오차를 강하게 벌하고 싶으면 RMSE, 이상치 영향을 줄이고 싶으면 MAE.** 예측값이 실제값을 얼마나 설명하는지는 R².

> 💡 **관련 이론**: RMSE가 MAE보다 이상치에 민감한 건 오차를 제곱하기 때문이다. 오차 10인 한 점은 RMSE에선 100으로, MAE에선 10으로 기여한다. 그래서 큰 오차가 치명적인 문제(예: 수요 예측에서 대량 결품)는 RMSE를, 모든 오차를 균등하게 보고 싶은 문제는 MAE를 쓴다. 이는 손실함수 선택과도 직결된다 — RMSE를 줄이도록 학습하면 모델이 큰 오차를 피하는 쪽으로 치우친다.

## 과적합과 과소적합

모델 평가의 다른 축은 일반화다. 학습 데이터에만 잘 맞고 새 데이터에서 무너지면 과적합(overfitting)이다.

| 상태 | 학습 성능 | 검증/테스트 성능 | 진단 |
|------|----------|----------------|------|
| 과소적합 (underfit) | 낮음 | 낮음 | 모델이 너무 단순/덜 학습 (high bias) |
| 적합 | 높음 | 높음 | 균형 |
| 과적합 (overfit) | 매우 높음 | 낮음 | 모델이 학습 데이터를 외움 (high variance) |

진단: 학습 성능은 좋은데 검증 성능이 나쁘고 둘의 격차가 크면 **과적합**. 둘 다 나쁘면 **과소적합**.

과적합 완화:
- 더 많은 데이터, 데이터 증강
- 정규화(L1/L2), 드롭아웃
- 모델 복잡도 축소, 조기 종료(early stopping)
- 특성 수 줄이기

과소적합 완화:
- 모델 복잡도 증가, 더 오래 학습
- 더 나은 특성 추가, 정규화 완화

> 📚 **사례**: 한 팀이 이미지 분류 모델을 학습했더니 학습 정확도 99%, 검증 정확도 70%로 큰 격차가 났다. 전형적 과적합. 데이터 증강(회전·플립)과 드롭아웃을 추가하고 조기 종료를 걸자 학습 95%/검증 91%로 격차가 줄며 일반화가 좋아졌다. 교훈: 학습-검증 격차가 과적합의 핵심 신호이고, 정규화·증강·조기 종료가 표준 처방이다.

## 교차검증

검증 세트를 한 번만 나누면 그 분할의 운에 따라 평가가 흔들린다. **k-fold 교차검증**은 데이터를 k조각으로 나눠, 각 조각을 한 번씩 검증으로 쓰고 나머지로 학습한 뒤 k개 성능을 평균한다. 데이터가 적을 때 특히 안정적인 평가를 준다.

```
k=5 예시:
Fold1: [검증][학습][학습][학습][학습]
Fold2: [학습][검증][학습][학습][학습]
...    → 5번 학습/평가 후 평균
```

- **Stratified k-fold**: 각 fold가 클래스 비율을 유지 — 불균형 분류에 중요.
- **시계열 데이터**: 미래로 검증하는 time-series split(과거→미래 순서 유지)을 써야 미래 누수를 막는다. 무작위 k-fold는 시계열에 부적합.

> 💡 **관련 이론**: 교차검증의 가치는 평가 분산을 줄이는 데 있다. 한 번의 train/test 분할은 그 분할에 운이 따른 추정치(고분산)다. k-fold는 여러 분할의 평균을 내 추정의 분산을 낮추고, 데이터를 학습·검증에 모두 활용해 적은 데이터를 효율적으로 쓴다. 다만 k가 클수록 학습을 k번 반복해 비용이 늘고, 시계열처럼 순서가 의미 있는 데이터에선 무작위 분할이 미래 정보를 흘려 평가를 부풀린다는 점을 주의한다.

## 정리하며

모델 평가는 "문제에 맞는 지표"로 "일반화"를 재는 일이다. **분류**는 혼동행렬에서 정밀도(거짓경보 억제)·재현율(놓침 방지)·F1·AUC를 뽑고, 불균형 데이터에선 정확도 대신 F1·재현율·AUC를 본다. **회귀**는 RMSE(큰 오차 민감)·MAE(이상치 둔감)·R²을 쓴다. **과적합**은 학습-검증 성능 격차로 진단하고 정규화·증강·조기 종료로 완화한다. **교차검증(k-fold)**은 평가 분산을 줄이며, 불균형엔 stratified, 시계열엔 time-series split을 쓴다. 시험은 "불균형→정확도 함정", "큰 오차→RMSE", "학습-검증 격차→과적합" 패턴을 노린다.

**문제 2.** 암 검진 모델에서 실제 환자를 놓치는 것(거짓음성)이 가장 위험하다. 우선적으로 높여야 할 지표는?

A) 정밀도(Precision)  
B) 재현율(Recall)  
C) 학습 속도  
D) GPU 활용률  

**정답: B**  
해설: 재현율은 실제 양성(환자) 중 모델이 잡아낸 비율로, 놓치면 안 되는 상황(거짓음성 최소화)에서 우선시한다. A는 거짓양성을 줄이는 지표로 초점이 다르고, C·D는 평가 지표가 아니라 학습 효율·자원 관련이다.

**문제 3.** 모델의 학습 정확도는 99%인데 검증 정확도는 70%로 둘의 격차가 크다. 진단과 적절한 완화책은?

A) 과소적합이므로 모델을 더 단순하게 만든다  
B) 과적합이므로 정규화·드롭아웃·데이터 증강·조기 종료를 적용한다  
C) 정상이므로 그대로 배포한다  
D) 학습 데이터를 검증에도 그대로 쓴다  

**정답: B**  
해설: 학습 성능은 높고 검증 성능이 낮으며 격차가 큰 것은 전형적 과적합으로, 정규화·드롭아웃·증강·조기 종료로 일반화를 높인다. A는 과소적합 처방이라 방향이 반대이고, C는 일반화 실패를 무시하며, D는 데이터 누수를 일으키는 잘못된 평가다.
