# Day 3 - 프로세스의 개념과 유형

## 📌 핵심 정리

- **프로그램은 디스크에 있는 파일**, **프로세스는 실행되어 메모리에 올라간 것**이다.
- 모든 프로세스에는 **PID(자기 번호)** 와 **PPID(부모 번호)** 가 있다.
- 모든 프로세스의 조상은 **PID 1** — 예전에는 **init**, 지금은 **systemd** 다.
- **포그라운드는 화면을 붙잡고, 백그라운드는 뒤에서** 돈다. 뒤로 보내려면 명령 끝에 **`&`** 를 붙인다.
- **데몬은 배후에서 서비스를 기다리는 프로세스**다. 이름이 대개 **`d`로 끝난다** — `httpd`, `sshd`.

## 프로그램과 프로세스

| 구분 | 있는 곳 | 상태 |
|------|--------|------|
| **프로그램** | **디스크** | 실행되기 전의 **파일** |
| **프로세스** | **메모리** | **실행 중**인 상태 |

- 하나의 프로그램에서 **여러 개의 프로세스**가 만들어질 수 있다. 터미널 창을 세 개 열면 bash 프로세스가 세 개다.
- 프로세스마다 **고유한 번호(PID)** 가 붙는다.

## 부모와 자식

```text
   systemd  (PID 1)
      │  fork
      ├── sshd
      │     └── bash        ← 내가 로그인한 셸
      │           ├── vi
      │           └── ls
      └── crond
```

| 용어 | 뜻 |
|------|-----|
| **PID** | 프로세스 자신의 번호 |
| **PPID** | **부모 프로세스**의 번호 |
| **fork** | 부모가 **자신을 복제해** 자식을 만드는 것 |
| **exec** | 그 자리에서 **다른 프로그램으로 바뀌는** 것 |

- 셸에서 명령을 실행하면 **셸이 fork로 자식을 만들고 그 자식이 exec로 그 명령이 된다.**
- **PID 1은 모든 프로세스의 조상**이다. 부팅 때 커널이 가장 먼저 띄운다.

| 시기 | PID 1 |
|------|-------|
| 예전 | **init** |
| 지금 | **systemd** (또는 upstart) |

### 비정상 상태 둘

| 상태 | 무엇 |
|------|------|
| **고아(orphan) 프로세스** | **부모가 먼저 죽은** 자식. **PID 1이 입양**한다 |
| **좀비(zombie) 프로세스** | **자식은 끝났는데 부모가 종료 상태를 안 받아간** 상태 |

- **좀비는 이미 끝난 프로세스**다. CPU도 메모리도 쓰지 않고 **프로세스 목록의 자리만 차지**한다. `ps`에서 상태가 **`Z`** 로 보인다.
- 좀비는 **직접 죽일 수 없다.** 이미 죽어 있기 때문이다. **부모를 종료**하면 PID 1이 정리한다.

## 포그라운드와 백그라운드

| 구분 | 성격 |
|------|------|
| **포그라운드(foreground)** | 터미널을 **붙잡고** 실행. 끝날 때까지 다른 명령을 못 친다 |
| **백그라운드(background)** | **뒤에서** 실행. 바로 다음 명령을 칠 수 있다 |

```bash
sleep 100 &          # 처음부터 백그라운드로
jobs                 # 백그라운드 작업 목록
fg %1                # 1번 작업을 포그라운드로
bg %1                # 1번 작업을 백그라운드로
```

| 조작 | 하는 일 |
|------|--------|
| **`&`** | 명령 끝에 붙여 **백그라운드 실행** |
| **`Ctrl+Z`** | 실행 중인 작업을 **일시 정지** |
| **`Ctrl+C`** | 실행 중인 작업을 **종료** |
| **`jobs`** | 작업 목록 보기 |
| **`fg`** | 포그라운드로 전환 |
| **`bg`** | 정지된 작업을 백그라운드로 재개 |

```text
   명령 실행 ──► 포그라운드
                   │  Ctrl+Z
                   ▼
                 정지 ──bg──► 백그라운드
                   ▲                │
                   └──── fg ────────┘
```

- **`Ctrl+Z`는 정지이고 `Ctrl+C`는 종료**다. 이 둘을 바꿔 쓰면 안 된다.
- **`nohup`** 을 붙이면 터미널을 닫아도 계속 실행된다 — `nohup 명령 &`.

## 데몬 프로세스

- **백그라운드에서 요청을 기다리는 서비스 프로세스**다. 터미널에 붙어 있지 않다.
- 이름이 **`d`로 끝나는 관례**가 있다.

| 데몬 | 하는 일 |
|------|--------|
| **`httpd`** | 웹 서버 |
| **`sshd`** | 원격 접속(SSH) |
| **`crond`** | 예약 작업 |
| `syslogd` | 로그 기록 |
| `ftpd` | 파일 전송 |
| `named` | DNS |

### 데몬이 실행되는 두 방식

| 방식 | 성격 |
|------|------|
| **standalone** | **항상 메모리에 상주**하며 대기. **응답이 빠르다**. 자주 쓰이는 서비스에 적합 |
| **inetd (xinetd)** | **슈퍼 데몬**이 대신 대기하다가 요청이 오면 그때 띄운다. **메모리를 아낀다** |

- **standalone은 빠르고 메모리를 많이**, **inetd 방식은 느리지만 메모리를 아낀다.** 이 맞바꿈이 시험에 나온다.
- `inetd`를 개선한 것이 **`xinetd`** 이며 접근 제어 기능이 추가되었다.
- 요청이 잦은 웹·SSH는 standalone, 어쩌다 쓰는 telnet 같은 것은 inetd 방식에 어울린다.

> 내일은 이 프로세스를 눈으로 보고 다루는 명령 — `ps`, `top`, `kill`과 작업 예약을 다룬다.

## 📖 용어

- **프로세스** : 실행되어 메모리에 올라간 프로그램.
- **PID / PPID** : 프로세스 자신의 번호 / 부모 프로세스의 번호.
- **fork** : 부모 프로세스가 자신을 복제해 자식 프로세스를 만드는 동작.
- **고아 프로세스** : 부모가 먼저 종료된 자식 프로세스. PID 1이 입양한다.
- **좀비 프로세스** : 종료되었으나 부모가 종료 상태를 회수하지 않아 목록에 남은 프로세스.
- **포그라운드 / 백그라운드** : 터미널을 붙잡고 실행 / 뒤에서 실행.
- **데몬** : 배후에서 서비스 요청을 기다리는 프로세스. 이름이 주로 `d`로 끝난다.
- **standalone / inetd** : 데몬을 항상 상주시키는 방식 / 슈퍼 데몬이 필요할 때 띄우는 방식.

## 📝 연습 문제

**문제 1.** 다음 중 부모 프로세스가 종료 상태를 회수하지 않아 프로세스 목록에만 남아 있는 프로세스로 알맞은 것은?

A) 고아 프로세스  
B) 데몬 프로세스  
C) 좀비 프로세스  
D) 포그라운드 프로세스  

**정답: C**  
해설: 좀비 프로세스는 이미 실행이 끝났지만 부모가 종료 상태를 가져가지 않아 목록의 자리만 차지하는 상태이며 `ps`에서 상태가 `Z`로 표시됩니다. 이미 죽은 상태라 직접 종료할 수 없고 부모 프로세스를 정리해야 사라집니다. 부모가 먼저 죽은 자식은 고아 프로세스라고 합니다.

---

**문제 2.** 다음 중 리눅스에서 모든 프로세스의 조상이 되는 PID 1번 프로세스로 알맞은 것은?

A) bash  
B) kernel  
C) sshd  
D) systemd  

**정답: D**  
해설: 부팅 과정에서 커널이 가장 먼저 실행하는 프로세스가 PID 1이며 최근 배포판은 systemd를, 예전 시스템은 init을 사용합니다. 이 프로세스가 이후의 모든 프로세스를 직간접적으로 생성하며 고아 프로세스를 입양하는 역할도 맡습니다.

---

**문제 3.** 다음 중 명령을 처음부터 백그라운드로 실행하기 위해 명령 끝에 붙이는 기호로 알맞은 것은?

A) &  
B) |  
C) ;  
D) >  

**정답: A**  
해설: 명령 끝에 `&`를 붙이면 셸이 그 명령을 백그라운드로 실행하고 곧바로 프롬프트를 돌려줍니다. `|`는 파이프, `>`는 리다이렉션, `;`는 명령을 순서대로 이어 실행하는 구분자입니다.

---

**문제 4.** 다음 중 실행 중인 포그라운드 작업을 일시 정지시키는 키 조합으로 알맞은 것은?

A) Ctrl+C  
B) Ctrl+Z  
C) Ctrl+D  
D) Ctrl+R  

**정답: B**  
해설: `Ctrl+Z`는 실행 중인 작업을 정지 상태로 만들며 이후 `bg`로 백그라운드에서 재개하거나 `fg`로 다시 포그라운드로 가져올 수 있습니다. `Ctrl+C`는 작업을 종료하고, `Ctrl+D`는 입력의 끝을 알리며, `Ctrl+R`은 히스토리 검색입니다.

---

**문제 5.** 다음 중 서비스 데몬을 항상 메모리에 상주시켜 요청에 빠르게 응답하도록 하는 실행 방식으로 알맞은 것은?

A) 포그라운드 방식  
B) inetd 방식  
C) standalone 방식  
D) 배치 방식  

**정답: C**  
해설: standalone 방식은 데몬이 계속 메모리에 상주하며 대기하므로 응답이 빠르지만 메모리를 지속적으로 사용합니다. 반면 inetd 방식은 슈퍼 데몬이 대신 대기하다 요청이 올 때 해당 데몬을 띄우므로 메모리를 아끼는 대신 응답이 느립니다.
