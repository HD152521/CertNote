# Day 2 - vi 검색·치환과 다른 편집기

## 📌 핵심 정리

- 검색은 **`/패턴`(아래로) · `?패턴`(위로)**, 다음 결과는 **`n`**, 반대 방향은 **`N`** 이다.
- 치환의 기본형은 **`:s/찾을것/바꿀것/`** 이다.
- **`%`는 파일 전체, `g`는 한 줄 안의 전부**를 뜻한다. **`:%s/A/B/g`** 가 가장 많이 나온다.
- vi 설정은 **`~/.vimrc`**(개인)와 **`/etc/vimrc`**(전역)에 저장한다.
- **nano는 화면 아래에 단축키가 보이고**, **emacs는 모드가 없다**. vi만 모드를 가진다.

## 검색

| 명령 | 방향 |
|------|------|
| **`/패턴`** | 커서에서 **아래로** 검색 |
| **`?패턴`** | 커서에서 **위로** 검색 |
| **`n`** | **같은 방향**으로 다음 결과 |
| **`N`** | **반대 방향**으로 다음 결과 |

```text
   /error        아래로 error 찾기
   ?error        위로 error 찾기
   n             다음 결과
   N             반대 방향 다음 결과
```

- 검색은 **명령 모드에서** 시작한다. `/`를 누르면 화면 맨 아래에 입력줄이 나타난다.
- **`n`과 `N`의 관계**가 시험 포인트다. `N`은 "위로"가 아니라 **처음 검색한 방향의 반대**다. `?`로 검색했다면 `N`이 아래로 간다.

## 치환

```text
   :  %  s / 서울 / 부산 / g
   │  │  │    │      │     │
   │  │  │    │      │     └── g  그 줄의 모든 것
   │  │  │    │      └──────── 바꿀 문자열
   │  │  │    └─────────────── 찾을 문자열
   │  │  └──────────────────── s  substitute(치환)
   │  └─────────────────────── %  파일 전체
   └────────────────────────── :  ex 모드
```

| 명령 | 범위 |
|------|------|
| `:s/A/B/` | **커서가 있는 줄**의 **첫 번째** A만 |
| `:s/A/B/g` | **커서가 있는 줄**의 **모든** A |
| **`:%s/A/B/g`** | **파일 전체**의 **모든** A |
| `:1,10s/A/B/g` | **1~10번째 줄**의 모든 A |
| `:%s/A/B/gc` | 전체를 바꾸되 **하나씩 확인**(confirm) |

> **`%`와 `g`를 구분한다.** `%`는 **어느 줄까지**를, `g`는 **한 줄 안에서 몇 개**를 정한다. 둘 다 붙인 **`:%s/A/B/g`** 가 "파일 전체의 모든 것을 바꿔라"다.

## 자주 쓰는 설정

| 명령 | 하는 일 |
|------|--------|
| **`:set nu`** | **줄 번호 표시** |
| `:set nonu` | 줄 번호 숨기기 |
| `:set ai` | 자동 들여쓰기 (autoindent) |
| `:set ts=4` | 탭 크기 지정 (tabstop) |
| `:set ic` | 검색 시 대소문자 무시 (ignorecase) |
| `:set hlsearch` | 검색 결과 강조 |

- 이렇게 준 설정은 **편집기를 닫으면 사라진다.**
- 계속 쓰려면 설정 파일에 적는다.

| 파일 | 범위 |
|------|------|
| **`~/.vimrc`** | **개인** 설정 |
| **`/etc/vimrc`** | **전역** 설정 (모든 사용자) |
| `~/.exrc` | 예전 vi의 개인 설정 파일 |

```text
   " ~/.vimrc 예
   set nu
   set ai
   set ts=4
```

- 셸의 `.bashrc`와 같은 구조다. **`~/`로 시작하면 개인, `/etc/`면 전역**이다.

## 다른 편집기들

### nano

```text
   ^G Get Help    ^O Write Out    ^X Exit
   └ ^ 는 Ctrl 키를 뜻한다
```

| 단축키 | 하는 일 |
|-------|--------|
| **`Ctrl+O`** | **저장**(Write Out) |
| **`Ctrl+X`** | **종료**(Exit) |
| `Ctrl+W` | 검색 |
| `Ctrl+K` | 한 줄 잘라내기 |
| `Ctrl+G` | 도움말 |

- **모드가 없다.** 열면 바로 글자를 입력할 수 있다.
- **화면 아래에 단축키 목록이 항상 보인다.** 초보자에게 쉬운 이유다.
- **pico의 개선판**이며 GNU 프로젝트에서 만들었다.

### emacs

| 단축키 | 하는 일 |
|-------|--------|
| **`Ctrl+X Ctrl+S`** | 저장 |
| **`Ctrl+X Ctrl+C`** | 종료 |
| `Ctrl+G` | 명령 취소 |

- **Richard Stallman**이 만들었다. GNU 프로젝트의 편집기다.
- **모드가 없고** 대신 **Ctrl과 Meta(Alt) 조합키**로 모든 기능을 부른다.
- Lisp으로 기능을 확장할 수 있어 편집기를 넘어선 환경으로 불린다.

### 세 편집기 비교

| 구분 | **vi / vim** | **emacs** | **nano** |
|------|------------|----------|---------|
| 만든 사람 | **Bill Joy** | **Richard Stallman** | GNU (pico 개선) |
| **모드** | **있다 (3개)** | **없다** | **없다** |
| 저장 | `:w` | `Ctrl+X Ctrl+S` | `Ctrl+O` |
| 종료 | `:q` | `Ctrl+X Ctrl+C` | `Ctrl+X` |
| 설정 파일 | `~/.vimrc` | `~/.emacs` | `~/.nanorc` |
| 성격 | 어디에나 있다 | 확장성이 크다 | 배우기 쉽다 |

> **"모드가 있는 편집기는?"** 이라는 문제의 답은 **vi** 다. emacs와 nano는 모드가 없다.

> 내일은 실행 중인 프로그램 — 프로세스의 개념과 유형을 다룬다.

## 📖 용어

- **`/패턴`** : 커서 아래 방향으로 문자열을 검색하는 vi 명령.
- **`n` / `N`** : 검색 결과를 같은 방향 / 반대 방향으로 이동하는 키.
- **치환(substitute)** : `:s/A/B/` 형식으로 문자열을 바꾸는 ex 명령.
- **`%`** : 치환에서 파일 전체를 대상으로 지정하는 범위 기호.
- **`g`** : 치환에서 한 줄 안의 모든 일치를 바꾸도록 지정하는 옵션.
- **`~/.vimrc`** : vim의 개인 설정 파일. 전역 설정은 `/etc/vimrc`다.
- **nano** : pico를 개선한 GNU 편집기. 모드가 없고 화면 아래에 단축키가 표시된다.
- **emacs** : Richard Stallman이 만든 확장성 높은 편집기. 모드 없이 조합키로 조작한다.

## 📝 연습 문제

**문제 1.** 다음 중 vi 편집기에서 파일 전체의 모든 `apple`을 `orange`로 바꾸는 명령으로 알맞은 것은?

A) :s/apple/orange/  
B) :%s/apple/orange/g  
C) :s/apple/orange/g  
D) :%s/apple/orange/  

**정답: B**  
해설: `%`는 파일 전체를 범위로 지정하고 `g`는 한 줄 안의 모든 일치를 바꾸도록 지정합니다. 둘을 함께 써야 문서 전체의 모든 문자열이 치환됩니다. `%` 없이 쓰면 커서가 있는 줄만, `g` 없이 쓰면 각 줄의 첫 번째 것만 바뀝니다.

---

**문제 2.** 다음 중 vi 편집기에서 화면에 줄 번호를 표시하는 명령으로 알맞은 것은?

A) :set ai  
B) :set ic  
C) :set nu  
D) :set ts=4  

**정답: C**  
해설: `:set nu`(number)는 각 줄 앞에 번호를 표시하며 `:set nonu`로 다시 숨길 수 있습니다. `ai`는 자동 들여쓰기, `ic`는 검색 시 대소문자 무시, `ts`는 탭 크기를 지정하는 옵션입니다.

---

**문제 3.** 다음 중 vim의 개인 환경 설정을 저장하는 파일로 알맞은 것은?

A) ~/.bashrc  
B) /etc/profile  
C) ~/.viminfo  
D) ~/.vimrc  

**정답: D**  
해설: 사용자별 vim 설정은 홈 디렉터리의 `~/.vimrc`에 저장하며 모든 사용자에게 적용하려면 `/etc/vimrc`에 기록합니다. `~/.bashrc`는 셸 설정 파일이고 `/etc/profile`은 전역 로그인 설정 파일입니다.

---

**문제 4.** 다음 중 편집 모드의 구분이 없어 실행 직후 바로 문자를 입력할 수 있는 편집기로 알맞은 것은?

A) nano  
B) vi  
C) vim  
D) ex  

**정답: A**  
해설: nano는 모드 구분이 없어 실행하자마자 글자를 입력할 수 있고 화면 아래에 주요 단축키가 표시됩니다. vi와 vim은 명령·입력·ex 세 모드를 가지며 실행 직후에는 명령 모드에 놓입니다. ex는 줄 단위로 동작하는 라인 편집기입니다.

---

**문제 5.** 다음 중 nano 편집기에서 작성한 내용을 저장하는 단축키로 알맞은 것은?

A) Ctrl+X  
B) Ctrl+W  
C) Ctrl+O  
D) Ctrl+S  

**정답: C**  
해설: nano에서 저장은 `Ctrl+O`(Write Out), 종료는 `Ctrl+X`(Exit)입니다. 화면 아래 도움말에 `^O`처럼 표시되며 여기서 `^` 기호는 Ctrl 키를 뜻합니다. `Ctrl+W`는 문자열 검색 단축키입니다.
