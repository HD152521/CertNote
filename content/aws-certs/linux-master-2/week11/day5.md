# Day 5 - 2차 종합 모의와 최종 정리

## 📌 핵심 정리

- 2차 시험은 **리눅스 활용** — **X 윈도 · 인터넷 활용 · 응용분야** 세 항목이다.
- 비중이 크게 다르다 — **인터넷 활용이 절반을 훌쩍 넘고**, X 윈도가 그다음, 응용분야는 몇 문항이다.
- 2차는 **원리보다 이름과 값**을 묻는다. **제품명·프로토콜·포트·레코드**가 핵심이다.
- 마지막까지 남겨야 할 것은 **포트 번호 · 서브넷 계산 · 계층 분류표** 셋이다.
- 아래 10문항으로 2차 전 범위를 마무리한다.

## 2차 최종 점검표

```text
   W8 X 윈도       서버=화면 가진 쪽 / 클라이언트=프로그램
                   XFree86 → X.org → Wayland
                   계층  X서버 ← Xlib·XCB ← 툴킷(GTK+ C·Qt C++·FLTK·Motif) ← 앱
                   윈도매니저 KWin·Mutter·Xfwm·Windowmaker·Afterstep
                   디스플레이매니저 XDM·GDM·KDM·SDDM·LightDM  (끝이 DM)
                   데스크톱환경 GNOME(GTK+)·KDE(Qt)·Xfce·LXDE·CDE(Motif)
                   DISPLAY :0.0 · startx · 런레벨 3/5 · xhost(위험) vs ssh -X

   W9 네트워크      OSI 물데네전세표응 / 허브1 스위치2 라우터3
                   비트·프레임·패킷·세그먼트 / MAC 2계층 IP 3계층 포트 4계층
                   TCP 신뢰 · UDP 속도
                   회선(PSTN) vs 패킷(PSDN) · CSMA/CD 유선 · CA 무선
                   X.25 → Frame Relay → ATM(53바이트) · FDDI(광 이중링 토큰)
                   IEEE 802.3/802.5/802.6/802.11 · IANA
                   클래스 A1~126 B128~191 C192~223 D224~239
                   사설 10 / 172.16~31 / 192.168 · 루프백 127.0.0.1
                   호스트 수 = (256 − 마스크) − 2  →  254·126·62·30·14·6·2

   W10 인터넷 서비스  HTTP 80 · HTTPS 443 · SSH 22 · TELNET 23
                   SMTP 25(보내기·서버간) · POP3 110(받아서 삭제) · IMAP 143(서버 유지)
                   MUA → MTA → MDA · MIME
                   DNS 53 · A·AAAA·MX·CNAME·NS·PTR · BIND
                   FTP 21제어/20데이터 · 능동 vs 수동 · anonymous · bin/ascii
                   NFS(유닉스·RPC·/etc/exports) vs 삼바(윈도·SMB/CIFS/NetBIOS)
                   Gopher(메뉴검색) · Usenet(NNTP) · Archie(FTP검색) · IRC

   W11 응용분야     클러스터 고계산용(HPC) · 고가용성(HA) · 부하분산(LB)
                   전가상화(수정 불필요) vs 반가상화(수정 필요)
                   Type1 KVM·Xen·ESXi / Type2 VirtualBox·Workstation
                   VirtualBox = 오라클 · GPL · 전가상화 · VMDK/VHD 지원
                   리눅스 커널 기반 OS: 안드로이드·Tizen·webOS (iOS 아님)
                   IaaS/PaaS/SaaS · 하둡(HDFS·MapReduce)
```

## 마지막까지 들고 갈 세 가지

```text
   ① 포트     21 FTP · 22 SSH · 23 TELNET · 25 SMTP · 53 DNS
              80 HTTP · 110 POP3 · 143 IMAP · 443 HTTPS · 631 CUPS

   ② 서브넷   256 − 마스크 = 블록,  블록 − 2 = 호스트
              /24 254 · /25 126 · /26 62 · /27 30 · /28 14 · /29 6 · /30 2

   ③ 분류     끝이 DM → 디스플레이 매니저
              Xfce 는 환경 · Xfwm 은 윈도 매니저
              NFS 는 유닉스 · 삼바는 윈도
              TELNET 은 접속이지 전송이 아니다
```

## 📖 용어

- **X 서버** : 화면과 입력장치를 가진 쪽. 사용자가 앉아 있는 컴퓨터다.
- **디스플레이 매니저** : 그래픽 로그인 화면을 제공하는 프로그램. 이름이 DM으로 끝난다.
- **서브넷마스크** : 네트워크 부분과 호스트 부분을 가르는 값.
- **MX 레코드** : 도메인의 메일을 받을 서버를 지정하는 DNS 레코드.
- **삼바** : SMB/CIFS로 윈도와 파일을 공유하는 소프트웨어.
- **고가용성 클러스터** : 장애가 나도 서비스가 끊기지 않도록 구성한 클러스터.

## 📝 연습 문제

**문제 1.** 다음 중 X 윈도에서 GTK+ 툴킷을 사용하는 데스크톱 환경으로 알맞은 것은?

A) KDE  
B) GNOME  
C) LXQt  
D) CDE  

**정답: B**  
해설: GNOME은 C 언어로 작성된 GTK+ 툴킷을 기반으로 하며 Xfce와 MATE도 같은 툴킷을 사용합니다. KDE와 LXQt는 C++로 작성된 Qt를, CDE는 전통적인 Motif 툴킷을 사용합니다.

---

**문제 2.** 다음 중 성격이 나머지 셋과 다른 것으로 알맞은 것은?

A) GDM  
B) SDDM  
C) LightDM  
D) Mutter  

**정답: D**  
해설: GDM, SDDM, LightDM은 모두 그래픽 로그인 화면을 제공하는 디스플레이 매니저이며 이름이 DM으로 끝납니다. Mutter는 GNOME에서 창의 테두리와 이동을 담당하는 윈도 매니저이므로 역할이 다릅니다.

---

**문제 3.** 다음 중 OSI 7계층에서 포트 번호를 사용해 종단 간 통신을 담당하는 계층으로 알맞은 것은?

A) 전송 계층  
B) 네트워크 계층  
C) 세션 계층  
D) 표현 계층  

**정답: A**  
해설: 4계층인 전송 계층은 포트 번호로 애플리케이션을 구분하며 TCP와 UDP가 여기에 속합니다. 3계층인 네트워크 계층은 IP 주소로 경로를 정하고, 2계층은 MAC 주소를 사용합니다.

---

**문제 4.** C 클래스 네트워크에서 서브넷마스크가 255.255.255.240일 때 하나의 서브넷에서 사용할 수 있는 호스트 개수로 알맞은 것은?

A) 16  
B) 30  
C) 14  
D) 62  

**정답: C**  
해설: 256에서 240을 빼면 블록 크기가 16이고, 여기서 네트워크 주소와 브로드캐스트 주소 두 개를 제외하면 14개가 남습니다. 마스크가 224일 때는 30개, 192일 때는 62개가 됩니다.

---

**문제 5.** 다음 중 사용자가 작성한 메일을 자신의 메일 서버로 보내고 그 서버가 상대 서버로 전달할 때 공통으로 사용하는 프로토콜로 알맞은 것은?

A) IMAP  
B) POP3  
C) NNTP  
D) SMTP  

**정답: D**  
해설: SMTP는 사용자가 메일을 발송할 때와 메일 서버끼리 메일을 전달할 때 모두 사용됩니다. POP3와 IMAP은 도착한 메일을 사용자가 가져오거나 열람할 때만 쓰이며, NNTP는 뉴스그룹용 프로토콜입니다.

---

**문제 6.** 다음 중 도메인 이름을 IPv6 주소와 연결하는 DNS 레코드로 알맞은 것은?

A) AAAA  
B) A  
C) MX  
D) SOA  

**정답: A**  
해설: 128비트인 IPv6 주소는 AAAA 레코드로 연결하며 32비트인 IPv4 주소는 A 레코드를 사용합니다. MX는 메일 서버를, SOA는 영역의 관리자와 갱신 주기 같은 기본 정보를 담습니다.

---

**문제 7.** 다음 중 FTP에서 클라이언트가 데이터 연결을 직접 여는 방식으로 방화벽 환경에서 주로 사용되는 모드로 알맞은 것은?

A) 능동 모드  
B) 수동 모드  
C) 바이너리 모드  
D) 익명 모드  

**정답: B**  
해설: 수동 모드는 클라이언트가 데이터 연결까지 직접 열기 때문에 클라이언트 쪽 방화벽에 막히지 않습니다. 능동 모드는 서버가 20번 포트에서 클라이언트로 연결을 시도하므로 방화벽 뒤에 있는 환경에서는 실패하기 쉽습니다.

---

**문제 8.** 다음 중 삼바 서버의 동작을 설정하는 파일로 알맞은 것은?

A) /etc/exports  
B) /etc/resolv.conf  
C) /etc/samba/smb.conf  
D) /etc/cups/cupsd.conf  

**정답: C**  
해설: 삼바는 `/etc/samba/smb.conf`에 공유할 디렉터리와 접근 권한을 설정하며 `smbd`와 `nmbd` 두 데몬이 동작합니다. `/etc/exports`는 NFS, `/etc/resolv.conf`는 DNS 서버 주소, `cupsd.conf`는 인쇄 시스템의 설정 파일입니다.

---

**문제 9.** 다음 중 하나의 큰 연산을 여러 노드가 나누어 처리하도록 구성한 클러스터로 알맞은 것은?

A) 부하분산 클러스터  
B) 고계산용 클러스터  
C) 고가용성 클러스터  
D) 하이브리드 클러스터  

**정답: B**  
해설: 고계산용 클러스터는 기상 예측이나 유전자 분석처럼 큰 연산을 여러 노드가 병렬로 나누어 처리합니다. 부하분산은 요청을 나누어 받는 것이고 고가용성은 장애가 나도 서비스가 끊기지 않게 하는 구성이라 목적이 다릅니다.

---

**문제 10.** 다음 중 게스트 운영체제를 수정하지 않고도 가상 머신에서 실행할 수 있게 하는 가상화 방식으로 알맞은 것은?

A) 반가상화  
B) 컨테이너 방식  
C) 에뮬레이션  
D) 전가상화  

**정답: D**  
해설: 전가상화는 하이퍼바이저가 하드웨어를 그대로 흉내 내므로 게스트 운영체제를 고칠 필요가 없으며 Intel VT-x와 AMD-V 같은 하드웨어 지원으로 성능도 확보합니다. 반가상화는 게스트 커널을 수정해야 하는 대신 성능이 좋습니다.
