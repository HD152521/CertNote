# Day 3 - 임베디드와 기술 동향

## 📌 핵심 정리

- **임베디드 시스템은 특정 기능을 위해 기기 안에 내장된 시스템**이다. 냉장고·공유기·자동차에 들어 있다.
- **안드로이드는 리눅스 커널 기반**이다. **iOS는 아니다** — 이 구분이 자주 나온다.
- 리눅스 커널을 쓰는 OS — **안드로이드 · Tizen · webOS · ChromeOS**.
- 클라우드 서비스 모델 셋 — **IaaS(인프라) · PaaS(플랫폼) · SaaS(소프트웨어)**.
- 빅데이터 분산 처리의 대표는 **하둡(Hadoop)** 이다.

## 임베디드 시스템

| 항목 | 내용 |
|------|------|
| 정의 | **특정 기능을 수행하기 위해 기기 안에 내장된** 컴퓨터 시스템 |
| 특징 | 정해진 일만 한다 · 자원이 **제한적** · 오래 켜져 있다 |
| 예 | **공유기, 스마트TV, 냉장고, 자동차, 의료기기, 드론** |

- 범용 PC와 달리 **하는 일이 정해져 있다.** 그래서 필요한 기능만 담아 작게 만든다.
- **리눅스가 임베디드에 많이 쓰이는 이유**는 분명하다.

| 이유 | 설명 |
|------|------|
| **무료** | 라이선스 비용이 없다 |
| **소스 공개** | 필요한 부분만 골라 **줄여서** 넣을 수 있다 |
| **이식성** | ARM·MIPS 등 **다양한 CPU**를 지원한다 |
| 안정성 | 오래 켜 두어도 잘 버틴다 |

- **RTOS**(Real-Time Operating System)는 **정해진 시간 안에 반드시 응답**해야 하는 시스템용 운영체제다. 자동차 제동장치처럼 늦으면 안 되는 곳에 쓴다.

## 리눅스 커널 기반 운영체제

| 운영체제 | 만든 곳 | 쓰이는 곳 |
|---------|--------|----------|
| **안드로이드(Android)** | **구글** | **스마트폰·태블릿** |
| **Tizen** | 삼성·인텔 | 스마트워치·TV |
| **webOS** | LG(원래 팜) | 스마트TV |
| **ChromeOS** | 구글 | 크롬북 |
| Raspberry Pi OS | 라즈베리파이 재단 | 소형 보드 |

> ⚠️ **iOS와 macOS는 리눅스 커널이 아니다.** 애플의 Darwin(BSD 계열) 커널을 쓴다. **윈도도 당연히 아니다.** "리눅스 커널 기반 운영체제가 아닌 것"이라는 문제에 이 이름들이 오답으로 나온다.

- **안드로이드는 리눅스 커널 위에 자체 프레임워크를 얹은 것**이다. 커널은 공유하지만 GNU 도구 모음은 쓰지 않는다.

## 클라우드 컴퓨팅

| 모델 | 제공하는 것 | 예 |
|------|-----------|-----|
| **IaaS** | **Infrastructure** — 서버·저장소·네트워크 | AWS EC2 |
| **PaaS** | **Platform** — 실행 환경·개발 도구 | 앱 엔진 |
| **SaaS** | **Software** — 완성된 소프트웨어 | 웹 메일, 웹 오피스 |

```text
   IaaS  ─── 하드웨어만 빌린다.  OS부터 내가 설치
   PaaS  ─── 실행 환경까지 준다.  앱만 올리면 된다
   SaaS  ─── 완성품을 쓴다.      설치할 것이 없다
```

- **가운데 글자로 구분한다** — **I는 Infrastructure, P는 Platform, S는 Software**.
- 아래로 내려갈수록 **내가 관리할 것이 줄어든다.**

| 구축 형태 | 뜻 |
|----------|-----|
| **퍼블릭 클라우드** | 누구나 빌려 쓰는 공용 |
| **프라이빗 클라우드** | 조직 내부 전용 |
| **하이브리드** | 둘을 섞어 쓰는 형태 |

- **OpenStack**은 프라이빗 클라우드를 구축하는 대표적인 **오픈소스 플랫폼**이다.

## 빅데이터

| 기술 | 하는 일 |
|------|--------|
| **Hadoop(하둡)** | **대용량 데이터를 여러 서버에 나눠 저장·처리** |
| **HDFS** | 하둡의 **분산 파일 시스템** |
| **MapReduce** | 나눠서 처리하고(Map) 합치는(Reduce) 방식 |
| **Spark** | 하둡보다 **메모리 기반으로 빠른** 처리 |
| **NoSQL** | 정형화되지 않은 데이터용 데이터베이스 (MongoDB 등) |

- 빅데이터의 특징을 **3V** — **Volume(양) · Velocity(속도) · Variety(다양성)** 로 설명한다.
- 하둡과 스파크 모두 **리눅스 위에서 동작**한다.

## 리눅스가 쓰이는 분야

| 분야 | 내용 |
|------|------|
| **서버** | 웹·메일·DB·파일 서버 — 가장 큰 시장 |
| **슈퍼컴퓨터** | **세계 상위 슈퍼컴퓨터는 사실상 전부 리눅스** |
| **모바일** | **안드로이드** |
| **임베디드** | 공유기, TV, 자동차 |
| **클라우드** | 대부분의 클라우드 인스턴스가 리눅스 |
| 데스크톱 | 비중은 작지만 꾸준하다 |

- **슈퍼컴퓨터 분야에서 리눅스의 점유율이 압도적**이라는 사실이 자주 출제된다. 소스를 고쳐 하드웨어에 맞출 수 있기 때문이다.

## 최근 기술 용어

| 용어 | 뜻 |
|------|-----|
| **IoT** | Internet of Things — 사물인터넷 |
| **5G** | 5세대 이동통신. 표준은 **3GPP** 가 만든다 |
| **엣지 컴퓨팅** | 중앙이 아니라 **가까운 곳에서** 처리 |
| **컨테이너 오케스트레이션** | 컨테이너를 자동 관리 — **쿠버네티스** |

> 내일부터는 지금까지 배운 전부를 모아 종합 문제를 푼다.

## 📖 용어

- **임베디드 시스템** : 특정 기능을 위해 기기 안에 내장된 컴퓨터 시스템.
- **RTOS** : 정해진 시간 안에 반드시 응답해야 하는 실시간 운영체제.
- **안드로이드** : 리눅스 커널을 기반으로 구글이 만든 모바일 운영체제.
- **IaaS / PaaS / SaaS** : 인프라 / 플랫폼 / 소프트웨어를 제공하는 클라우드 서비스 모델.
- **OpenStack** : 프라이빗 클라우드를 구축하는 오픈소스 플랫폼.
- **하둡(Hadoop)** : 대용량 데이터를 여러 서버에 나눠 저장하고 처리하는 빅데이터 기술.
- **HDFS** : 하둡의 분산 파일 시스템.
- **쿠버네티스** : 컨테이너를 자동으로 배치하고 관리하는 오케스트레이션 도구.

## 📝 연습 문제

**문제 1.** 다음 중 리눅스 커널을 기반으로 만들어진 모바일 운영체제로 알맞은 것은?

A) iOS  
B) 윈도 모바일  
C) 심비안  
D) 안드로이드  

**정답: D**  
해설: 안드로이드는 리눅스 커널 위에 구글이 자체 프레임워크를 올려 만든 모바일 운영체제입니다. iOS는 애플의 Darwin 커널을 기반으로 하며 리눅스 커널과는 계보가 다릅니다. 같은 리눅스 커널 기반으로는 Tizen과 webOS가 있습니다.

---

**문제 2.** 다음 중 임베디드 시스템에 대한 설명으로 알맞은 것은?

A) 여러 대의 컴퓨터를 묶어 하나처럼 사용하는 구성이다  
B) 특정 기능을 수행하기 위해 기기 안에 내장된 시스템이다  
C) 인터넷을 통해 자원을 빌려 쓰는 서비스 형태다  
D) 대용량 데이터를 분산 저장하고 처리하는 기술이다  

**정답: B**  
해설: 임베디드 시스템은 공유기, 스마트TV, 자동차처럼 정해진 기능을 수행하기 위해 기기 내부에 탑재된 시스템입니다. 자원이 제한적이라 필요한 기능만 담아 작게 구성하며, 소스를 줄여 넣을 수 있는 리눅스가 널리 쓰입니다.

---

**문제 3.** 다음 중 정해진 시간 안에 반드시 처리를 완료해야 하는 시스템에 사용되는 운영체제로 알맞은 것은?

A) 분산 운영체제  
B) 다중 사용자 운영체제  
C) 실시간 운영체제  
D) 일괄 처리 운영체제  

**정답: C**  
해설: 실시간 운영체제(RTOS)는 요청에 대해 정해진 시간 안에 응답하는 것을 보장하며 자동차 제동장치나 의료기기처럼 지연이 허용되지 않는 분야에 사용됩니다. 처리량보다 응답 시간의 예측 가능성을 우선합니다.

---

**문제 4.** 다음 중 대용량 데이터를 여러 서버에 분산 저장하고 처리하는 대표적인 빅데이터 기술로 알맞은 것은?

A) 하둡  
B) 오픈스택  
C) 쿠버네티스  
D) 도커  

**정답: A**  
해설: 하둡은 HDFS라는 분산 파일 시스템과 MapReduce 처리 방식을 통해 대용량 데이터를 여러 서버에 나누어 저장하고 병렬로 처리합니다. 오픈스택은 클라우드 구축 플랫폼이며 쿠버네티스와 도커는 컨테이너 관련 기술입니다.

---

**문제 5.** 다음 중 서버와 저장소 같은 하드웨어 자원을 빌려 주고 운영체제부터는 사용자가 직접 설치하는 클라우드 서비스 모델로 알맞은 것은?

A) SaaS  
B) PaaS  
C) DaaS  
D) IaaS  

**정답: D**  
해설: IaaS는 Infrastructure as a Service의 줄임말로 서버, 저장소, 네트워크 같은 인프라만 제공하며 운영체제와 그 위의 소프트웨어는 사용자가 직접 구성합니다. PaaS는 실행 환경까지, SaaS는 완성된 소프트웨어까지 제공합니다.
