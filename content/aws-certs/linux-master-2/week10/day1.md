# Day 1 - 웹과 메일

## 📌 핵심 정리

- 웹은 **HTTP(80)** 로 동작하고 암호화된 것이 **HTTPS(443)** 다.
- 리눅스 웹 서버는 **Apache**와 **Nginx**가 대표다.
- 메일 프로토콜은 셋이다 — **보낼 때 SMTP(25)**, **받을 때 POP3(110) 또는 IMAP(143)**.
- **메일 서버끼리 주고받는 것도 SMTP** 다. 이 문제가 자주 나온다.
- **POP3는 내려받아 지우고, IMAP은 서버에 남긴다.** 여러 기기를 쓰면 IMAP이다.

## 웹

| 항목 | 내용 |
|------|------|
| **WWW** | World Wide Web. 1989년 **팀 버너스리**(CERN)가 고안 |
| **HTTP** | HyperText Transfer Protocol. **80번 포트** |
| **HTTPS** | HTTP + 암호화(SSL/TLS). **443번 포트** |
| **HTML** | 문서를 기술하는 언어 |
| **URL** | 자원의 위치를 나타내는 주소 |

### URL 읽기

```text
   https :// www.example.com : 443 /docs/index.html
     │            │             │        │
     │            │             │        └── 경로
     │            │             └─────────── 포트 (생략하면 기본값)
     │            └───────────────────────── 호스트 이름
     └────────────────────────────────────── 프로토콜(스킴)
```

### 웹 서버와 브라우저

| 구분 | 이름 |
|------|------|
| **웹 서버** | **Apache**(가장 오래된 표준), **Nginx**(가볍고 빠름), lighttpd |
| **그래픽 브라우저** | Firefox, Chrome, Konqueror(KDE) |
| **텍스트 브라우저** | **Lynx**, w3m, links |

- **Lynx는 텍스트 기반 브라우저**다. 그래픽 환경 없이 명령줄에서 웹을 볼 때 쓴다. 이름이 보기에 나온다.
- 명령줄에서 파일을 내려받을 때는 **`wget`** 이나 **`curl`** 을 쓴다.

## 메일의 세 프로토콜

```text
   [보내는 사람]                                   [받는 사람]

     메일 프로그램                                   메일 프로그램
          │                                              ▲
          │ SMTP                                  POP3 / IMAP
          ▼                                              │
     보내는 메일 서버 ──── SMTP ────► 받는 메일 서버 ──────┘
                        (서버 간 전달도 SMTP)
```

| 프로토콜 | 포트 | 하는 일 |
|---------|-----|--------|
| **SMTP** | **25** | **메일을 보낸다.** 서버 간 전달도 담당 |
| **POP3** | **110** | 메일을 **내려받는다** |
| **IMAP** | **143** | 메일을 **서버에 두고 본다** |

> **"메일 서버 사이에서 메일을 교환하는 프로토콜은?"** → **SMTP** 다. 받는 것은 POP3·IMAP이지만, **서버끼리 주고받는 것은 SMTP** 라는 점이 핵심이다.

- 줄임말도 나온다 — **SMTP는 Simple Mail Transfer Protocol**, **POP은 Post Office Protocol**, **IMAP은 Internet Message Access Protocol**이다.

### POP3와 IMAP

| 구분 | **POP3** | **IMAP** |
|------|---------|---------|
| 저장 위치 | **내 컴퓨터로 내려받음** | **서버에 그대로 남음** |
| 서버의 원본 | 보통 **삭제** | **유지** |
| 여러 기기 | 동기화가 안 된다 | **모든 기기에서 같은 상태** |
| 오프라인 | 읽기 좋다 | 연결이 필요하다 |
| 포트 | **110** | **143** |

- **휴대폰과 PC에서 같은 메일함을 보려면 IMAP**이다. POP3로 PC에서 받아 버리면 휴대폰에서는 사라진다.
- 암호화 버전은 POP3S(995), IMAPS(993)다.

## 메일 시스템의 구성 요소

| 약자 | 풀네임 | 하는 일 | 예 |
|-----|-------|--------|-----|
| **MUA** | Mail **User** Agent | **사용자가 쓰는 프로그램** | Thunderbird, Outlook, mutt |
| **MTA** | Mail **Transfer** Agent | **서버 간 전달** | **Sendmail, Postfix**, qmail, exim |
| **MDA** | Mail **Delivery** Agent | 사서함에 **배달** | procmail, Dovecot |

```text
   MUA ──► MTA ──── SMTP ────► MTA ──► MDA ──► 사서함 ──► MUA
   (작성)  (전송)              (수신)  (배달)          (읽기)
```

- **U는 User(사용자), T는 Transfer(전송), D는 Delivery(배달)** 로 가운데 글자를 보면 구분된다.
- **Sendmail과 Postfix가 대표적인 MTA** 라는 점이 자주 출제된다.
- **MIME**(Multipurpose Internet Mail Extensions)은 메일에 **한글·이미지·첨부파일**을 담을 수 있게 하는 규격이다. 원래 메일은 영문 텍스트만 보낼 수 있었다.

> 내일은 도메인 이름을 IP로 바꿔 주는 DNS를 다룬다.

## 📖 용어

- **HTTP / HTTPS** : 웹 통신 프로토콜 / 암호화가 적용된 웹 통신 프로토콜. 포트는 80과 443이다.
- **URL** : 프로토콜·호스트·포트·경로로 이루어진 자원의 주소.
- **Apache / Nginx** : 리눅스에서 가장 널리 쓰이는 웹 서버.
- **SMTP** : 메일을 보내고 서버 간에 전달하는 프로토콜. 포트는 25다.
- **POP3** : 메일을 내려받는 프로토콜. 서버의 원본은 보통 삭제된다. 포트는 110이다.
- **IMAP** : 메일을 서버에 두고 열람하는 프로토콜. 포트는 143이다.
- **MUA / MTA / MDA** : 사용자 프로그램 / 서버 간 전송 / 사서함 배달을 담당하는 구성 요소.
- **MIME** : 메일에 한글과 첨부파일을 담을 수 있게 하는 확장 규격.

## 📝 연습 문제

**문제 1.** 다음 중 메일 서버 사이에서 메일을 주고받을 때 사용하는 프로토콜로 알맞은 것은?

A) SMTP  
B) POP3  
C) IMAP  
D) HTTP  

**정답: A**  
해설: SMTP는 사용자가 메일을 보낼 때뿐 아니라 메일 서버끼리 메일을 전달할 때도 사용하는 프로토콜입니다. POP3와 IMAP은 사용자가 서버에 도착한 메일을 가져오거나 열람할 때 사용하므로 서버 간 전송에는 쓰이지 않습니다.

---

**문제 2.** 다음 중 메일을 서버에 그대로 두고 여러 기기에서 동일한 상태로 확인할 수 있는 프로토콜로 알맞은 것은?

A) SMTP  
B) POP3  
C) IMAP  
D) MIME  

**정답: C**  
해설: IMAP은 메일을 서버에 보관한 채 열람하므로 휴대폰과 PC 어디에서 접속해도 읽음 표시와 폴더 구조가 같게 유지됩니다. POP3는 메일을 내려받은 뒤 서버에서 삭제하는 것이 기본이라 기기 간 동기화가 되지 않습니다.

---

**문제 3.** 다음 중 HTTPS가 기본으로 사용하는 포트 번호로 알맞은 것은?

A) 80  
B) 443  
C) 8080  
D) 25  

**정답: B**  
해설: HTTPS는 HTTP에 SSL/TLS 암호화를 더한 것으로 443번 포트를 사용합니다. 암호화하지 않는 HTTP는 80번을 쓰며, 25번은 메일 전송용 SMTP의 포트입니다.

---

**문제 4.** 다음 중 메일 시스템에서 서버 간 메일 전송을 담당하는 구성 요소로 알맞은 것은?

A) MUA  
B) MDA  
C) MIME  
D) MTA  

**정답: D**  
해설: MTA는 Mail Transfer Agent의 줄임말로 메일 서버 사이의 전송을 담당하며 Sendmail과 Postfix가 대표적입니다. MUA는 사용자가 직접 쓰는 메일 프로그램, MDA는 도착한 메일을 사서함에 배달하는 구성 요소입니다.

---

**문제 5.** 다음 중 텍스트 기반으로 동작하는 웹 브라우저로 알맞은 것은?

A) Lynx  
B) Firefox  
C) Konqueror  
D) Chrome  

**정답: A**  
해설: Lynx는 그래픽 환경 없이 터미널에서 웹 문서를 볼 수 있는 텍스트 기반 브라우저입니다. Firefox, Chrome, Konqueror는 모두 그래픽 환경에서 동작하는 브라우저이며 Konqueror는 KDE 데스크톱 환경에 포함되어 있습니다.
