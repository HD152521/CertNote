# Day 3 - 원격 접속과 파일 전송

## 📌 핵심 정리

- **TELNET(23)은 평문**이라 위험하고, **SSH(22)는 암호화**한다. 지금은 SSH만 쓴다.
- **TELNET과 SSH는 원격 접속**이고, **파일 전송이 아니다.** 이 구분이 시험에 나온다.
- **FTP는 포트 두 개** — **21번이 제어, 20번이 데이터**다.
- FTP에는 **능동(active) 모드와 수동(passive) 모드**가 있다.
- SSH 기반 파일 전송은 **`scp`** 와 **`sftp`** 다.

## 원격 접속

| 서비스 | 포트 | 암호화 |
|-------|-----|-------|
| **TELNET** | **23** | **없다 — 평문** |
| **SSH** | **22** | **있다** |
| rlogin / rsh | 513 / 514 | 없다 (옛 r 계열) |

### TELNET

- 원격 컴퓨터에 접속해 명령을 실행하는 **가장 오래된 방법**이다.
- **아이디와 비밀번호까지 평문으로 흐른다.** 도청하면 그대로 보인다.
- 지금은 거의 쓰지 않지만 **포트 확인용**으로는 쓰인다 — `telnet 서버 80`.

### SSH

```bash
ssh user@192.168.0.10          # 접속
ssh -p 2222 user@server        # 포트 지정
ssh -X user@server             # 원격 GUI (X11 forwarding)
```

| 특징 | 설명 |
|------|------|
| **암호화** | 로그인 정보와 명령·결과가 **전부 암호화**된다 |
| **공개키 인증** | 비밀번호 없이 **키 쌍**으로 인증할 수 있다 |
| **터널링** | 다른 통신을 SSH 안으로 통과시킬 수 있다 |
| 구현 | **OpenSSH** (데몬 `sshd`) |

```bash
ssh-keygen                     # 키 쌍 생성 (~/.ssh/id_rsa, id_rsa.pub)
ssh-copy-id user@server        # 공개키를 서버에 등록
```

- **개인키는 내가 갖고, 공개키를 서버에 둔다.** 서버의 `~/.ssh/authorized_keys`에 공개키가 등록된다.
- **개인키는 절대 남에게 주지 않는다.** 권한도 `600`이어야 한다.

> **TELNET과 SSH는 "원격 접속"이지 "파일 전송"이 아니다.** "파일을 주고받는 서비스로 거리가 먼 것은?"이라는 문제의 답이 **TELNET** 인 이유다.

## 파일 전송 — FTP

| 포트 | 용도 |
|-----|------|
| **21** | **제어(control)** — 명령을 주고받는다 |
| **20** | **데이터(data)** — 실제 파일이 오간다 |

- **포트를 두 개 쓴다**는 점이 FTP의 특징이자 시험 포인트다.

### 능동 모드와 수동 모드

```text
   능동(Active)                       수동(Passive)

   클라이언트 ──21──► 서버            클라이언트 ──21──► 서버
   클라이언트 ◄─20─── 서버            클라이언트 ────► 서버
              (서버가 연결을 건다)              (클라이언트가 건다)
```

| 구분 | **능동 모드** | **수동 모드** |
|------|-------------|-------------|
| 데이터 연결 | **서버가 클라이언트에게** | **클라이언트가 서버에게** |
| 서버 포트 | **20번** | 임의의 높은 포트 |
| 방화벽 | 클라이언트 방화벽에 **막히기 쉽다** | **잘 통과한다** |

- 요즘 클라이언트는 대부분 방화벽 뒤에 있어 **수동 모드가 기본**이다.

### 익명 FTP

- 계정 없이 접속하는 공개 FTP다. **아이디는 `anonymous`**, 비밀번호는 관례적으로 **이메일 주소**를 넣는다.
- 공개 자료 배포에 쓰였다. **`anonymous`라는 이름**을 그대로 묻는다.

### FTP 명령

| 명령 | 하는 일 |
|------|--------|
| **`get`** | 파일 **하나 받기** |
| **`put`** | 파일 하나 **보내기** |
| **`mget` / `mput`** | **여러 개** 받기 / 보내기 |
| `ls`, `cd`, `pwd` | 원격 쪽 탐색 |
| `lcd` | **로컬** 디렉터리 변경 |
| **`bin` / `ascii`** | **바이너리** / 텍스트 전송 모드 |
| `bye`, `quit` | 종료 |

> **그림·압축 파일은 반드시 `bin`(바이너리) 모드**로 받아야 한다. ascii 모드로 받으면 줄바꿈이 변환되어 파일이 깨진다.

- FTP 서버 프로그램은 **vsftpd**, **ProFTPD** 가 대표적이다.

## 안전한 파일 전송

| 방법 | 기반 | 특징 |
|------|------|------|
| **`scp`** | **SSH** | 명령 한 줄로 복사 |
| **`sftp`** | **SSH** | FTP처럼 대화형으로 쓴다 |
| FTPS | FTP + SSL | FTP에 암호화를 덧붙인 것 |
| `rsync` | SSH 등 | **바뀐 부분만** 전송 — 백업에 유리 |

```bash
scp file.txt user@server:/home/user/       # 보내기
scp user@server:/home/user/file.txt .      # 받기
scp -r 폴더 user@server:/home/user/        # 디렉터리째
sftp user@server                           # 대화형
```

> **`sftp`와 `FTPS`는 다르다.** **sftp는 SSH 기반**이고, **FTPS는 FTP에 SSL을 씌운 것**이다. 이름이 비슷해 바꿔 놓은 보기가 나온다.

## 그래픽 원격

| 방법 | 설명 |
|------|------|
| **VNC** | 화면 자체를 전송한다. 플랫폼 독립적 |
| **XRDP** | 윈도의 원격 데스크톱(RDP)으로 접속 |
| **`ssh -X`** | X11 forwarding — **창 단위**로 띄운다 |

> 내일은 여러 컴퓨터가 파일을 공유하는 NFS와 삼바를 다룬다.

## 📖 용어

- **TELNET** : 암호화 없이 원격 접속하는 옛 프로토콜. 포트는 23이다.
- **SSH** : 통신을 암호화하는 원격 접속 프로토콜. 포트는 22이며 구현은 OpenSSH다.
- **공개키 인증** : 개인키와 공개키 쌍으로 비밀번호 없이 인증하는 방식.
- **FTP** : 파일 전송 프로토콜. 제어에 21번, 데이터에 20번 포트를 쓴다.
- **능동 / 수동 모드** : 데이터 연결을 서버가 여는 방식 / 클라이언트가 여는 방식.
- **익명 FTP** : `anonymous` 계정으로 접속하는 공개 FTP.
- **`scp` / `sftp`** : SSH를 기반으로 파일을 복사하거나 전송하는 도구.
- **`rsync`** : 변경된 부분만 전송해 효율적으로 동기화하는 도구.

## 📝 연습 문제

**문제 1.** 다음 중 TELNET과 비교한 SSH의 특징으로 알맞은 것은?

A) 별도의 포트를 사용하지 않는다  
B) 파일 전송만 가능하고 명령 실행은 할 수 없다  
C) 인증 정보와 통신 내용을 암호화한다  
D) 그래픽 환경에서만 사용할 수 있다  

**정답: C**  
해설: TELNET은 아이디와 비밀번호를 포함한 모든 통신을 평문으로 주고받아 도청에 취약합니다. SSH는 통신 전체를 암호화하며 공개키 인증과 터널링도 지원해 현재 원격 접속의 표준으로 쓰입니다.

---

**문제 2.** 다음 중 SSH를 기반으로 원격 시스템과 파일을 복사하는 명령으로 알맞은 것은?

A) scp  
B) telnet  
C) ping  
D) nslookup  

**정답: A**  
해설: `scp`는 SSH 프로토콜 위에서 동작하는 파일 복사 명령으로 전송 내용이 암호화됩니다. 대화형으로 사용하려면 같은 SSH 기반의 `sftp`를 쓸 수 있습니다. `telnet`은 원격 접속, `ping`과 `nslookup`은 진단 명령입니다.

---

**문제 3.** 다음 중 FTP가 명령을 주고받는 제어 연결에 사용하는 포트 번호로 알맞은 것은?

A) 20  
B) 22  
C) 23  
D) 21  

**정답: D**  
해설: FTP는 포트를 두 개 사용하며 21번이 명령을 주고받는 제어 연결, 20번이 실제 파일이 오가는 데이터 연결에 쓰입니다. 22번은 SSH, 23번은 TELNET의 포트입니다.

**문제 4.** 다음 중 익명 FTP에 접속할 때 사용하는 계정 이름으로 알맞은 것은?

A) guest  
B) anonymous  
C) public  
D) ftpuser  

**정답: B**  
해설: 익명 FTP는 `anonymous`라는 계정으로 접속하며 비밀번호에는 관례적으로 자신의 이메일 주소를 입력합니다. 별도의 계정 없이 공개 자료를 내려받을 수 있도록 제공하는 방식입니다.

---

**문제 5.** 다음 중 파일을 주고받는 서비스와 거리가 **먼** 것으로 알맞은 것은?

A) TELNET  
B) FTP  
C) SFTP  
D) SCP  

**정답: A**  
해설: TELNET은 원격 시스템에 접속해 명령을 실행하는 서비스이며 파일 전송 기능은 제공하지 않습니다. FTP는 대표적인 파일 전송 프로토콜이고 SFTP와 SCP는 SSH를 기반으로 파일을 안전하게 주고받는 도구입니다.
