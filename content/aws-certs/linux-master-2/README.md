# 🐧 리눅스마스터 2급 11주 학습 커리큘럼

> **목표**: 리눅스마스터 2급(KAIT 한국정보통신진흥협회 주관, 국가공인) 취득
> **총 학습 기간**: 11주 × 5일 = 55일
> **타겟**: 리눅스를 처음 다루는 학습자 — 사전 지식 없이 시작
> **핵심**: 2급은 1차·2차 모두 사지선다다. 1급처럼 명령어를 손으로 쓰는 실기가 없으므로
> "직접 쳐보되, 시험에서는 고르는 힘"을 기르는 데 초점을 둔다

> ⚠️ 과목별 배점 비율은 공식 고시에 없다. 2차 자료에 도는 "운영 및 관리 60% / 활용 40%"는
> 공식 출제기준 표에서 확인되지 않아 채택하지 않았다.

### 1급과 다른 점

- **2차가 실기가 아니다.** 1급 2차는 단답·서술 + 작업식이지만 2급 2차는 사지선다 80문항이다.
- **2차에 응시 자격 제한이 없다.** 1급은 1차 합격자만 2차를 볼 수 있다.

## 🗓 주차 구성

배점 비율이 공식에 없으므로 검정항목 개수(리눅스 일반 3 · 운영 및 관리 6 · 활용 3)를
기준으로 배분하되, **기출 문항 분포를 실측해 조정**했다. 특히 '리눅스 활용' 32문항이
X 윈도 8 · 인터넷 활용 20 · 응용분야 4 로 나뉘어 인터넷 활용에 두 주(W9·W10)를 배정했다.

| 주차 | 주제 | 대응 과목 |
|------|------|-----------|
| W1 | 리눅스란 무엇인가 — 커널·배포판·라이선스 | 리눅스 일반 |
| W2 | 설치와 첫 부팅 · 디렉터리 구조 | 리눅스 일반 |
| W3 | 기본 명령어 — 파일·디렉터리·계정 | 리눅스 일반 |
| W4 | 파일시스템 명령어와 권한 | 운영 및 관리 |
| W5 | Shell — 종류·변수·환경 설정 | 운영 및 관리 |
| W6 | 에디터(vi) · 프로세스 관리 | 운영 및 관리 |
| W7 | 소프트웨어 설치 · 장치 설정 | 운영 및 관리 |
| W8 | X 윈도 — 구조·툴킷 계층·데스크톱 환경·디스플레이 매니저 | 활용 |
| W9 | 네트워크의 개념 — OSI·통신 방식·IP와 서브넷 | 활용 |
| W10 | 인터넷 서비스의 종류 — 웹·메일·DNS·원격·파일 공유 | 활용 |
| W11 | 응용분야 + 1차/2차 종합 모의 | 활용 |

각 주차 day5는 **종합 복습**으로 둔다(1급과 동일한 패턴).

## ✍️ 집필 시 주의

- 1급 트랙(`linux-master-1`) 콘텐츠를 **구조·순서는 재활용하되 난이도는 낮춰 다시 쓴다.**
  1급 노트는 "리눅스 기본기 보유자" 대상이라 그대로 옮기면 입문자에게 맞지 않는다.
- 1급의 **week12~13(2차 실기 작업형)은 옮기지 않는다.** 2급 2차는 사지선다다.
- 1급의 **LVM·RAID(w5), 서버 구축 심화(DNS·Apache·Samba·방화벽)는 2급 범위를 넘는다.**
  2급 '인터넷 활용'은 서비스의 **종류와 개념** 수준이다.
- **부분 보강이 필요한 두 곳**: X 윈도의 데스크톱 환경·디스플레이 매니저,
  응용분야의 클러스터링·임베디드·기술동향. 1급이 실무 심화라 이 "개괄" 영역이 얇다.
- 퀴즈 파손 방지 3중 방어를 반드시 쓸 것 — `docs/linux-master-2-plan.md` §5 참조.
