# Day 2 - 디렉터리와 파일 다루기

## 📌 핵심 정리

- 위치를 다루는 세 명령: **`pwd`(어디에 있나) · `cd`(옮기기) · `ls`(무엇이 있나)**.
- **`ls -a`는 숨김 파일**을, **`ls -l`은 상세 정보**를 보여준다. 리눅스의 숨김 파일은 **이름이 `.`으로 시작**하는 파일이다.
- **`cp`는 복사, `mv`는 이동이자 이름 변경**이다. `mv`에 별도의 rename 명령이 없다.
- **디렉터리를 다루려면 `-r`(재귀)** 이 필요하다 — `cp -r`, `rm -r`.
- **`rm`에는 휴지통이 없다.** 지우면 끝이다. `rm -rf`는 특히 위험하다.

## 지금 어디에 있나

| 명령 | 하는 일 |
|------|--------|
| `pwd` | **현재 디렉터리의 절대 경로**를 출력 (print working directory) |
| `cd 경로` | 그 경로로 이동 |
| `cd` 또는 `cd ~` | **홈 디렉터리**로 |
| `cd ..` | 상위 디렉터리로 |
| `cd -` | **직전에 있던** 디렉터리로 |

```bash
pwd            # /home/user
cd /etc        # 절대 경로로 이동
cd ..          # /  로 올라감
cd ~           # 홈으로 복귀
```

## 무엇이 있나 — ls

| 옵션 | 뜻 |
|------|-----|
| `-a` | **숨김 파일 포함** (all) |
| `-l` | 상세 정보 (long) — 권한·소유자·크기·시간 |
| `-h` | 크기를 사람이 읽기 쉽게 (human) — KB, MB |
| `-t` | **시간순** 정렬 |
| `-r` | 역순 정렬 (reverse) |
| `-R` | 하위 디렉터리까지 **재귀적으로** |
| `-i` | inode 번호 표시 |

```bash
ls -l          # 상세히
ls -la         # 숨김 파일까지 상세히
ls -lh         # 크기를 KB/MB 로
ls -ltr        # 시간순 역순 — 최근 파일이 맨 아래
```

### 숨김 파일

- 리눅스에서 숨김 파일은 **이름이 `.`으로 시작**하는 파일이다. 별도의 속성이 아니다.
- `.bashrc`, `.ssh`, `.profile` 처럼 설정 파일이 대부분 여기 해당한다.
- 그냥 `ls`로는 안 보이고 **`ls -a`** 를 써야 보인다.

### `ls -l` 한 줄 읽기

```text
   -rw-r--r--  1  user  group  1024  Sep  3 09:00  a.txt
   │        │  │   │      │      │        │          │
   │        │  │   │      │      │        │          └── 이름
   │        │  │   │      │      │        └───────────── 마지막 수정 시각
   │        │  │   │      │      └────────────────────── 크기(바이트)
   │        │  │   │      └───────────────────────────── 그룹
   │        │  │   └──────────────────────────────────── 소유자
   │        │  └──────────────────────────────────────── 하드 링크 수
   │        └─────────────────────────────────────────── 권한 (다음 주에 자세히)
   └──────────────────────────────────────────────────── 파일 종류
```

**맨 앞 한 글자가 파일 종류**다.

| 글자 | 종류 |
|------|------|
| `-` | 일반 파일 |
| `d` | **디렉터리** |
| `l` | 심볼릭 링크 |
| `b` | 블록 장치 (디스크) |
| `c` | 문자 장치 (키보드) |

## 만들고 지우기

| 명령 | 하는 일 | 주의 |
|------|--------|------|
| `mkdir 이름` | 디렉터리 생성 | 중간 경로가 없으면 실패 |
| `mkdir -p a/b/c` | **중간 경로까지 한 번에** 생성 | |
| `rmdir 이름` | 디렉터리 삭제 | **비어 있어야만** 지워진다 |
| `rm 파일` | 파일 삭제 | 되돌릴 수 없다 |
| `rm -r 디렉터리` | 디렉터리를 **내용째** 삭제 | |
| `rm -f` | 확인 없이 강제 삭제 | |
| `touch 파일` | 빈 파일 생성 / 시간 갱신 | |

> ⚠️ **`rm -rf`는 리눅스에서 가장 위험한 명령**이다. 휴지통이 없어 복구가 사실상 불가능하다. 경로를 지우기 전에 `ls`로 먼저 확인하는 습관이 안전하다.

## 복사하고 옮기기

| 명령 | 하는 일 |
|------|--------|
| `cp 원본 사본` | 복사 |
| `cp -r 디렉터리 대상` | **디렉터리 복사 — `-r` 필수** |
| `cp -i` | 덮어쓰기 전에 물어본다 |
| `cp -p` | 권한·시간 정보를 **보존**하며 복사 |
| `mv 원본 대상` | **이동** |
| `mv 옛이름 새이름` | **이름 변경** |

- **`mv` 하나가 이동과 이름 변경을 겸한다.** 리눅스에는 rename 전용 명령이 기본으로 없다.
- 같은 디렉터리 안에서 `mv a.txt b.txt` 하면 이름이 바뀌고, 다른 디렉터리를 대상으로 주면 이동한다.
- **`mv`는 `-r`이 필요 없다.** 디렉터리도 그냥 옮겨진다.

```bash
cp a.txt b.txt          # 파일 복사
cp -r docs backup       # 디렉터리 복사 (-r 없으면 오류)
mv a.txt /tmp/          # 이동
mv old.txt new.txt      # 이름 변경
```

## 링크

| 종류 | 명령 | 성질 |
|------|------|------|
| **하드 링크** | `ln 원본 링크` | 같은 **inode**를 가리킨다. 원본을 지워도 데이터가 남는다 |
| **심볼릭 링크** | `ln -s 원본 링크` | 경로를 가리키는 **바로가기**. 원본을 지우면 깨진다 |

- 심볼릭 링크는 `ls -l`에서 맨 앞이 **`l`** 로 표시되고 `링크 -> 원본` 형태로 보인다.
- 하드 링크는 **다른 파일 시스템끼리는 만들 수 없고, 디렉터리에는 걸 수 없다.**

> 내일은 파일 안을 들여다보고 원하는 것을 찾아내는 명령들을 익힌다.

## 📖 용어

- **작업 디렉터리** : 지금 셸이 위치한 디렉터리. `pwd`로 확인한다.
- **숨김 파일** : 이름이 `.`으로 시작하는 파일. `ls -a`로만 보인다.
- **재귀(`-r`)** : 하위 디렉터리까지 훑는 옵션. `cp`·`rm`에서 디렉터리를 다루려면 필요하다.
- **하드 링크** : 같은 inode를 가리키는 또 다른 이름.
- **심볼릭 링크** : 다른 파일의 경로를 담은 바로가기 파일. `ln -s`로 만든다.
- **`touch`** : 빈 파일을 만들거나 기존 파일의 시간 정보를 갱신하는 명령.
- **`mkdir -p`** : 중간 경로가 없으면 함께 만들어 주는 옵션.

## 📝 연습 문제

**문제 1.** 다음 중 숨김 파일을 포함해 파일 목록을 보려고 할 때 사용하는 옵션으로 알맞은 것은?

A) ls -l  
B) ls -h  
C) ls -a  
D) ls -t  

**정답: C**  
해설: 리눅스에서 숨김 파일은 이름이 `.`으로 시작하는 파일이며 `-a`(all) 옵션을 주어야 목록에 나타납니다. `-l`은 상세 정보, `-h`는 크기를 읽기 쉬운 단위로, `-t`는 시간순 정렬입니다.

---

**문제 2.** 다음 중 디렉터리를 통째로 복사할 때 반드시 필요한 옵션으로 알맞은 것은?

A) cp -i  
B) cp -r  
C) cp -p  
D) cp -f  

**정답: B**  
해설: `cp`는 기본적으로 파일만 복사하므로 디렉터리를 복사하려면 재귀 옵션 `-r`(또는 `-R`)이 필요합니다. `-i`는 덮어쓰기 전 확인, `-p`는 권한과 시간 정보 보존, `-f`는 강제 실행입니다. 참고로 `mv`는 디렉터리를 옮길 때 `-r`이 필요 없습니다.

---

**문제 3.** 다음 중 파일의 이름을 변경할 때 사용하는 명령으로 알맞은 것은?

A) mv  
B) rename  
C) cp  
D) touch  

**정답: A**  
해설: 리눅스에는 이름 변경 전용 명령이 기본으로 없고 `mv`가 이동과 이름 변경을 겸합니다. 같은 디렉터리 안에서 `mv old.txt new.txt`처럼 쓰면 이름이 바뀌고, 다른 디렉터리를 대상으로 지정하면 이동이 됩니다.

---

**문제 4.** 다음 중 `ls -l` 결과의 맨 앞 문자가 `d`일 때 의미하는 것으로 알맞은 것은?

A) 심볼릭 링크  
B) 블록 장치 파일  
C) 일반 파일  
D) 디렉터리  

**정답: D**  
해설: `ls -l`의 첫 글자는 파일의 종류를 나타냅니다. `-`는 일반 파일, `d`는 디렉터리, `l`은 심볼릭 링크, `b`는 블록 장치, `c`는 문자 장치입니다.

---

**문제 5.** 다음 중 여러 단계의 디렉터리를 한 번에 생성할 때 사용하는 명령으로 알맞은 것은?

A) mkdir -a project/src/lib  
B) mkdir -p project/src/lib  
C) mkdir -r project/src/lib  
D) rmdir -p project/src/lib  

**정답: B**  
해설: `mkdir`은 기본적으로 중간 경로가 존재하지 않으면 오류를 냅니다. `-p`(parents) 옵션을 주면 없는 상위 디렉터리까지 함께 만들어 줍니다. `rmdir`은 디렉터리를 삭제하는 명령이며, 그것도 내용이 비어 있을 때만 동작합니다.
