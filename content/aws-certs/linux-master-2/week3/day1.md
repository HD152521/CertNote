# Day 1 - 셸 첫걸음: 명령 한 줄을 읽는 법

## 📌 핵심 정리

- 프롬프트 끝의 **`$`는 일반 사용자**, **`#`는 root**다. 이 한 글자가 권한을 말해준다.
- 명령은 **`명령어 [옵션] [인자]`** 세 토막으로 읽는다.
- 옵션은 **짧은 형(`-a`)** 과 **긴 형(`--all`)** 이 있고, 짧은 형은 **`-la`처럼 묶어 쓸 수 있다.**
- **`/`로 시작하면 절대 경로**, 아니면 현재 위치 기준의 상대 경로다. `.`=현재, `..`=상위, `~`=홈.
- 모르는 명령은 **`man 명령어`** 로 찾는다. **Tab 자동완성**과 **↑ 히스토리**가 오타를 줄여준다.

## 프롬프트 읽기

로그인하면 이런 줄이 뜬다. 이게 **프롬프트**, 명령을 기다린다는 표시다.

```text
   user@localhost:~$
    │      │      ││
    │      │      │└── $ = 일반 사용자,  # = root
    │      │      └─── 현재 디렉터리 (~ 는 홈 디렉터리)
    │      └────────── 호스트명(컴퓨터 이름)
    └───────────────── 로그인한 사용자 이름
```

- **`$`와 `#`의 구분이 가장 중요하다.** 교재나 문서에서 `#`으로 시작하는 명령은 "관리자 권한으로 실행하라"는 뜻이다.
- root로 상시 로그인하지 않는 것이 원칙이다. 필요할 때만 `sudo`로 잠깐 권한을 올린다.

## 명령의 구조

```text
   $ ls -l /home
     │   │    │
     │   │    └── 인자(argument) — 무엇에 대해
     │   └─────── 옵션(option)   — 어떻게
     └─────────── 명령어(command) — 무엇을
```

| 토막 | 설명 | 예 |
|------|------|-----|
| **명령어** | 실행할 프로그램 이름 | `ls`, `cp`, `mkdir` |
| **옵션** | 동작 방식을 바꾼다. 보통 `-`로 시작 | `-l`, `-a`, `--help` |
| **인자** | 대상. 파일명·디렉터리·문자열 | `/home`, `a.txt` |

- 셸은 **공백으로 토막을 나눈다.** 그래서 파일명에 공백이 있으면 따옴표로 묶거나 `\ `로 escape 해야 한다.
- 대소문자를 **구분한다.** `LS`는 `ls`가 아니다.

### 옵션의 두 형태

| 형태 | 모양 | 특징 |
|------|------|------|
| 짧은 형(short) | `-a` | 한 글자. **여러 개를 묶을 수 있다** → `-l -a` = `-la` |
| 긴 형(long) | `--all` | 뜻이 분명하다. 묶을 수 없다 |

```bash
ls -l -a /home     # 따로 쓰기
ls -la /home       # 묶어 쓰기 — 같은 뜻
ls --all /home     # 긴 형
```

> 함정: 긴 형은 **`--`(하이픈 두 개)** 로 시작한다. `-all`처럼 하이픈 하나로 쓰면 `-a -l -l`로 해석된다.

## 경로 읽기

| 표기 | 뜻 |
|------|-----|
| `/` | **루트 디렉터리.** 모든 경로의 시작점 |
| `.` | 현재 디렉터리 |
| `..` | 한 단계 위(상위) 디렉터리 |
| `~` | 현재 사용자의 홈 디렉터리 |
| `-` | 직전에 있던 디렉터리 (`cd -`) |

```text
   절대 경로   /home/user/docs/a.txt     ← / 로 시작. 어디서 실행하든 같은 곳
   상대 경로   docs/a.txt                ← 현재 위치 기준
              ../user2/b.txt            ← 위로 한 칸 갔다가 내려감
```

- **`/`로 시작하는가**만 보면 절대·상대가 갈린다. 이 한 줄이 시험 포인트다.

## 모를 때 찾는 법

| 명령 | 하는 일 |
|------|--------|
| `man 명령어` | **매뉴얼 페이지.** 가장 표준적인 도움말 |
| `명령어 --help` | 간단한 사용법 요약 |
| `info 명령어` | GNU의 상세 문서 |
| `whatis 명령어` | 한 줄 설명 |
| `apropos 키워드` | 키워드로 명령 **검색** |
| `which 명령어` | 실행되는 파일의 **경로** |
| `type 명령어` | 그것이 명령인지 별칭인지 내장인지 |

### man 페이지의 섹션 번호

같은 이름이 명령어이기도 하고 설정 파일이기도 할 때 섹션으로 구분한다.

| 섹션 | 내용 |
|------|------|
| **1** | 일반 사용자 명령 |
| **5** | **설정 파일 형식** |
| **8** | 시스템 관리자 명령 |

```bash
man 1 passwd      # passwd 명령
man 5 passwd      # /etc/passwd 파일의 형식
```

- `man` 안에서는 **`q`로 나가고**, 화살표·`Space`로 넘기며, `/단어`로 검색한다.

## 손이 덜 아프게 하는 습관

| 키 | 하는 일 |
|----|--------|
| **Tab** | 명령·파일명 **자동 완성**. 두 번 누르면 후보 목록 |
| **↑ / ↓** | 이전에 친 명령 불러오기 |
| `history` | 명령 기록 보기 |
| **Ctrl + C** | 실행 중인 명령 **중단** |
| **Ctrl + D** | 입력 종료 / 로그아웃 |
| **Ctrl + L** | 화면 지우기 (`clear`와 같음) |

> Tab 자동완성은 오타를 줄여줄 뿐 아니라 **경로가 맞는지 확인하는 수단**이기도 하다. 완성이 안 되면 그 경로가 없는 것이다.

> 내일은 이 문법으로 실제 파일과 디렉터리를 다루는 명령들을 익힌다.

## 📖 용어

- **프롬프트(Prompt)** : 셸이 명령을 기다린다는 표시. 사용자·호스트·현재 위치·권한을 보여준다.
- **옵션(Option)** : 명령의 동작 방식을 바꾸는 표시. `-a` 같은 짧은 형과 `--all` 같은 긴 형이 있다.
- **인자(Argument)** : 명령이 처리할 대상. 파일명이나 디렉터리 이름이 온다.
- **절대 경로** : `/`부터 시작하는 전체 경로. 현재 위치와 무관하게 같은 곳을 가리킨다.
- **상대 경로** : 현재 디렉터리를 기준으로 하는 경로.
- **홈 디렉터리** : 사용자에게 할당된 개인 디렉터리. `~`로 줄여 쓴다.
- **man 페이지** : 명령의 공식 매뉴얼. 섹션 번호로 같은 이름을 구분한다.
- **자동 완성** : Tab 키로 명령·경로의 나머지를 채워 넣는 기능.

## 📝 연습 문제

**문제 1.** 다음 중 셸 프롬프트의 마지막 문자가 `#`일 때 알 수 있는 것으로 알맞은 것은?

A) 현재 디렉터리가 홈 디렉터리다  
B) root 권한으로 로그인한 상태다  
C) 명령이 실행 중이라는 뜻이다  
D) 셸이 bash가 아닌 다른 종류다  

**정답: B**  
해설: 프롬프트 끝의 `$`는 일반 사용자를, `#`는 root(관리자)를 나타냅니다. 문서나 교재에서 `#`으로 시작하는 명령은 관리자 권한이 필요하다는 뜻입니다. 현재 디렉터리는 프롬프트의 `:` 뒤쪽에 표시되며 홈 디렉터리는 `~`로 나타냅니다.

---

**문제 2.** 다음 중 `ls -l -a` 와 같은 의미를 갖는 명령으로 알맞은 것은?

A) ls -la  
B) ls --la  
C) ls -l--a  
D) ls l a  

**정답: A**  
해설: 짧은 형 옵션은 한 글자씩이므로 `-la`처럼 하이픈 하나에 묶어 쓸 수 있습니다. 하이픈 두 개(`--`)는 `--all` 같은 긴 형 옵션에 사용하며 묶어 쓸 수 없습니다. 하이픈 없이 쓰면 옵션이 아니라 인자로 해석됩니다.

---

**문제 3.** 다음 중 절대 경로에 해당하는 것으로 알맞은 것은?

A) docs/report.txt  
B) ../user2/b.txt  
C) ./a.txt  
D) /home/user/docs/a.txt  

**정답: D**  
해설: 절대 경로는 루트 디렉터리 `/`에서 시작해 목적지까지의 전체 경로를 적은 것으로, 어느 디렉터리에서 실행하든 같은 위치를 가리킵니다. 나머지는 모두 현재 디렉터리를 기준으로 하는 상대 경로이며 `.`은 현재, `..`은 상위 디렉터리를 뜻합니다.

---

**문제 4.** 다음 중 `/etc/passwd` **파일의 형식**에 대한 매뉴얼을 보려고 할 때 알맞은 명령은?

A) man 1 passwd  
B) man 5 passwd  
C) man 8 passwd  
D) whatis passwd  

**정답: B**  
해설: man 페이지는 섹션 번호로 같은 이름을 구분합니다. 1번은 일반 사용자 명령, 5번은 설정 파일의 형식, 8번은 시스템 관리자 명령입니다. `passwd`는 비밀번호를 바꾸는 명령이자 사용자 정보를 담은 파일 이름이기도 해서, 파일 형식을 보려면 5번 섹션을 지정해야 합니다.

---

**문제 5.** 다음 중 실행 중인 명령을 강제로 중단할 때 사용하는 키 조합으로 알맞은 것은?

A) Ctrl + D  
B) Ctrl + L  
C) Ctrl + C  
D) Ctrl + Z  

**정답: C**  
해설: Ctrl + C는 현재 실행 중인 명령에 중단 신호를 보냅니다. Ctrl + D는 입력의 끝을 알려 로그아웃하거나 입력을 종료하고, Ctrl + L은 화면을 지웁니다. Ctrl + Z는 중단이 아니라 작업을 일시 정지시켜 백그라운드로 보냅니다.
