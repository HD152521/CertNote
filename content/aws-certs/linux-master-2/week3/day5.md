# Day 5 - Week 3 종합 복습: 명령어 한 장 정리

## 📌 핵심 정리

- 명령은 **`명령어 [옵션] [인자]`** 로 읽고, **`/`로 시작하면 절대 경로**다.
- **`-r`(재귀)이 필요한 것과 아닌 것**을 가른다 — `cp -r`·`rm -r`은 필요, **`mv`는 불필요**.
- **`find`는 파일을, `grep`은 내용을** 찾는다. 이 한 문장으로 두 명령을 가른다.
- `/etc/passwd`는 **콜론 7필드**, **UID 0 = root**, 비밀번호는 **`/etc/shadow`**.
- **`su`는 사용자 전환(대상 비번), `sudo`는 명령 하나(자기 비번)** — 짝으로 외운다.

## 명령어 한 장

```text
  위치          pwd · cd · ls
    │
  보기          cat(전부) · less(넘겨서) · head(앞10) · tail(뒤10) · tail -f(실시간)
    │
  만들기/지우기  touch · mkdir(-p) · rmdir(빈것만) · rm(-r, -f)
    │
  복사/이동     cp(-r 필요) · mv(-r 불필요, 이름변경 겸함) · ln(-s 심볼릭)
    │
  찾기          find(파일, 경로 먼저) · locate(색인, 빠름) · grep(내용)
    │
  세기/잇기     wc -l · | (파이프)
    │
  계정          useradd(-m) · passwd · usermod(-aG) · userdel(-r) · id · su · sudo
```

## 옵션 글자의 뜻 모으기

같은 글자가 여러 명령에서 비슷한 뜻으로 쓰인다.

| 글자 | 뜻 | 쓰이는 곳 |
|------|-----|----------|
| `-a` | all — 전부 | `ls -a`(숨김 포함), `usermod -aG`(추가) |
| `-r` / `-R` | recursive — 하위까지 | `cp -r`, `rm -r`, `grep -r`, `ls -R` |
| `-i` | 두 가지 뜻 ⚠️ | `cp -i`(확인), `grep -i`(대소문자 무시), `ls -i`(inode) |
| `-l` | long / line | `ls -l`(상세), `wc -l`(줄 수) |
| `-n` | number | `head -n`(줄 수), `grep -n`(줄 번호) |
| `-f` | force / follow ⚠️ | `rm -f`(강제), `tail -f`(따라가기) |
| `-p` | parents / preserve ⚠️ | `mkdir -p`(중간 경로), `cp -p`(속성 보존) |
| `-v` | invert | `grep -v`(일치하지 않는 줄) |

> ⚠️ 표시한 것들은 **명령마다 뜻이 다르다.** `-f`가 `rm`에서는 force인데 `tail`에서는 follow다. 이런 지점이 함정 문항으로 나온다.

### 대소문자로 갈리는 옵션

같은 글자라도 대문자와 소문자는 **전혀 다른 옵션**이다. 보기 네 개가 대소문자만 다르게 나오는 문항이 있다.

| 소문자 | 대문자 |
|--------|--------|
| `ls -r` 역순 정렬 | `ls -R` 하위 디렉터리까지 재귀 |
| `ls -a` `.`·`..` 포함 전부 | `ls -A` `.`·`..`만 빼고 전부 |
| `ls -s` 블록 수 표시 | `ls -S` 크기순 정렬 |
| `useradd -g` **기본** 그룹 | `useradd -G` **보조** 그룹 |
| `usermod -l` 로그인 이름 변경 | `usermod -L` 계정 잠금 |
| `grep -i` 대소문자 무시 | `grep -E` 확장 정규 표현식 |
| `man -k` 키워드 검색(`apropos`) | `man -f` 이름으로 한 줄 설명(`whatis`) |

## 명령 한 줄을 끝까지 읽는 연습

이번 주 내용은 명령을 **토막 내어 읽을 수 있는가**로 모인다. 아래 줄들을 왼쪽부터 끊어 읽어 본다.

```bash
find /var/log -type f -name "*.log" -mtime -7
```

- `find` 명령 / `/var/log` **시작 경로** / `-type f` 파일만 / `-name "*.log"` 이름이 `.log`로 끝나는 / `-mtime -7` **최근 7일 안에** 수정된.
- 조건을 나란히 쓰면 **모두 만족**(AND)하는 것만 나온다. 숫자 앞 `-`는 "그보다 최근", `+`는 "그보다 오래"다.

```bash
grep -v "^#" /etc/fstab | wc -l
```

- `grep -v` 일치하지 **않는** 줄 / `"^#"` `#`으로 **시작하는** / `/etc/fstab` 이 파일에서 / `|` 그 결과를 넘겨 / `wc -l` 줄 수를 센다.
- 풀어 읽으면 "주석이 아닌 줄이 몇 줄인가"다. `^`는 줄의 시작, `$`는 줄의 끝이다.

```bash
cp -rp /home/user/docs /backup/ && ls -ld /backup/docs
```

- `cp -rp` 디렉터리를 하위까지(`-r`), 권한·시각을 보존하며(`-p`) 복사 / `&&` **성공하면** / `ls -ld` 디렉터리 **자체**의 상세 정보를 본다.
- `/backup`이 이미 있는 디렉터리이므로 결과는 `/backup/docs`가 된다.

```bash
sudo useradd -m -g dev -G wheel -s /bin/bash kim
```

- `sudo` 이 명령 하나만 관리자 권한으로 / `useradd -m` 홈 디렉터리와 함께 / `-g dev` **기본** 그룹은 dev / `-G wheel` **보조** 그룹은 wheel / `-s /bin/bash` 로그인 셸 / `kim` 만들 계정 이름.
- 실행 뒤 `/etc/passwd`에는 `kim:x:UID:dev의 GID::/home/kim:/bin/bash` 형태의 줄이 생긴다. 옵션 하나하나가 일곱 필드 중 하나를 채운다.

## 이번 주에 나온 파일과 디렉터리

| 경로 | 무엇 | 기억할 점 |
|------|------|----------|
| `/etc/passwd` | 계정 기본 정보 | **7필드**, 누구나 읽음 |
| `/etc/shadow` | 암호화된 비밀번호·만료 정책 | **9필드**, root만 읽음 |
| `/etc/group` | 그룹 정보 | **4필드**, 구성원은 쉼표로 |
| `/etc/sudoers` | `sudo` 허용 설정 | **`visudo`** 로 편집 |
| `/etc/skel` | 새 홈 디렉터리에 복사될 기본 파일 | `useradd -m`이 쓴다 |
| `/etc/login.defs` | UID 범위·비밀번호 정책 기본값 | |
| `/sbin/nologin` | 로그인을 막는 셸 | 시스템 계정의 ⑦번 필드 |
| `/home/사용자` | 일반 사용자의 홈 | `~` |
| `/root` | **root의 홈** | `/`(루트 디렉터리)와 다르다 |

## "찾는" 명령과 "묻는" 명령 가르기

| 알고 싶은 것 | 명령 |
|-------------|------|
| 조건에 맞는 **파일이 어디 있나** | `find 경로 조건` |
| 이름만 알 때 **빨리** 찾기 | `locate 이름` (색인은 `updatedb`로 갱신) |
| 파일 **안에 그 글자가 있나** | `grep 패턴 파일` |
| 이 명령의 **실행 파일이 어디 있나** | `which 명령` |
| 실행 파일과 **매뉴얼 위치**까지 | `whereis 명령` |
| 이 이름이 **내장인가 별칭인가** | `type 명령` |
| 이 명령의 **사용법** | `man 명령`, `명령 --help` |
| 이 명령이 **한 줄로 무엇인가** | `whatis 명령` |
| 이런 일을 하는 **명령이 무엇인가** | `apropos 키워드` |
| **내가 누구인가** | `whoami`, `id` |
| **누가 접속해 있나** | `who`, `w` |

## 화면에서 바로 읽어 내야 하는 것

```text
[root@www ~]# ls -l /etc/passwd /tmp -d
-rw-r--r--.  1 root root 2104 Sep  3 09:00 /etc/passwd
drwxrwxrwt. 12 root root 4096 Sep  3 09:10 /tmp
```

| 자리 | 읽는 법 |
|------|--------|
| 프롬프트의 `root` · `#` | root로 로그인한 상태. 일반 사용자였다면 `$` |
| 프롬프트의 `~` | 현재 위치가 홈 디렉터리 (root이므로 `/root`) |
| 줄 맨 앞 `-` / `d` | 일반 파일 / 디렉터리 (`l` 링크, `b` 블록 장치, `c` 문자 장치) |
| 숫자 `1` / `12` | 하드 링크 수 |
| `root root` | 소유자 / 소유 그룹 |
| `2104` | 크기(바이트). `-h`를 붙이면 `2.1K`처럼 보인다 |
| `Sep  3 09:00` | **마지막 수정 시각** |

| 키 | 결과 |
|----|------|
| `Ctrl + C` | 실행 중인 명령을 **끝낸다** |
| `Ctrl + Z` | 명령을 **일시 정지**시킨다 (끝난 것이 아니다) |
| `Ctrl + D` | **입력의 끝**을 알린다 / 빈 프롬프트에서는 로그아웃 |
| `Tab` | 자동 완성, 두 번 누르면 후보 목록 |
| `q` | `man`·`less`에서 나가기 |

## 헷갈리는 짝 대조

| 구분 | A | B | 가르는 기준 |
|------|---|---|-----------|
| `find` vs `grep` | 파일을 찾는다 | **내용**을 찾는다 | 대상이 파일인가 줄인가 |
| `find` vs `locate` | 직접 탐색, 정확 | 색인 검색, **빠름** | 최신성 vs 속도 |
| `cp -r` vs `mv` | `-r` 필요 | **`-r` 불필요** | 디렉터리 처리 방식 |
| `rmdir` vs `rm -r` | **빈 것만** | 내용째 지움 | 내용이 있어도 되나 |
| `cat` vs `less` | 전부 쏟아냄 | 넘겨가며 봄 | 파일 길이 |
| `head` vs `tail` | 앞 10줄 | 뒤 10줄 | 어느 쪽 |
| `/etc/passwd` vs `/etc/shadow` | 계정 정보, 누구나 | **비밀번호, root만** | 읽기 권한 |
| `su` vs `sudo` | 사용자 전환, 대상 비번 | 명령 하나, **자기 비번** | 무엇을 입력하나 |
| `su` vs `su -` | 환경 유지 | **환경까지 전환** | 하이픈 유무 |
| `usermod -G` vs `-aG` | **덮어씀** | 추가함 | 기존 그룹 보존 |
| 하드 링크 vs 심볼릭 링크 | 같은 inode | 경로 바로가기 | 원본 삭제 시 |

## 자주 틀리는 지점

1. **`mv`에 `-r`을 붙여야 한다** → 아니다. `mv`는 디렉터리도 그냥 옮긴다. `-r`은 `cp`·`rm`에 필요하다.
2. **`find -name "*.txt" /home`** → 경로가 **먼저**다. `find /home -name "*.txt"`.
3. **`usermod -G`로 그룹 추가** → 기존 보조 그룹이 날아간다. **`-aG`** 를 써야 한다.
4. **UID 1이 root** → **0**이다.
5. **`rmdir`로 내용 있는 디렉터리 삭제** → 안 된다. `rm -r`을 써야 한다.
6. **비밀번호가 `/etc/passwd`에 있다** → **`/etc/shadow`** 에 있다. passwd의 `x`는 그 표시다.
7. **`su`에 자기 비밀번호** → **대상 계정**의 비밀번호다. 자기 것을 쓰는 건 `sudo`.
8. **숨김 파일은 별도 속성** → 아니다. **이름이 `.`으로 시작**할 뿐이다.

## 시험에 그대로 나오는 값

| 값 | 무엇 |
|-----|------|
| **7** | `/etc/passwd`의 필드 개수 |
| **`:`** | `/etc/passwd`의 구분자 |
| **0** | root의 UID |
| **1000** | 일반 사용자 UID 시작(배포판에 따라 500) |
| **10** | `head`·`tail`의 기본 줄 수 |
| **`x`** | passwd 2번 필드 — 비밀번호가 shadow에 있다는 표시 |

> 다음 주는 파일에 붙는 권한 이야기다 — rwx와 8진수, 소유권, 특수 권한을 다룬다.

## 📖 용어

- **재귀(Recursive)** : 하위 디렉터리까지 훑는 동작. `-r`/`-R` 옵션.
- **페이저(Pager)** : 긴 출력을 화면 단위로 끊어 보여주는 프로그램. `less`, `more`.
- **파이프(`|`)** : 앞 명령의 출력을 뒤 명령의 입력으로 넘기는 기호.
- **UID / GID** : 사용자·그룹을 구분하는 번호. UID 0이 root다.
- **시스템 계정** : 데몬 실행용 계정. 보통 로그인 셸이 `/sbin/nologin`이다.
- **최소 권한 원칙** : 필요한 만큼만 권한을 주는 보안 원칙. `sudo`를 권하는 이유다.

## 📝 연습 문제

**문제 1.** 다음 중 디렉터리를 옮길 때 재귀 옵션이 필요하지 **않은** 명령으로 알맞은 것은?

A) rm  
B) grep  
C) mv  
D) cp  

**정답: C**  
해설: `mv`는 디렉터리를 옮길 때도 별도의 재귀 옵션이 필요 없다. 반면 `cp`는 디렉터리를 복사하려면 `-r`이, `rm`은 내용이 있는 디렉터리를 지우려면 `-r`이 필요하다. `grep`도 하위 디렉터리까지 검색하려면 `-r`을 쓴다.

---

**문제 2.** 다음 중 파일 이름이 아니라 파일 **내용**에서 특정 문자열을 찾는 명령으로 알맞은 것은?

A) grep  
B) find  
C) locate  
D) ls  

**정답: A**  
해설: `grep`은 파일 안의 각 줄을 검사해 지정한 문자열이나 패턴이 포함된 줄을 출력한다. `find`와 `locate`는 이름·크기·시간 등의 조건으로 파일 자체를 찾는 명령이며, `ls`는 디렉터리의 목록을 보여준다.

---

**문제 3.** 다음 중 비어 있지 않은 디렉터리를 내용과 함께 삭제하는 명령으로 알맞은 것은?

A) rmdir docs  
B) rm docs  
C) mv docs /dev/null  
D) rm -r docs  

**정답: D**  
해설: `rmdir`은 비어 있는 디렉터리만 삭제할 수 있고, `rm`은 옵션 없이는 디렉터리를 지우지 못한다. 내용까지 함께 지우려면 재귀 옵션 `-r`을 붙여야 한다. `rm -rf`는 확인 없이 강제로 지우므로 특히 주의해야 한다.

---

**문제 4.** 다음 중 `/etc/passwd` 파일의 두 번째 필드에 있는 `x`가 의미하는 것으로 알맞은 것은?

A) 계정이 잠겨 있다  
B) 실제 비밀번호가 `/etc/shadow`에 있다  
C) 비밀번호가 설정되어 있지 않다  
D) 관리자 권한을 가진 계정이다  

**정답: B**  
해설: 예전에는 `/etc/passwd`의 두 번째 필드에 암호화된 비밀번호가 직접 들어 있었다. 그러나 이 파일은 누구나 읽을 수 있어 보안에 취약했기 때문에, 비밀번호를 root만 읽을 수 있는 `/etc/shadow`로 분리하고 원래 자리에는 `x`를 남겨 두었다.

---

**문제 5.** 다음 중 사용자를 전환하면서 그 사용자의 환경 변수와 작업 디렉터리까지 적용하는 명령으로 알맞은 것은?

A) sudo su  
B) su  
C) su -  
D) sudo -u  

**정답: C**  
해설: `su`만 사용하면 사용자만 바뀌고 기존 환경 변수와 작업 디렉터리가 그대로 유지된다. 하이픈을 붙인 `su -`는 해당 사용자로 새로 로그인한 것처럼 환경 설정 파일을 읽어 들여 환경 변수와 홈 디렉터리까지 전환한다.

**문제 6.** 다음 중 파일의 앞부분 5줄만 출력하는 명령으로 알맞은 것은?

A) tail -n 5 a.txt  
B) less -5 a.txt  
C) cat -5 a.txt  
D) head -n 5 a.txt  

**정답: D**  
해설: `head`는 파일의 앞부분을 출력하며 `-n` 옵션으로 줄 수를 지정한다. 옵션을 주지 않으면 기본 10줄이 출력된다. `tail`은 반대로 파일의 뒷부분을 보여주고, `cat`은 전체를 출력한다.
