# Day 5 - Week 9 종합 복습: 네트워크 한 장

## 📌 핵심 정리

- OSI 7계층 — **물데네전세표응**. **라우터 3계층, 스위치 2계층, 허브 1계층**.
- **CD는 유선(이더넷), CA는 무선(Wi-Fi)**.
- **ATM 셀은 53바이트**, **FDDI는 광케이블 이중 링 + 토큰 패싱**.
- **254 · 126 · 62 · 30 · 14 · 6 · 2** — C 클래스 서브넷 호스트 수 줄.
- **`hosts`는 답을 적어 두는 곳, `resolv.conf`는 물어볼 곳을 적어 두는 곳**.

## 네트워크 한 장

```text
   OSI 7계층                        TCP/IP        장비        단위
   ─────────────────────────────────────────────────────────────────
   7 응용    HTTP·FTP·SMTP·DNS  ┐
   6 표현    암호화·압축         ├─ 응용         게이트웨이   데이터
   5 세션    연결 관리           ┘
   4 전송    TCP · UDP · 포트    ── 전송         게이트웨이   세그먼트
   3 네트워크 IP · ICMP · ARP     ── 인터넷        라우터      패킷
   2 데이터링크 MAC · 이더넷      ┐
   1 물리    케이블·신호          ┘─ 네트워크액세스 스위치/허브  프레임/비트

   포트   21 FTP · 22 SSH · 23 TELNET · 25 SMTP · 53 DNS
          80 HTTP · 110 POP3 · 143 IMAP · 443 HTTPS

   교환   회선교환(PSTN, 전용경로) ↔ 패킷교환(PSDN, 잘라서)
          패킷교환 = 데이터그램(비연결) + 가상회선(연결)

   접근   CSMA/CD 유선 · CSMA/CA 무선 · 토큰패싱(토큰링·FDDI)

   WAN    X.25 → Frame Relay → ATM(53바이트 고정 셀)
          FDDI 광 이중링 토큰패싱 · DQDB MAN(802.6)

   IEEE   802.3 이더넷 · 802.5 토큰링 · 802.6 DQDB · 802.11 무선랜

   주소   A 1~126 · B 128~191 · C 192~223 · D 224~239(멀티캐스트)
          사설 10.x · 172.16~31.x · 192.168.x · 루프백 127.0.0.1
          호스트 수 = (256 − 마스크) − 2
```

## 서브넷 계산 한 번 더

| 마스크 | /표기 | 블록 | **호스트** |
|-------|------|------|----------|
| 255.255.255.**0** | /24 | 256 | **254** |
| 255.255.255.**128** | /25 | 128 | **126** |
| 255.255.255.**192** | /26 | 64 | **62** |
| 255.255.255.**224** | /27 | 32 | **30** |
| 255.255.255.**240** | /28 | 16 | **14** |
| 255.255.255.**248** | /29 | 8 | **6** |
| 255.255.255.**252** | /30 | 4 | **2** |

```text
   256 − 마스크 마지막 값 = 블록 크기
   블록 크기 − 2 = 쓸 수 있는 호스트 수
   256 ÷ 블록 크기 = 서브넷 개수
```

## 헷갈리는 짝 대조

| 구분 | A | B | 가르는 기준 |
|------|---|---|-----------|
| OSI vs TCP/IP | **7계층, 이론** | 4계층, 실제 | 목적 |
| 스위치 vs 라우터 | **2계층, MAC** | **3계층, IP** | 보는 주소 |
| MAC vs IP | 하드웨어, 고정 | **설정, 변경 가능** | 어디에 새겨졌나 |
| TCP vs UDP | **신뢰성, 연결형** | **속도, 비연결형** | 무엇을 우선하나 |
| 회선 vs 패킷 교환 | **PSTN**, 전용 | **PSDN**, 분할 | 경로 점유 |
| 데이터그램 vs 가상회선 | 비연결 | **연결, 순서 유지** | 경로 고정 여부 |
| CSMA/CD vs CA | **유선**, 감지 | **무선**, 회피 | 매체 |
| X.25 vs Frame Relay | 오류검사 많음, 느림 | **줄여서 빠름** | 회선 품질 전제 |
| A vs C 클래스 | 1~126 | **192~223** | 첫 옥텟 |
| `/etc/hosts` vs `resolv.conf` | **이름↔IP 답** | **물어볼 DNS 서버** | 무엇을 적나 |
| `ifconfig` vs `ip` | 옛 net-tools | **현재 iproute2** | 세대 |
| `ping` vs `traceroute` | **닿는가** | **어디서 막히나** | 알려 주는 것 |

## 자주 틀리는 지점

1. **5계층이 전송** → **4계층이 전송**, 5계층은 세션이다.
2. **스위치가 3계층** → **2계층**이다. 3계층은 라우터.
3. **UDP가 신뢰성을 보장** → 보장하지 않는다. **TCP**가 보장한다.
4. **CSMA/CA가 유선** → **CA는 무선**, **CD가 유선**이다.
5. **ATM 셀이 48바이트** → **53바이트**다. 48은 데이터 부분만이다.
6. **127이 A 클래스** → 범위에서 빠져 있다. **루프백 전용**이다.
7. **172.x 전부가 사설 IP** → **172.16 ~ 172.31** 만이다.
8. **255.255.255.192면 호스트 64개** → **62개**다. 2를 빼야 한다.
9. **255.255.255.100 같은 마스크** → 존재할 수 없다. **1이 왼쪽부터 연속**이어야 한다.
10. **DNS 서버를 `/etc/hosts`에 적는다** → **`/etc/resolv.conf`** 다.
11. **IPv6가 64비트** → **128비트**다. IPv4가 32비트.

## 시험에 그대로 나오는 값

| 값 | 무엇 |
|-----|------|
| **7 / 4** | OSI 계층 수 / TCP/IP 계층 수 |
| **53바이트** | ATM 셀 크기 |
| **62** | `/26`(255.255.255.192)의 호스트 수 |
| **32 / 128비트** | IPv4 / IPv6 주소 길이 |
| **48비트** | MAC 주소 길이 |
| **127.0.0.1** | 루프백 |
| **0~1023** | 잘 알려진 포트 범위 |
| **22 / 23 / 25 / 53 / 80 / 110** | SSH / TELNET / SMTP / DNS / HTTP / POP3 |

> 다음 주는 인터넷 서비스다. 웹·메일·DNS·원격접속·파일공유를 다룬다. **리눅스 활용 32문항 중 20문항이 이 영역**이라 가장 비중이 크다.

## 📖 용어

- **OSI 7계층** : 통신을 일곱 단계로 나눈 참조 모델. 물리부터 응용까지다.
- **CSMA/CD** : 충돌을 감지해 재전송하는 유선 이더넷 방식.
- **ATM** : 53바이트 고정 셀을 쓰는 전송 방식.
- **서브넷마스크** : 네트워크 부분과 호스트 부분을 가르는 값.
- **사설 IP** : 내부망에서만 쓰는 주소. 10, 172.16~31, 192.168 대역.
- **기본 게이트웨이** : 외부로 나가는 통신이 거치는 라우터.

## 📝 연습 문제

**문제 1.** 다음 중 OSI 7계층에서 스위치가 동작하는 계층으로 알맞은 것은?

A) 1계층  
B) 2계층  
C) 3계층  
D) 4계층  

**정답: B**  
해설: 스위치는 MAC 주소를 보고 같은 네트워크 안에서 프레임을 전달하므로 2계층인 데이터링크 계층 장비입니다. 1계층에는 리피터와 허브가, 3계층에는 IP 주소로 경로를 정하는 라우터가 있습니다.

---

**문제 2.** 다음 중 무선랜에서 사용하는 매체 접근 제어 방식으로 알맞은 것은?

A) CSMA/CD  
B) 토큰 패싱  
C) 폴링  
D) CSMA/CA  

**정답: D**  
해설: 무선 환경에서는 신호가 약해 충돌을 감지하기 어려우므로 전송 전에 충돌을 미리 피하는 CSMA/CA 방식을 사용하며 IEEE 802.11로 표준화되어 있습니다. 유선 이더넷은 충돌을 감지해 재전송하는 CSMA/CD를 씁니다.

---

**문제 3.** 다음 중 자기 자신을 가리키는 루프백 주소로 알맞은 것은?

A) 127.0.0.1  
B) 0.0.0.0  
C) 192.168.0.1  
D) 255.255.255.255  

**정답: A**  
해설: 127.0.0.1은 자기 자신을 가리키는 루프백 주소로 `localhost`라는 이름과 연결되어 있습니다. 127로 시작하는 대역 전체가 이 용도로 예약되어 있어 A 클래스의 범위에서 제외됩니다.

---

**문제 4.** C 클래스 네트워크에 서브넷마스크 255.255.255.224를 적용했을 때 하나의 서브넷에서 사용 가능한 호스트 개수로 알맞은 것은?

A) 32  
B) 62  
C) 30  
D) 14  

**정답: C**  
해설: 256에서 224를 빼면 블록 크기가 32이고, 여기서 네트워크 주소와 브로드캐스트 주소를 뺀 30개가 실제 사용 가능한 호스트 수입니다. 마스크가 192일 때는 62개, 240일 때는 14개가 됩니다.

---

**문제 5.** 다음 중 메일을 보낼 때 사용하는 SMTP의 기본 포트 번호로 알맞은 것은?

A) 21  
B) 23  
C) 25  
D) 110  

**정답: C**  
해설: SMTP는 25번 포트를 사용해 메일을 보내는 프로토콜입니다. 110번은 메일을 받아 오는 POP3, 21번은 FTP 제어, 23번은 TELNET이 사용합니다.

---

**문제 6.** 다음 중 사설 IP 주소 대역에 해당하지 **않는** 것으로 알맞은 것은?

A) 10.1.1.1  
B) 172.35.0.1  
C) 192.168.1.1  
D) 172.20.0.1  

**정답: B**  
해설: B 클래스의 사설 대역은 172.16.0.0부터 172.31.255.255까지이므로 172.35로 시작하는 주소는 공인 IP입니다. 10으로 시작하는 대역과 192.168로 시작하는 대역은 각각 A 클래스와 C 클래스의 사설 IP입니다.
