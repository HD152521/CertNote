# Day 5 - Week 4 종합 복습: 권한 한 장 정리

## 📌 핵심 정리

- 권한은 **[특수][소유자][그룹][기타]** 네 자리다. 앞자리가 0이면 생략한다.
- **r=4 w=2 x=1**, **SetUID=4 SetGID=2 Sticky=1** — **두 줄이 같은 4·2·1** 이다.
- **umask는 빼기**다. **파일은 666, 디렉터리는 777** 에서 뺀다. 기본값 022 → 644 / 755.
- **`chown`은 root만**, `chmod`는 소유자도 할 수 있다.
- **`df`는 파일 시스템, `du`는 경로.** `umount`는 n이 없다.

## 권한 한 장

```text
   chmod  4  7  5  5   file
          │  │  │  │
          │  │  │  └── other   r-x
          │  │  └───── group   r-x
          │  └──────── user    rwx
          └─────────── 특수     SetUID
                       4 SetUID · 2 SetGID · 1 Sticky

   -rws r-x r-x
    │└┬┘ └┬┘ └┬┘
    │ │   │   └── 기타
    │ │   └────── 그룹
    │ └────────── 소유자 (x 자리가 s = SetUID)
    └──────────── 파일 종류
```

```text
   umask 계산

     파일      666  -  umask
     디렉터리   777  -  umask

     022  →  파일 644 · 디렉터리 755   (기본)
     077  →  파일 600 · 디렉터리 700   (엄격)
     000  →  파일 666 · 디렉터리 777   (파일은 777이 아니다!)
```

## 8진수 변환표 — 외워 둘 것

| 숫자 | 표기 | 숫자 | 표기 |
|-----|------|-----|------|
| **7** | `rwx` | 3 | `-wx` |
| **6** | `rw-` | **2** | `-w-` |
| **5** | `r-x` | 1 | `--x` |
| **4** | `r--` | 0 | `---` |

| 권한값 | 표기 | 쓰이는 곳 |
|-------|------|----------|
| **644** | `rw-r--r--` | 일반 파일 |
| **755** | `rwxr-xr-x` | 디렉터리·실행 파일 |
| **600** | `rw-------` | 비밀 키 |
| **1777** | `rwxrwxrwt` | **`/tmp`** |
| **4755** | `rwsr-xr-x` | **`/usr/bin/passwd`** |

## 헷갈리는 짝 대조

| 구분 | A | B | 가르는 기준 |
|------|---|---|-----------|
| 파일의 `x` vs 디렉터리의 `x` | 실행 | **진입(`cd`)** | 대상이 무엇인가 |
| 파일의 `r` vs 디렉터리의 `r` | 내용 읽기 | **목록 보기** | 〃 |
| `chmod 755` vs `chmod u+x` | **전체를 덮어씀** | 지금 상태에 더함 | 기존 권한 보존 |
| `chown` vs `chgrp` | 소유자 | 그룹 | 무엇을 바꾸나 |
| `chown` vs `chmod` | **root만** | 소유자도 가능 | 누가 할 수 있나 |
| SetUID vs SetGID | 소유자 권한 | 그룹 권한 / **그룹 상속** | 어느 자리의 s |
| SetGID(파일) vs SetGID(디렉터리) | 그룹 권한 실행 | **그룹 물려주기** | 대상이 무엇인가 |
| Sticky vs 일반 `w` | **자기 것만 삭제** | 남의 것도 삭제 | 삭제 제한 여부 |
| `s` vs `S` | x 권한 **있음** | x 권한 없음 | 대소문자 |
| `df` vs `du` | **파일 시스템** 용량 | **경로별** 사용량 | 무엇을 세나 |
| `/bin` vs `/sbin` | 일반 명령 | **관리자 명령** | 누가 쓰나 |
| `/` vs `/root` | 최상위 | **root의 홈** | 위치 |
| `/mnt` vs `/media` | 수동 마운트 | 이동식 매체 | 자동 여부 |

## 자주 틀리는 지점

1. **umask 000이면 파일이 777** → 아니다. 파일 기준값이 **666**이라 **666**이다. 777이 되는 건 디렉터리다.
2. **umask는 더하기** → **빼기**다. 값이 클수록 권한이 좁아진다.
3. **디렉터리의 x는 실행** → **진입**이다. `x`가 없으면 `cd` 가 안 된다.
4. **읽기 전용 파일은 못 지운다** → 지울 수 있다. 삭제는 **파일이 아니라 그 디렉터리의 `w`** 가 결정한다. 이걸 막는 게 Sticky bit다.
5. **소유자면 무조건 다 된다** → 아니다. 권한은 **user 칸 하나만** 적용된다. 소유자 칸이 좁으면 소유자가 못 읽는다.
6. **자기 파일을 남에게 넘길 수 있다** → `chown`은 **root만** 가능하다.
7. **`unmount`** → **`umount`** 다. n이 없다.
8. **`fsck`를 마운트한 채 실행** → 손상 위험이 있다. **반드시 언마운트** 후에 한다.
9. **특수 권한 순서를 1·2·4로** → **4(SetUID)·2(SetGID)·1(Sticky)** 다. rwx와 같은 순서로 외운다.

## 시험에 그대로 나오는 값

| 값 | 무엇 |
|-----|------|
| **4 / 2 / 1** | r / w / x, 그리고 SetUID / SetGID / Sticky |
| **022** | 일반적인 기본 umask |
| **666 / 777** | umask 계산의 기준값 (파일 / 디렉터리) |
| **644 / 755** | umask 022 의 결과 |
| **1777** | `/tmp` 의 권한 |
| **4755** | `/usr/bin/passwd` 의 권한 |
| **`s` / `t`** | SetUID·SetGID / Sticky bit 의 표시 문자 |

> 다음 주는 명령을 받아 해석하는 프로그램 자체 — **셸**을 다룬다. 환경 변수, 리다이렉션, 별칭이 나온다.

## 📖 용어

- **특수 권한 자리** : 권한 네 자리 중 맨 앞자리. 0이면 생략해 세 자리로 쓴다.
- **umask** : 새 파일·디렉터리의 권한에서 깎아낼 값. 파일 666, 디렉터리 777이 기준이다.
- **SetUID / SetGID / Sticky bit** : 각각 4·2·1 값을 갖는 특수 권한.
- **마운트 포인트** : 파일 시스템이 붙는 디렉터리.
- **FHS** : 디렉터리의 이름과 역할을 정한 파일 시스템 계층 표준.
- **inode 고갈** : 용량은 남았지만 파일을 더 만들 수 없는 상태. `df -i`로 확인한다.

## 📝 연습 문제

**문제 1.** 다음 중 `chmod 1777 /shared` 명령으로 설정되는 특수 권한으로 알맞은 것은?

A) SetUID  
B) Sticky bit  
C) SetGID  
D) 특수 권한 없음  

**정답: B**  
해설: 네 자리 권한에서 맨 앞자리가 특수 권한이며 1은 Sticky bit입니다. Sticky bit가 걸린 디렉터리에서는 파일의 소유자와 root만 그 파일을 삭제할 수 있습니다. `/tmp`가 바로 이 1777 권한을 사용합니다.

---

**문제 2.** umask 값이 000일 때 새로 생성되는 일반 파일의 권한으로 알맞은 것은?

A) 777  
B) 755  
C) 644  
D) 666  

**정답: D**  
해설: 파일의 기준값은 666이므로 umask가 0이어도 666을 넘지 못합니다. 새로 만드는 파일에 실행 권한을 자동으로 주지 않기 위한 설계입니다. 디렉터리는 기준값이 777이므로 같은 조건에서 777이 됩니다.

---

**문제 3.** 다음 중 파일 자체에는 쓰기 권한이 없어도 그 파일을 삭제할 수 있게 하는 조건으로 알맞은 것은?

A) 해당 파일이 있는 디렉터리에 쓰기 권한이 있을 때  
B) 해당 파일에 읽기 권한이 있을 때  
C) 해당 파일에 실행 권한이 있을 때  
D) 해당 파일의 그룹에 속해 있을 때  

**정답: A**  
해설: 파일 삭제는 파일 자체의 권한이 아니라 그 파일이 들어 있는 디렉터리의 쓰기 권한으로 결정됩니다. 디렉터리에서 항목을 지우는 동작이기 때문입니다. 이 때문에 공유 디렉터리에서 남의 파일이 지워지는 것을 막으려면 Sticky bit를 설정합니다.

---

**문제 4.** 다음 중 관리자용 명령어가 주로 저장되는 디렉터리로 알맞은 것은?

A) /bin  
B) /lib  
C) /sbin  
D) /opt  

**정답: C**  
해설: `/sbin`에는 `fdisk`, `shutdown`처럼 시스템 관리에 사용하는 명령이 들어 있습니다. `/bin`은 `ls`, `cp`처럼 일반 사용자도 쓰는 기본 명령을, `/lib`은 공유 라이브러리를, `/opt`는 추가로 설치한 패키지를 담습니다.

---

**문제 5.** 다음 중 `-rwxr-sr-x` 권한 표기가 나타내는 상태로 알맞은 것은?

A) SetUID가 설정되어 있다  
B) Sticky bit가 설정되어 있다  
C) 그룹에 실행 권한이 없다  
D) SetGID가 설정되어 있다  

**정답: D**  
해설: 그룹 자리의 실행 권한이 `s`로 표시된 것은 SetGID가 설정되었다는 뜻입니다. 소문자 `s`이므로 실행 권한도 함께 있는 상태입니다. 소유자 자리의 `s`는 SetUID, 기타 자리의 `t`는 Sticky bit를 나타냅니다.

---

**문제 6.** 다음 중 특정 디렉터리가 차지하는 전체 용량을 합계로 확인하는 명령으로 알맞은 것은?

A) du -sh /var/log  
B) df -h /var/log  
C) ls -lh /var/log  
D) fsck /var/log  

**정답: A**  
해설: `du`는 경로별 사용량을 계산하며 `-s`는 하위 항목을 나열하지 않고 합계만 내는 옵션, `-h`는 읽기 쉬운 단위로 표시하는 옵션입니다. `df`는 파일 시스템 단위의 전체 용량을 보여 주는 명령이라 특정 디렉터리의 사용량 합계와는 다릅니다.
