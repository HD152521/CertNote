# 🏆 AWS Certified Solutions Architect - Associate (SAA-C03) 12주 학습 커리큘럼

> **목표**: AWS Certified Solutions Architect - Associate 자격증 취득
> **총 학습 기간**: 12주 × 5일 = 60일
> **타겟**: 개발자/엔지니어 출퇴근 학습 (하루 10-20분 핵심 / 주말 심화)

---

## 📋 시험 정보

| 항목 | 내용 |
|------|------|
| 시험 코드 | SAA-C03 |
| 시험 시간 | 130분 |
| 문제 수 | 65문제 |
| 합격 점수 | 720점 (1000점 만점) |
| 시험 비용 | $150 USD |
| 시험 형식 | 객관식(단일/복수), 시나리오형 위주 |

## 📊 시험 도메인 및 비중

| 도메인 | 내용 | 비중 |
|--------|------|------|
| 도메인 1 | 보안 아키텍처 설계 (Design Secure Architectures) | 30% |
| 도메인 2 | 복원력 있는 아키텍처 설계 (Design Resilient Architectures) | 26% |
| 도메인 3 | 고성능 아키텍처 설계 (Design High-Performing Architectures) | 24% |
| 도메인 4 | 비용 최적화 아키텍처 설계 (Design Cost-Optimized Architectures) | 20% |

> 🎯 SAA는 "어떤 서비스를 골라야 가장 안전/탄력적/빠르고 저렴한가?" 를 묻는 시나리오 시험입니다.

## 📚 학습 방법

1. **출퇴근 시간 (15-20분)**: 각 day.md의 학습 목표 + 핵심 포인트 + 연습문제만 훑기
2. **저녁 30분**: 이론 + 심화 정독
3. **주말**: AWS 콘솔에서 직접 실습 + 약점 다시보기
4. **매주 금요일**: 그 주 복습 + 시나리오 문제 풀이
