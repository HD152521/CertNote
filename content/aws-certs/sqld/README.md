# 🗄️ SQLD 8주 학습 커리큘럼

> **목표**: SQL 개발자(SQLD, 한국데이터산업진흥원 주관, 국가공인) 취득
> **총 학습 기간**: 8주 × 5일 = 40일
> **타겟**: SQL 을 처음 배우거나, 써 봤지만 시험 문법(Oracle)이 낯선 학습자
> **핵심**: 배점의 80%가 2과목(SQL)이라 6주를 SQL 에 쓴다. 노트의 예제 결과표는 모두 실제 Oracle 에서 실행해 붙였다.
