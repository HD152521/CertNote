# Day 3 - AWS AI 서비스 (1): 이미지·문서·텍스트·음성을 다루는 관리형 API

지금까지 본 Bedrock과 SageMaker는 "모델 자체"를 다루는 서비스였다. 오늘 보는 서비스들은 결이 다르다. **모델을 만들거나 고를 필요조차 없이, API 한 번 호출로 특정 작업을 끝내주는** 관리형 AI 서비스들이다. AWS는 이를 "AI Services"라고 부른다.

이들은 AWS가 미리 학습시켜 둔 모델을 뒤에 숨겨두고, "이미지에서 글자 찾기", "음성을 텍스트로" 같은 **완성된 기능**만 노출한다. AIF-C01 시험은 "이 작업에는 어떤 서비스?"를 집요하게 묻는다. 오늘은 6개 핵심 서비스의 **용도**를 정확히 외우는 게 목표다.

## 한눈에 보는 6개 서비스

| 서비스 | 입력 → 출력 | 한 줄 용도 |
|--------|-------------|------------|
| Rekognition | 이미지/영상 → 분석 결과 | 객체·얼굴·텍스트·부적절 콘텐츠 탐지 |
| Textract | 문서 이미지 → 구조화 텍스트 | 문서에서 글자·표·양식 추출(OCR+) |
| Comprehend | 텍스트 → 의미 분석 | 감정·개체·핵심구·언어 분석(NLP) |
| Transcribe | 음성 → 텍스트 | 음성 인식(STT) |
| Polly | 텍스트 → 음성 | 음성 합성(TTS) |
| Translate | 텍스트 → 번역 텍스트 | 언어 간 번역 |

이 표가 오늘의 핵심이다. 각각을 조금 더 들여다보자.

## Rekognition: 이미지와 영상을 보는 눈

**Amazon Rekognition**은 이미지·영상을 분석하는 컴퓨터 비전 서비스다.

- **객체·장면 탐지**: 사진에 무엇이 있는지(자동차, 강아지, 해변).
- **얼굴 분석·비교**: 얼굴 감지, 두 얼굴이 같은 사람인지 비교, 표정·연령대 추정.
- **텍스트 추출**: 이미지 속 글자 읽기(간판, 번호판).
- **부적절 콘텐츠 탐지(content moderation)**: 폭력·선정적 이미지 필터링.
- **유명인 인식, 라벨링** 등.

> 📚 **사례**: 한 SNS 플랫폼은 사용자가 올리는 수백만 장의 이미지에서 부적절 콘텐츠를 사람이 일일이 검수했다. Rekognition의 content moderation API로 1차 자동 필터링을 도입하자, 사람은 애매한 경우만 검토하면 되어 검수 인력이 크게 줄었다. "이미지/영상을 이해해야 한다"는 단서가 나오면 Rekognition이다.

## Textract: 문서를 진짜로 읽기

**Amazon Textract**는 단순 OCR을 넘어선다. 일반 OCR이 "글자만" 뽑는다면, Textract는 **표(table)와 양식(form)의 구조까지** 이해한다. 청구서에서 "총액: $1,200" 같은 키-값 쌍을 인식하고, 표를 행·열로 정확히 추출한다.

> 💡 **관련 이론**: Rekognition도 이미지 속 텍스트를 읽지만, Textract는 **문서 처리**에 특화되어 있다. 영수증, 세금 양식, 보험 청구서, 신분증처럼 "구조가 있는 문서"에서 데이터를 뽑아 자동 처리하는 게 목적이다. 시험에서 "스캔한 청구서/양식에서 필드를 추출해 자동 입력"이면 Textract, "사진 속 객체나 얼굴 분석"이면 Rekognition으로 가른다.

## Comprehend: 텍스트의 의미를 파악

**Amazon Comprehend**는 자연어 처리(NLP) 서비스로, 텍스트의 의미를 분석한다.

- **감정 분석(sentiment)**: 긍정/부정/중립.
- **개체 인식(entity)**: 사람·장소·날짜·조직 추출.
- **핵심 구(key phrase)**, **언어 감지**, **주제 모델링**.
- **PII 탐지**: 텍스트 속 개인정보 식별.

의료 텍스트에 특화된 **Comprehend Medical**도 있다.

> 🔍 **더 깊이**: Comprehend는 "텍스트가 이미 있을 때" 그 의미를 분석한다. 고객 리뷰 수천 건의 감정을 자동 집계하거나, 문서에서 사람·날짜를 뽑아 색인하는 식이다. "텍스트의 감정/개체/언어를 분석"이라는 단서가 핵심 신호다.

## Transcribe & Polly: 음성과 텍스트를 오가다

이 둘은 서로 반대 방향이다.

- **Amazon Transcribe (STT, Speech-to-Text)**: 음성 → 텍스트. 회의 녹음 받아쓰기, 콜센터 통화 기록, 자막 생성. 화자 분리(누가 말했는지)도 지원.
- **Amazon Polly (TTS, Text-to-Speech)**: 텍스트 → 음성. 자연스러운 사람 목소리로 글을 읽어준다. 오디오북, 음성 안내, 접근성.

| 구분 | Transcribe | Polly |
|------|-----------|-------|
| 방향 | 음성 → 텍스트 | 텍스트 → 음성 |
| 약어 | STT | TTS |
| 활용 | 자막, 통화 기록 | 음성 안내, 오디오북 |

> 📚 **사례**: 한 콜센터는 Transcribe로 통화를 텍스트로 변환하고, 그 텍스트를 Comprehend에 넣어 고객 감정을 분석했다. 불만 신호가 강한 통화를 자동 플래그해 관리자에게 알렸다. 여러 AI 서비스를 **파이프라인으로 연결**한 전형적 예다(음성→텍스트→감정).

## Translate: 언어의 장벽 넘기

**Amazon Translate**는 신경망 기반 기계 번역 서비스다. 텍스트를 한 언어에서 다른 언어로 실시간 번역한다. 다국어 웹사이트, 고객 지원 메시지 번역, 실시간 채팅 통역 등에 쓴다.

Translate 역시 다른 서비스와 자주 결합한다. 예를 들어 외국어 음성을 Transcribe로 받아쓰고 → Translate로 번역하고 → Polly로 다시 음성으로 내보내면 간단한 통역 파이프라인이 된다.

> 💡 **관련 이론**: 이 6개 서비스의 공통점은 **"사전학습된 모델을 API로 노출"**한다는 것이다. 사용자는 ML 지식 없이 즉시 쓸 수 있다. 단, 매우 특수한 도메인(예: 전문 의료 용어, 자사 고유 제품명)은 일반 모델이 약할 수 있어, 일부 서비스는 **커스텀 모델/사용자 사전** 기능을 제공한다. 그래도 "직접 학습"이 필요한 수준이면 SageMaker로 넘어가야 한다.

## 정리하며

오늘의 핵심은 **용도 매핑**이다. 이미지·영상은 **Rekognition**, 문서(양식·표) 추출은 **Textract**, 텍스트 의미 분석(NLP)은 **Comprehend**, 음성→텍스트는 **Transcribe**, 텍스트→음성은 **Polly**, 번역은 **Translate**. 그리고 이들은 **파이프라인으로 연결**해 더 강력한 흐름(통화→텍스트→감정, 음성→번역→음성)을 만들 수 있다.

다음 글에서는 나머지 AI 서비스들(Lex, Kendra, Personalize, Forecast)과 **Amazon Q**를 보고, 전체 서비스를 "어떤 작업에 무엇을" 고르는 기준으로 묶는다.

## 📝 연습 문제

**문제 1.** 사용자가 업로드한 사진에서 객체와 얼굴을 감지하고 부적절한 콘텐츠를 자동으로 걸러내려 한다. 가장 적합한 서비스는?

A) Amazon Comprehend  
B) Amazon Rekognition  
C) Amazon Polly  
D) Amazon Translate  

**정답: B**  
해설: Rekognition은 이미지·영상에서 객체·얼굴 탐지와 부적절 콘텐츠 검열을 제공하는 컴퓨터 비전 서비스다. A는 텍스트 NLP, C는 음성 합성, D는 번역으로 이미지 분석과 무관하다.

---

**문제 2.** 스캔한 청구서 이미지에서 "총액", "날짜" 같은 키-값 쌍과 표 데이터를 구조화해 추출하려 한다. 가장 적합한 서비스는?

A) Amazon Textract  
B) Amazon Transcribe  
C) Amazon Rekognition  
D) Amazon Polly  

**정답: A**  
해설: Textract는 문서에서 글자뿐 아니라 표와 양식의 키-값 구조까지 추출하는 문서 처리 서비스다. C(Rekognition)도 이미지 속 텍스트를 읽지만 문서의 구조화 추출에는 Textract가 특화되어 있다. B는 음성 인식, D는 음성 합성으로 무관하다.

---

**문제 3.** 고객 리뷰 수천 건이 긍정인지 부정인지 자동으로 분류하고, 텍스트에서 사람·장소 같은 개체를 추출하려 한다. 적합한 서비스는?

A) Amazon Translate  
B) Amazon Comprehend  
C) Amazon Textract  
D) Amazon Lex  

**정답: B**  
해설: Comprehend는 감정 분석, 개체 인식, 핵심 구 추출 등 텍스트 의미 분석(NLP)을 제공한다. A는 번역, C는 문서 추출이며, D(Lex)는 챗봇 구축 서비스로 대량 텍스트 의미 분석이 본업이 아니다.

---

**문제 4.** 콜센터 통화 녹음을 텍스트로 변환한 뒤, 그 텍스트의 고객 감정을 분석하려 한다. 어떤 서비스 조합이 적절한가?

A) Polly → Translate  
B) Transcribe → Comprehend  
C) Rekognition → Textract  
D) Translate → Polly  

**정답: B**  
해설: Transcribe로 음성을 텍스트(STT)로 바꾸고, 그 텍스트를 Comprehend로 감정 분석하는 파이프라인이 적절하다. A는 텍스트를 음성으로 만든 뒤 번역하는 비논리적 순서다. C는 이미지·문서용, D는 번역 후 음성 합성으로 통화 감정 분석과 맞지 않는다.

---

**문제 5.** 웹사이트의 안내 텍스트를 자연스러운 사람 목소리의 음성으로 변환해 들려주려 한다. 가장 적합한 서비스는?

A) Amazon Transcribe  
B) Amazon Polly  
C) Amazon Comprehend  
D) Amazon Rekognition  

**정답: B**  
해설: Polly는 텍스트를 자연스러운 음성으로 합성하는 TTS 서비스다. A(Transcribe)는 반대로 음성을 텍스트로 바꾸는 STT다. C는 텍스트 의미 분석, D는 이미지 분석으로 음성 합성과 무관하다.
