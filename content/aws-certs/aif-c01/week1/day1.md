# Day 1 - AI·머신러닝·딥러닝의 관계와 차이

## 📌 핵심 정리

- **AI ⊃ 머신러닝 ⊃ 딥러닝** — 큰 원 안에 작은 원이 든 포함 관계다.
- **AI**: 지능적 행동을 흉내 내는 모든 기술. 사람이 규칙을 직접 적는 방식도 포함한다.
- **머신러닝**: 규칙을 사람이 적지 않고 **데이터에서 학습**하는 방법.
- **딥러닝**: 신경망을 여러 층으로 깊게 쌓은 머신러닝의 한 종류. 대량 데이터와 GPU가 필요하다.
- 모든 딥러닝은 머신러닝이지만, **모든 AI가 머신러닝인 것은 아니다**. 생성형 AI·에이전틱 AI도 딥러닝 원 안의 응용이다.

## 세 개념의 포함 관계

**AI / ML / DL**은 뉴스나 광고에서 같은 말처럼 쓰이지만, 실제로는 큰 원 안에 작은 원이 든 포함 관계다.

![AI 안에 머신러닝이, 머신러닝 안에 딥러닝이 포함된 관계도](/diagrams/ai-ml-dl-nesting.svg)

- **인공지능(AI)**: 가장 넓은 개념. 인간의 지능적 행동을 흉내 내는 모든 기술.
- **머신러닝(ML)**: AI를 구현하는 한 가지 방법. 데이터로부터 규칙을 "학습"하는 기술.
- **딥러닝(DL)**: 머신러닝의 한 종류. 인공 신경망을 여러 층으로 쌓아 학습하는 기술.

## 1. 인공지능(AI)이란

- 목표: 기계가 사람처럼 생각하거나 행동하도록 만드는 것 — 가장 넓은 분야다.
- 머신러닝뿐 아니라 **사람이 규칙을 하나하나 적어 넣는 방식(규칙 기반 시스템)**도 포함한다.
- 예: "온도가 28도를 넘으면 에어컨을 켜라"로만 동작하는 자동 온도조절기 → 데이터로 학습하지 않아도 넓은 의미의 AI 초기 형태.

> 💡 **관련 이론**: AI라는 용어는 1956년 다트머스 회의에서 처음 공식적으로 사용되었습니다. 초기 AI는 대부분 사람이 규칙을 직접 정의하는 "규칙 기반(expert system)" 방식이었습니다.

## 2. 머신러닝(ML)이란

- 사람이 규칙을 일일이 적는 대신, **데이터를 보여주고 기계가 스스로 규칙(패턴)을 찾게** 하는 방법이다.

| 구분 | 규칙 기반 프로그래밍 | 머신러닝 |
|------|---------------------|----------|
| 규칙을 만드는 주체 | 사람 | 데이터로부터 기계가 학습 |
| 입력 | 데이터 + 규칙 | 데이터 + 정답(예시) |
| 출력 | 결과 | 규칙(모델) |
| 새로운 상황 적응 | 규칙을 다시 짜야 함 | 새 데이터로 다시 학습 가능 |

**스팸 메일 걸러내기 예시**

- 규칙 기반: "제목에 '무료'가 있으면 스팸"처럼 사람이 조건을 직접 적는다 → 발송자가 표현을 바꾸면 규칙도 계속 고쳐야 한다.
- 머신러닝: 수만 통의 스팸/정상 메일을 보여주면 어떤 특징이 스팸인지 스스로 학습한다.

> 💡 **관련 이론**: 머신러닝의 고전적 정의는 "명시적으로 프로그래밍하지 않아도 컴퓨터가 학습할 수 있게 하는 연구 분야"(아서 새뮤얼, 1959)입니다.

## 3. 딥러닝(DL)이란

- **인공 신경망(neural network)**을 여러 층(deep, 깊게) 쌓아 복잡한 패턴을 학습한다. 사람 뇌의 뉴런 구조에서 아이디어를 얻었다.
- 이미지·음성·자연어처럼 매우 복잡하고 비정형적인 데이터에서 특히 강력하다.
- 대신 이런 부담이 따른다.
  - **많은 데이터**가 필요하다.
  - **강력한 연산 자원(GPU 등)**이 필요하다.
  - 학습 과정이 "블랙박스"처럼 보여 결과를 사람이 이해하기 어려울 때가 많다.
- 오늘날 화제인 **생성형 AI(ChatGPT, 이미지 생성 등)**도 모두 딥러닝 기반이다 → 이후 주차에서 더 자세히 다룬다.

> 💡 **관련 이론**: 딥러닝이 주류가 된 결정적 계기는 2012년 이미지 인식 대회(ImageNet)에서 신경망 기반 모델이 압도적 성능을 보인 사건입니다. 대량의 데이터와 GPU 연산의 결합이 핵심이었습니다.

## 일상 속 사례로 정리하기

| 사례 | 분류 | 이유 |
|------|------|------|
| 규칙으로 동작하는 자동 온도조절기 | AI(머신러닝 아님) | 사람이 만든 규칙으로만 동작 |
| 이메일 스팸 필터 | 머신러닝 | 데이터로 스팸 패턴을 학습 |
| 스마트폰 얼굴 인식 잠금 해제 | 딥러닝 | 신경망으로 얼굴 이미지 인식 |
| 음성 비서(시리, 알렉사)의 음성 인식 | 딥러닝 | 신경망으로 음성을 텍스트로 변환 |
| 쇼핑몰 상품 추천 | 머신러닝 | 구매 데이터로 취향 패턴 학습 |

## 같은 문제를 세 방식으로 풀어 보기

"사진에 고양이가 있는가"라는 한 문제를 세 방식에 맡기면 **누가 무엇을 정하는지**가 달라진다.

| 방식 | 사람이 하는 일 | 기계가 하는 일 | 한계 |
|------|---------------|---------------|------|
| 규칙 기반 | "귀가 뾰족하고 수염이 있으면 고양이" 같은 조건을 전부 적는다 | 적힌 조건을 그대로 검사한다 | 각도·조명이 바뀌면 조건이 무너진다 |
| 전통적 머신러닝 | 귀 모양·털 색 비율처럼 **무엇을 볼지**(특성)를 골라 숫자로 뽑아 준다 | 그 숫자들과 정답의 관계를 학습한다 | 사람이 고른 특성이 나쁘면 성능도 나쁘다 |
| 딥러닝 | 사진과 정답만 잔뜩 준다 | **무엇을 볼지까지** 층을 거치며 스스로 찾아낸다 | 데이터·연산이 많이 들고 이유를 설명하기 어렵다 |

- 머신러닝과 딥러닝을 가르는 실질적 차이는 "신경망을 쓰느냐"보다 **특성을 사람이 설계하느냐, 모델이 원본 데이터에서 직접 배우느냐**다.
- 앞쪽 층은 선·모서리 같은 단순한 모양을, 뒤쪽 층은 눈·귀 같은 복잡한 모양을 잡는 식으로 단계가 쌓인다. "깊다(deep)"는 이 층이 많다는 뜻이다.

| 비교 축 | 전통적 머신러닝 | 딥러닝 |
|---------|----------------|--------|
| 잘 맞는 데이터 | 표 형태(정형) 데이터 | 이미지·음성·문장 같은 비정형 데이터 |
| 필요한 데이터 양 | 비교적 적어도 동작 | 많을수록 좋고, 적으면 힘을 못 쓴다 |
| 연산 자원 | 일반 서버로도 가능 | GPU 등 대량 병렬 연산 |
| 결과 설명 | 비교적 쉽다 | 어렵다(블랙박스) |
| 어울리는 예 | 고객 이탈 예측, 대출 심사 점수 | 얼굴 인식, 음성 받아쓰기, 번역 |

## 생성형 AI와 에이전틱 AI는 어디에 들어가나

시험 가이드는 AI·ML·딥러닝에 더해 **생성형 AI**(GenAI)와 **에이전틱 AI**(agentic AI)까지 묶어 차이를 묻는다. 둘 다 원 밖의 새 분야가 아니라 **딥러닝 원 안에서 자라난 응용**이다.

| 용어 | 포함 관계에서의 위치 | 한 줄 구분 | 예 |
|------|---------------------|-----------|-----|
| AI | 가장 바깥 원 | 지능적 행동을 흉내 내는 기술 전체 | 규칙 기반 챗봇, 아래 전부 |
| 머신러닝 | AI 안 | 데이터에서 규칙을 학습 | 스팸 필터, 수요 예측 |
| 딥러닝 | 머신러닝 안 | 여러 층의 신경망으로 학습 | 얼굴 인식, 음성 인식 |
| 생성형 AI | 딥러닝 안 | 고르거나 맞히는 대신 **새 콘텐츠를 만든다** | 글 초안 작성, 이미지 생성, 요약 |
| 에이전틱 AI | 생성형 AI 모델을 두뇌로 사용 | 답을 내놓는 데서 멈추지 않고 **목표를 향해 스스로 여러 단계를 실행한다** | 일정 조회 → 예약 → 확인 메일 발송까지 처리하는 비서 |

- 기존 머신러닝 모델은 주로 "스팸인가 아닌가", "얼마인가"처럼 **정해진 형태의 답**을 낸다. 생성형 AI는 문장·이미지처럼 **형태가 열린 결과물**을 만든다.
- AWS는 에이전틱 AI를 "미리 정한 목표를 이루기 위해 독립적으로 행동할 수 있는 자율 AI 시스템"으로 설명한다. 사람이 단계마다 지시하지 않아도 계획을 세우고 도구를 불러 쓴다는 점이 일반 챗봇과 다르다.
- 두 주제는 Week 3 이후에 본격적으로 다룬다. 지금은 **원 안의 위치**만 잡아 두면 된다.

> ⚠️ **함정**: **컴퓨터 비전**과 **자연어 처리**(NLP)는 포함 관계의 한 층이 아니라 "무엇에 쓰느냐"로 붙인 **응용 분야 이름**이다. 이미지를 다루면 컴퓨터 비전, 사람 말을 다루면 NLP이고, 둘 다 오늘날 대부분 딥러닝으로 구현한다. AWS 서비스로는 이미지·영상 분석의 Amazon Rekognition, 텍스트 분석의 Amazon Comprehend, 음성을 글로 옮기는 Amazon Transcribe가 각 분야의 대표다.

## 지문의 단서로 판별하기

| 지문에 이런 표현이 나오면 | 가리키는 것 | 근거 |
|--------------------------|------------|------|
| "담당자가 조건을 if-then으로 정의했다" | AI(규칙 기반), 머신러닝 아님 | 학습 과정이 없다 |
| "과거 거래 데이터로 학습해 패턴을 찾는다" | 머신러닝 | 데이터에서 규칙을 얻는다 |
| "표 형태의 고객 데이터, 수천 건" | 전통적 머신러닝으로 충분 | 정형·소량이면 딥러닝의 이점이 작다 |
| "여러 층의 신경망", "이미지·음성 원본을 그대로 입력" | 딥러닝 | 비정형 데이터에서 특성을 스스로 학습 |
| "새 문장·이미지·코드를 만들어 낸다" | 생성형 AI | 출력이 새 콘텐츠다 |
| "목표를 주면 계획을 세워 도구를 호출하며 작업을 끝낸다" | 에이전틱 AI | 자율적인 다단계 실행 |

## 흔한 오해 바로잡기

- **"AI = 머신러닝"** → 규칙 기반 시스템처럼 학습이 없는 AI도 있다. 보기에서 "모든 AI는 데이터로 학습한다"는 틀린 문장이다.
- **"신경망을 쓰면 다 딥러닝"** → 층이 얕은 신경망도 있다. 딥러닝이라 부르는 조건은 **층을 여러 겹 쌓았다**는 것이다.
- **"딥러닝이 항상 더 정확하다"** → 데이터가 적거나 표 형태면 단순한 머신러닝이 더 낫고 싸고 설명하기도 쉽다.
- **"생성형 AI는 머신러닝과 별개의 기술"** → 딥러닝으로 만든 모델이므로 머신러닝이고 AI다. 포함 관계는 그대로 유지된다.
- **"에이전틱 AI는 생성형 AI의 다른 이름"** → 생성형 AI는 콘텐츠를 **만드는** 능력, 에이전틱 AI는 그 능력을 써서 **일을 수행하는** 시스템이다.

## 왜 이 구분이 중요한가

- 시험: "이 시나리오는 어떤 기술에 해당하는가?", "딥러닝이 머신러닝과 다른 점은?" 형태로 나온다.
- 실무: "우리 문제에 꼭 딥러닝이 필요한가, 단순한 머신러닝이나 규칙으로 충분한가"를 판단하는 기초가 된다.
- **더 복잡한 기술이 항상 더 좋은 것은 아니다** — 간단한 문제는 간단한 방법으로 푸는 쪽이 비용·유지보수에 유리하다.

## 📖 용어

- **인공지능(AI)** : 사람처럼 생각하거나 행동하는 것을 흉내 내는 기술 전체를 묶어 부르는 말.
- **머신러닝(ML)** : 사람이 규칙을 적어주지 않고, 데이터를 보여줘서 기계가 규칙을 찾아내게 하는 방법.
- **딥러닝(DL)** : 신경망을 여러 층으로 깊게 쌓아 학습하는 머신러닝. 이미지·음성·언어에 강하다.
- **규칙 기반 시스템** : "이러면 저렇게 하라"는 조건을 사람이 전부 직접 적어 넣은 프로그램. 학습 과정이 없다.
- **인공 신경망** : 사람 뇌의 뉴런을 흉내 낸 계산 구조. 딥러닝을 만드는 재료다.
- **비정형 데이터** : 표의 칸에 딱 떨어지게 넣기 어려운 데이터. 사진, 음성, 문장 등.
- **블랙박스** : 답은 나오는데 왜 그렇게 나왔는지 사람이 들여다보기 어려운 상태.
- **GPU** : 같은 계산을 대량으로 동시에 처리하는 연산 장치. 딥러닝 학습 속도를 좌우한다.
- **생성형 AI** : 새로운 문장·이미지 등을 만들어 내는 AI. 딥러닝을 기반으로 한다.
- **에이전틱 AI** : 목표를 받으면 스스로 계획을 세우고 도구를 써 가며 여러 단계를 실행하는 AI 시스템.

## 📝 연습 문제

**문제 1.** 인공지능(AI), 머신러닝(ML), 딥러닝(DL)의 관계를 가장 정확하게 설명한 것은?

A) 세 개념은 서로 완전히 독립적이며 겹치지 않는다  
B) 딥러닝이 가장 넓은 개념이고 그 안에 머신러닝과 AI가 포함된다  
C) AI가 가장 넓고, 그 안에 머신러닝이, 머신러닝 안에 딥러닝이 포함된다  
D) 머신러닝과 딥러닝은 같은 의미이며 AI와는 무관하다  

**정답: C**  
해설: AI가 가장 큰 범주이고 머신러닝은 AI를 구현하는 한 방법, 딥러닝은 머신러닝의 한 종류입니다. 따라서 포함 관계는 AI ⊃ ML ⊃ DL입니다. 세 개념이 독립적이라거나 딥러닝이 가장 넓다는 설명, 머신러닝과 딥러닝이 동일하다는 설명은 모두 포함 관계를 잘못 이해한 것입니다.

**문제 2.** 사람이 "제목에 특정 단어가 있으면 처리하라"는 규칙을 직접 모두 작성해 동작하는 시스템에 대한 설명으로 옳은 것은?

A) 데이터로부터 규칙을 학습하므로 전형적인 머신러닝이다  
B) 신경망을 사용하므로 딥러닝이다  
C) 사람이 규칙을 직접 만들었으므로 머신러닝이라 보기 어렵다  
D) AI와는 전혀 관련이 없는 일반 소프트웨어일 뿐이다  

**정답: C**  
해설: 머신러닝의 핵심은 데이터에서 기계가 스스로 규칙을 학습하는 것입니다. 사람이 규칙을 직접 작성한 시스템은 학습 과정이 없으므로 머신러닝이라 보기 어렵습니다. 신경망을 쓰지 않았으므로 딥러닝도 아닙니다. 다만 지능적 행동을 흉내 내는 규칙 기반 시스템은 넓은 의미의 AI 범주에는 포함될 수 있습니다.

**문제 3.** 딥러닝이 전통적인 머신러닝과 비교해 일반적으로 더 많이 요구하는 것은?

A) 사람이 직접 작성한 명시적 규칙  
B) 대량의 데이터와 강력한 연산 자원  
C) 데이터를 전혀 사용하지 않는 환경  
D) 단순한 표 형태의 소량 데이터만 사용하는 환경  

**정답: B**  
해설: 딥러닝은 신경망을 깊게 쌓아 복잡한 패턴을 학습하기 때문에 일반적으로 대량의 데이터와 GPU 같은 강력한 연산 자원을 필요로 합니다. 사람이 작성한 명시적 규칙은 규칙 기반 방식의 특징이며, 데이터를 사용하지 않는다는 설명은 머신러닝의 본질과 어긋납니다.

**문제 4.** 다음 중 일반적으로 딥러닝이 가장 큰 강점을 보이는 데이터 유형은?

A) 정해진 규칙으로 쉽게 처리 가능한 단순 계산  
B) 이미지, 음성, 자연어 같은 복잡하고 비정형적인 데이터  
C) 데이터가 거의 없는 소규모 환경  
D) 사람이 모든 규칙을 명확히 정의할 수 있는 문제  

**정답: B**  
해설: 딥러닝은 이미지 인식, 음성 인식, 자연어 처리처럼 사람이 규칙을 명확히 정의하기 어렵고 패턴이 복잡한 비정형 데이터에서 특히 강력합니다. 규칙으로 쉽게 처리되는 단순 문제나 데이터가 매우 적은 환경에서는 딥러닝의 장점이 발휘되기 어렵습니다.
