# Day 5 - Week 1 종합: AI/ML 기초 복습

## 📌 핵심 정리

- **Day 1**: AI ⊃ 머신러닝 ⊃ 딥러닝. 모든 딥러닝은 ML이지만, 모든 AI가 ML은 아니다.
- **Day 2**: 학습 유형은 정답 유무·보상 여부로 지도(분류/회귀)·비지도(군집/차원 축소)·강화로 나뉜다.
- **Day 3**: 전통적 프로그래밍은 `데이터+규칙→결과`, ML은 `데이터+결과→규칙`. ML은 규칙이 복잡하고 데이터가 충분할 때 적합하다.
- **Day 4**: 특성+레이블로 학습해 모델을 만들고, 추론으로 예측하며, 테스트 데이터로 과적합을 점검한다.
- 시험에서 헷갈리기 쉬운 함정: 분류 vs 회귀(범주/숫자), 분류 vs 군집(레이블 유무), 과적합(=암기지 학습 부족이 아님).

## 이번 주 흐름

복습은 암기가 아니라 **개념이 어떻게 연결되는지**를 다시 그려 보는 시간이다.

```
[Day1] AI > ML > DL 관계
   ↓
[Day2] ML의 학습 유형 (지도·비지도·강화)
   ↓
[Day3] ML이 적합한 문제 vs 아닌 문제
   ↓
[Day4] 핵심 용어 (모델·학습·추론·특성·레이블·과적합)
```

## Day 1 복습: AI·ML·DL의 관계

- **AI ⊃ 머신러닝 ⊃ 딥러닝**
- **AI**: 지능적 행동을 흉내 내는 모든 기술(규칙 기반 포함)
- **머신러닝**: 데이터로부터 규칙을 학습하는 방법
- **딥러닝**: 신경망을 깊게 쌓은 머신러닝의 한 종류
- 사람이 규칙을 직접 적은 시스템은 AI일 수 있어도 머신러닝은 아니다.

## Day 2 복습: 학습 유형

| 학습 유형 | 정답(레이블) | 대표 작업 |
|-----------|-------------|----------|
| 지도학습 | 있음 | 분류(범주), 회귀(숫자) |
| 비지도학습 | 없음 | 군집, 차원 축소 |
| 강화학습 | 보상으로 대체 | 게임·로봇·제어 |

자주 헷갈리는 두 쌍을 다시 정리한다.

- **분류 vs 회귀**: 출력이 범주면 분류, 숫자면 회귀.
- **분류 vs 군집**: 정답 레이블이 있으면 분류, 없으면 군집.

## Day 3 복습: ML이 적합한 문제

- **전통적 프로그래밍**: `데이터 + 규칙 → 결과`
- **머신러닝**: `데이터 + 결과 → 규칙`

| 머신러닝이 적합 | 머신러닝이 부적합 |
|----------------|------------------|
| 규칙이 복잡하거나 정의하기 어려움 | 규칙이 단순·명확함 |
| 데이터가 충분함 | 데이터가 거의 없음 |
| 약간의 오차 허용 가능 | 100% 정확성·완전한 설명 필수 |

- 가장 단순하면서 충분한 방법을 고르는 것이 좋은 설계다.

## Day 4 복습: 핵심 용어

```
특성 + 레이블 [학습 데이터]
   ↓ 학습(Training)
[모델] 완성
   ↓ 추론(Inference)
새 입력(특성) → 예측된 레이블
   ↓
[테스트 데이터]로 평가 → 과적합/과소적합 점검
```

- **모델**: 학습된 규칙 덩어리
- **학습 vs 추론**: 모델을 만드는 과정 vs 만든 모델로 예측하는 과정
- **특성 vs 레이블**: 입력 정보 vs 맞혀야 할 정답
- **과적합 vs 과소적합**: 학습 데이터만 외운 상태 vs 학습이 부족한 상태

이번 주 내용은 AIF-C01 시험의 "AI/ML 기초 개념" 영역의 토대다. 이 흐름을 명확히 이해해야 이후 생성형 AI, AWS AI 서비스 같은 심화 주제를 무리 없이 따라갈 수 있다.

## 자주 틀리는 함정 정리

| 함정 | 올바른 이해 |
|------|------------|
| "딥러닝이 가장 큰 개념" | AI가 가장 큼. 딥러닝이 가장 작음 |
| "분류와 회귀는 같다" | 분류=범주, 회귀=숫자 |
| "분류와 군집은 같다" | 정답 레이블 유무가 다름 |
| "머신러닝이 항상 더 좋다" | 단순 문제엔 전통적 방식이 유리 |
| "학습 데이터로 평가해도 된다" | 테스트 데이터로 평가해야 정직함 |
| "과적합 = 학습 부족" | 과적합은 오히려 너무 많이 외운 상태 |

## 지문을 읽는 순서: 네 번 물으면 답이 남는다

나흘치 내용은 따로 외우면 흩어지지만, **질문의 순서**로 엮으면 하나의 판별 절차가 된다.

```
① 규칙을 누가 만들었나?
   ├─ 사람이 조건을 직접 적었다 ─────────► 규칙 기반(AI일 수는 있어도 ML 아님)
   └─ 데이터에서 학습했다 ───────────────► 머신러닝 (②로)
                                            └ 여러 층의 신경망이면 딥러닝

② 무엇을 보고 배웠나?
   ├─ 정답(레이블)이 붙은 데이터 ────────► 지도학습 (③으로)
   ├─ 정답 없는 데이터 ──────────────────► 비지도학습 (군집·차원 축소·이상 탐지)
   └─ 행동의 결과로 받은 보상 ───────────► 강화학습

③ 맞히려는 답의 모양은?
   ├─ 정해진 종류 중 하나 ───────────────► 분류
   └─ 크기에 의미가 있는 숫자 ───────────► 회귀

④ 성능 이야기가 나오면 두 점수를 본다
   ├─ 학습도 낮고 테스트도 낮다 ─────────► 과소적합
   ├─ 학습만 높고 테스트가 뚝 떨어진다 ──► 과적합
   └─ 둘 다 높고 차이가 작다 ────────────► 일반화가 잘 됨
```

- ①보다 앞선 질문이 하나 더 있다. **"애초에 ML이 필요한가"**(Day 3). 규칙이 한 줄이거나, 정해진 결과가 필요하거나, 데이터가 없으면 ①로 들어갈 이유가 없다.
- ②와 ③을 섞지 말 것. "그룹으로 나눈다"는 말만 보고 분류를 고르면 틀린다. 먼저 ②에서 레이블 유무를 확인해야 분류와 군집이 갈린다.

## 한 사례로 나흘치를 꿰기

온라인 서점이 "반품될 주문을 미리 알아내고 싶다"고 한다. 이 한 문장에 이번 주 내용이 전부 걸린다.

| 단계 | 서점에서 벌어지는 일 | 걸리는 개념 |
|------|---------------------|------------|
| 필요성 판단 | "3만 원 미만은 반품 불가" 같은 정책은 코드로 충분하다. 하지만 "어떤 주문이 반품될까"는 규칙으로 적을 수 없고, 과거 주문 기록이 수십만 건 있다 | Day 3: ML이 적합한 조건 |
| 기술 수준 | 주문 금액·배송 지역·구매 이력 같은 표 데이터다. 굳이 딥러닝이 아니어도 된다 | Day 1: ML과 딥러닝의 구분 |
| 학습 유형 | 과거 주문마다 "반품됨/안 됨" 기록이 있다 → 지도학습, 답이 두 범주 → 분류 | Day 2: 레이블 유무, 범주/숫자 |
| 데이터 구성 | 주문 금액·지역·이력이 특성, 반품 여부가 레이블 | Day 4: 특성과 레이블 |
| 모델 만들기 | 기록의 일부로 학습하고, 떼어 둔 테스트 데이터로 점수를 잰다. 학습 98% / 테스트 71%면 과적합이다 | Day 4: 데이터 분리, 과적합 |
| 서비스 | 주문이 들어올 때마다 반품 가능성을 바로 알려면 실시간 추론, 밤마다 그날 주문을 몰아서 점검하면 배치 추론 | Day 4: 학습과 추론, 추론 방식 |

- 질문을 조금만 바꾸면 답이 달라진다. "반품 **금액**이 얼마일까" → 회귀. "반품 기록 없이 고객을 유형별로 나눠 보자" → 군집. "주문마다 어떤 쿠폰을 보여 줄지 반응을 보며 익히자" → 강화학습.

## 자주 헷갈리는 짝, 지문의 단어로 가르기

| 짝 | 앞의 것을 가리키는 단어 | 뒤의 것을 가리키는 단어 |
|-----|------------------------|------------------------|
| 규칙 기반 vs 머신러닝 | "조건을 정의", "if-then" | "과거 데이터로 학습", "패턴" |
| 머신러닝 vs 딥러닝 | "표 데이터", "특성을 사람이 선정" | "여러 층의 신경망", "이미지·음성 원본" |
| 분류 vs 회귀 | "여부", "종류", "등급" | "얼마", "몇 개", "몇 도" |
| 분류 vs 군집 | "표시된", "과거 결과가 있는" | "레이블 없이", "비슷한 것끼리" |
| 학습 vs 추론 | "모델을 만든다", "오래 걸린다" | "새 입력", "예측", "응답 시간" |
| 알고리즘 vs 모델 | "학습 방법", "절차" | "학습된 결과물", "배포한다" |
| 검증 vs 테스트 | "학습 중 조정", "설정 선택" | "최종 평가", "한 번만" |
| 과적합 vs 과소적합 | "학습만 높다", "격차", "외웠다" | "둘 다 낮다", "너무 단순" |
| 실시간 vs 배치 추론 | "즉시", "낮은 지연" | "대량", "주기적", "야간" |

다음 주에는 이 기초 위에서 ML 수명주기(수집 → 준비 → 학습 → 평가 → 배포 → 모니터링)와 데이터, 평가 지표, 사람의 역할을 다룬다.

## 📖 용어

- **AI ⊃ ML ⊃ DL** : "AI 안에 머신러닝이, 머신러닝 안에 딥러닝이 들어 있다"는 포함 관계 표기.
- **지도학습** : 문제와 정답을 함께 주고 배우게 하는 방식.
- **비지도학습** : 정답 없이 데이터만 주고 숨은 구조를 스스로 찾게 하는 방식.
- **강화학습** : 보상과 벌점을 주며 시행착오로 행동 요령을 익히게 하는 방식.
- **분류 vs 회귀** : 답이 "종류"면 분류, 답이 "숫자"면 회귀.
- **군집** : 정답 없이 비슷한 데이터끼리 자동으로 묶는 작업.
- **특성 vs 레이블** : 예측에 넣는 입력 정보가 특성, 맞혀야 할 정답이 레이블.
- **추론** : 완성된 모델에 새 입력을 넣어 답을 얻는 단계.
- **과적합** : 학습 데이터를 통째로 외워 새 데이터에서 힘을 못 쓰는 상태.
- **일반화** : 학습 때 못 본 데이터에서도 잘 맞히는 성질. 모델의 최종 목표.

## 📝 연습 문제

**문제 1.** AI·머신러닝·딥러닝의 관계와 학습 유형에 대한 설명으로 옳은 것은?

A) 딥러닝이 AI보다 넓은 개념이다  
B) 머신러닝은 데이터로 규칙을 학습하며, 딥러닝은 그중 신경망 기반 방식이다  
C) 지도학습은 정답이 전혀 없는 데이터로 학습한다  
D) 강화학습은 정답 레이블을 그대로 외워서 학습한다  

**정답: B**  
해설: 머신러닝은 데이터로부터 규칙을 학습하는 방법이며, 딥러닝은 그 안에서 신경망을 깊게 쌓는 방식이다. AI가 가장 넓은 개념이므로 딥러닝이 더 넓다는 설명은 틀리고, 지도학습은 정답이 있는 데이터로, 강화학습은 보상으로 학습한다.

---

**문제 2.** "고객 데이터를 정답 없이 비슷한 성향끼리 자동으로 묶는다"와 "내일 기온이 몇 도일지 숫자로 예측한다"는 각각 어떤 작업인가?

A) 둘 다 분류  
B) 군집과 회귀  
C) 회귀와 군집  
D) 둘 다 강화학습  

**정답: B**  
해설: 정답 없이 유사한 데이터를 묶는 것은 비지도학습의 군집이고, 연속적인 숫자 값을 예측하는 것은 지도학습의 회귀이다. 따라서 순서대로 군집과 회귀이다.

---

**문제 3.** 어떤 업무에서 규칙이 매우 단순하고 명확하며("금액 × 고정 세율"), 결과는 항상 100% 정확해야 한다. 이에 대한 판단으로 가장 적절한 것은?

A) 데이터가 많으니 무조건 딥러닝을 써야 한다  
B) 규칙이 단순하고 완전한 정확성이 필요하므로 전통적 프로그래밍이 더 적합하다  
C) 군집을 사용하면 가장 정확하게 해결된다  
D) 머신러닝이 항상 더 정확하므로 머신러닝을 써야 한다  

**정답: B**  
해설: 규칙이 단순·명확하고 100% 정확성이 요구되는 문제는 전통적 프로그래밍이 더 정확하고 저렴하다. 머신러닝이 항상 더 정확한 것은 아니며, 군집은 정답 없이 묶는 비지도학습이라 이 문제에 맞지 않다.

**문제 4.** 학습된 모델이 학습 데이터에서는 거의 완벽하지만 새로운 데이터에서는 성능이 크게 떨어졌다. 그리고 특성과 레이블의 정의를 묻는다. 옳은 설명은?

A) 이 상태는 과소적합이며, 특성은 정답을 뜻한다  
B) 이 상태는 과적합이며, 특성은 입력 정보, 레이블은 맞혀야 할 정답이다  
C) 이 상태는 추론이며, 레이블은 입력 정보를 뜻한다  
D) 이 상태는 일반화가 잘 된 이상적인 모델이다  

**정답: B**  
해설: 학습 데이터만 잘 맞히고 새 데이터에서 성능이 떨어지는 상태는 과적합이다. 특성은 예측에 쓰는 입력 정보, 레이블은 모델이 맞혀야 할 정답을 뜻한다. 과소적합은 학습 데이터에서도 성능이 낮은 상태이고, 새 데이터 성능이 낮으므로 일반화가 잘 된 것도 아니다.

**문제 5.** 이번 주에 배운 내용을 종합할 때, 좋은 머신러닝 활용 판단으로 가장 적절한 것은?

A) 모든 문제에 가장 복잡한 딥러닝을 적용한다  
B) 문제의 성격·데이터 양·정확성 요구를 보고 가장 단순하면서 충분한 방법을 선택한다  
C) 테스트 데이터를 학습에 포함해 정확도를 높인다  
D) 정답이 있는 데이터에는 항상 군집을 사용한다  

**정답: B**  
해설: 좋은 설계는 문제 성격, 데이터의 양과 품질, 정확성 요구 수준을 종합해 가장 단순하면서 충분한 방법을 고르는 것이다. 무조건 딥러닝을 쓰거나, 테스트 데이터를 학습에 섞거나, 정답이 있는데도 군집을 쓰는 것은 모두 잘못된 판단이다.
